# 개인정보 처리방침

<div class="key-takeaway">
본 사이트는 정적 사이트입니다 — 회원가입과 입력 양식이 없습니다. 이용 통계를 작성하기 위해 Google Analytics 4 분석 쿠키를 사용합니다.
</div>

## 수집하는 정보

<p class="key-answer" data-question="KrTxGNN은 개인정보를 수집합니까?">
<strong>Google Analytics 4를 통한 이용 통계만 수집합니다.</strong> 본 사이트는 GitHub Pages에서 호스팅되는 순수 정적
사이트입니다. 계정 시스템과 입력 양식이 없으며, 이름, 이메일 주소, 진료 기록은 수집하지 않습니다. 이용 통계(조회한
페이지, 유입 경로, 스크롤 깊이, 페이지 체류 시간)를 작성하기 위해 Google Analytics 4 분석 쿠키를 사용합니다. 쿠키는
페이지를 불러올 때 설정되며, 검색어, 입력 양식 내용, URL 쿼리 문자열은 전송하지 않습니다.
</p>

## 제3자 서비스

본 사이트는 다음의 제3자 리소스를 사용하며, 각 서비스는 자체 정책에 따라 접속 기록을 남길 수
있습니다:

| 서비스 | 용도 | 개인정보 처리방침 |
|---------|---------|----------------|
| GitHub Pages | 사이트 호스팅 | [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement) |
| Google Analytics 4 (www.googletagmanager.com, google-analytics.com) | 방문 통계(조회한 페이지, 유입 경로)이며 분석 쿠키를 사용합니다. 검색어, 입력 양식 내용, URL 쿼리 문자열은 전송하지 않습니다. | [Google 개인정보처리방침](https://policies.google.com/privacy) |
| cdn.jsdelivr.net | 스크립트 라이브러리: 모든 페이지의 d3 차트, SMART 페이지의 Fuse.js 이름 대조와 SMART on FHIR 클라이언트 | [jsDelivr 개인정보처리방침](https://www.jsdelivr.com/terms/privacy-policy-jsdelivr-net) |
| clinicaltrials.gov | SMART 페이지의 임상시험 조회: 이용자가 요청할 때만 약물명과 적응증명이 ClinicalTrials.gov API로 전송됩니다 | [NLM 웹 정책](https://www.nlm.nih.gov/web_policies.html) |
| rxnav.nlm.nih.gov | SMART 앱: 전자의무기록에서 읽은 약물의 RxNorm 코드가 성분명 조회를 위해 미국 국립의학도서관(NLM) RxNav API로 전송됩니다(환자 식별 정보 없음) | [NLM 웹 정책](https://www.nlm.nih.gov/web_policies.html) |

이용자가 직접 SMART on FHIR 앱을 실행하면, 해당 앱은 이용자의 전자의무기록 시스템에 투약
데이터를 요청합니다. 환자 신원과 전자의무기록 데이터는 <strong>본 사이트의 서버로 전송되지 않으며</strong>(본 사이트는
백엔드가 없는 정적 사이트입니다) 본 사이트에 저장되지 않습니다. 약품명을 대조하기 위해 앱은 약품의 RxNorm 코드를
미국 국립의학도서관(NLM)의 RxNav 서비스로 전송하며, 이 코드에는 환자를 식별할 수 있는 정보가 포함되지 않습니다.
임상시험 조회를 요청하면 약품명과 적응증명이 ClinicalTrials.gov로 전송됩니다.

## 적용 법률

한국 이용자에게는 [「개인정보 보호법」](https://www.law.go.kr/LSW/lsInfoP.do?lsId=011357)이 적용되며 [개인정보보호위원회](https://www.pipc.go.kr/)가 소관합니다. 이 사이트는 이름·이메일·진료 기록을 수집하지 않으며, 관련 개인정보는 Google Analytics 4가 분석 쿠키로 수집하는 이용 통계뿐이고 Google이 국외에서 처리합니다.

## 이용자의 권리와 행사 방법

- 개인정보 열람 요구(제35조).
- 정정·삭제 요구(제36조).
- 처리정지 요구(제37조) — 분석 쿠키를 차단하면 수집도 중단됩니다.
- 개인정보보호위원회 또는 개인정보침해 신고센터에 신고·상담.

요청·문의: service@yao.care. 사이트에 계정이 없으므로 Google Analytics가 보유한 데이터는 방문 날짜와 페이지 등 충분한 정보를 알려 주셔야 처리할 수 있습니다. 분석 쿠키는 브라우저에서 언제든 차단하거나 삭제할 수 있습니다.

## 저작권과 데이터 출처

사이트 본문은 [「저작권법」](https://www.law.go.kr/법령/저작권법)으로 보호됩니다. 사이트 코드는 [GitHub 저장소](https://github.com/yao-care/KrTxGNN)에 MIT 라이선스로 공개되어 있으며, 보고서 본문의 저작권은 藥提醒科技有限公司 (yao.care)에 있습니다.

이 사이트가 사용하는 데이터 출처와 이용 조건:

- **TxGNN** 예측 데이터(Harvard Dataverse): CC0 1.0 퍼블릭 도메인 기증. 인용 시 Huang et al., *Nature Medicine* 2024를 밝혀 주십시오.
- **ClinicalTrials.gov**·**PubMed**: 미국 국립의학도서관. [ClinicalTrials.gov 이용 조건](https://clinicaltrials.gov/about-site/terms-conditions)과 [NCBI 정책](https://www.ncbi.nlm.nih.gov/home/about/policies/)을 참고하십시오(일부 PubMed 초록은 출판사 저작권이 남아 있습니다).
- **DrugBank** 식별자와 데이터: [DrugBank](https://go.drugbank.com/) 라이선스 조건(비상업적 이용)에 따릅니다.
- **국내 데이터셋**: [의약품안전나라(nedrug) 의약품 검색](https://nedrug.mfds.go.kr/searchDrug), 식품의약품안전처이(가) 공개한 자료로, 재사용에는 공개 기관의 이용 조건이 적용되며 이 사이트가 추가 권리를 부여하지 않습니다.
