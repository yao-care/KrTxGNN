# Levodopa: 파킨슨병에서 Rasmussen 아급성 뇌염으로

## 한 문장 요약

Levodopa(DB01235)는 도파민 전구체로 일반적으로 파킨슨병 치료에 사용되는 약물입니다. TxGNN 모델은 **Rasmussen 아급성 뇌염(Rasmussen subacute encephalitis)**에 효과가 있을 수 있다고 예측했으나(점수 99.06%), 이를 뒷받침하는 임상시험이나 문헌은 **현재 하나도 없으며**, 모델 자체 평가에서도 기전적 타당성이 낮다고 판단됩니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가 자료 없음 (한국 미시판) |
| 예측 신규 적응증 | Rasmussen 아급성 뇌염 (Rasmussen subacute encephalitis) |
| TxGNN 예측 점수 | 99.06% (전체 순위 13,810위) |
| 근거 수준 | L5 (모델 예측만 존재, 실제 연구 없음) |
| 한국 시판 현황 | ✗ 미시판 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 Levodopa의 상세한 작용 기전(MOA) 데이터가 확보되지 않았습니다. 다만 일반적으로 Levodopa는 도파민 전구체로서 흑질-선조체 경로의 도파민 결핍을 보충하는 약물로 알려져 있습니다.

TxGNN 모델이 생성한 자체 근거 설명에 따르면, Rasmussen 뇌염은 소아 단측 대뇌반구의 만성 염증성 질환으로 T세포 매개 자가면역/염증 반응이 병태생리이며, 도파민 결핍과는 무관합니다. Levodopa가 이러한 면역·염증 기전을 직접 조절한다는 알려진 경로는 없습니다.

즉 99.06%라는 높은 예측 점수는 지식그래프 내 신경계 질환 노드 간의 근접성이나 공존질환 패턴을 반영한 것일 가능성이 크며, 실제 생물학적 기전에 기반한 예측이라 보기 어렵습니다. 이 점이 모델이 자체적으로 "기전적 타당성 부족"을 명시한 이유이기도 합니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 안전성 고려사항

안전성 정보는 허가사항을 참조하세요.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
- 근거 수준이 L5(모델 예측만 존재)로, 임상시험과 문헌 근거가 전무합니다.
- 모델이 자체적으로 제시한 기전적 근거(mechanistic_link)에서도 도파민 보충과 자가면역성 뇌염 간의 생물학적 연결고리가 확인되지 않습니다.
- 한국에 미시판 상태로 규제 현황 정보가 없습니다.

**진행하려면 필요한 것:**
- Levodopa의 상세 작용 기전(MOA) 데이터 확보 (현재 Blocking 등급 자료 공백: 허가사항 경고/금기 정보 미확보로 S1 안전성 초기 평가 진입 불가)
- Rasmussen 아급성 뇌염에 대한 전임상/기전 연구 자료
- 관련 임상시험 또는 증례보고 등 실제 근거 축적
- 위 자료 보완 전까지는 후속 단계 진행 보류 권장
