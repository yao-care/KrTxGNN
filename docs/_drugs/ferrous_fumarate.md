# Ferrous Fumarate: 철결핍성 빈혈에서 비증후군성 식도 기형으로

## 한 문장 요약

Ferrous fumarate는 철분 보충제로 철결핍성 빈혈 치료에 사용되는 약물입니다(원본 적응증은 자료팩에 별도 기재되어 있지 않으며, 이는 일반적으로 알려진 약리학적 용도입니다). TxGNN 모델은 **비증후군성 식도 기형(Non-syndromic Esophageal Malformation)**에 효과가 있을 수 있다고 예측했으나(예측 점수 99.49%), 이를 뒷받침하는 **임상시험과 문헌은 전혀 없습니다**.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 철결핍성 빈혈 (자료팩 미기재, 일반 약리 지식 기준) |
| 예측 신규 적응증 | 비증후군성 식도 기형 (Non-syndromic Esophageal Malformation) |
| TxGNN 예측 점수 | 99.49% (전체 순위 8,665위) |
| 근거 수준 | L5 (모델 예측만 존재, 실제 연구 없음) |
| 시판 현황 | 미판매 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터는 확보되지 않았습니다. 알려진 정보에 따르면 ferrous fumarate는 철 이온을 보충하는 무기염 형태의 철분제이며, 철결핍성 빈혈 치료에 사용됩니다.

비증후군성 식도 기형은 태생기 식도 형성 이상에 의한 구조적 선천 결손으로, 외과적 교정이 필요한 질환입니다. 철 대사 경로나 철분 보충으로 개입할 수 있는 병태생리 기전은 현재까지 알려진 바가 없습니다.

TxGNN 예측 점수는 99.49%로 매우 높지만, 이는 지식 그래프 내 노드 임베딩 유사도를 반영할 뿐 약리학적으로 설명 가능한 인과 경로는 확인되지 않았습니다. 철 결핍과 식도 발생의 연관성은 세포증식·혈관신생 측면에서 매우 약한 추정만 가능한 수준이며, 구체적 근거가 없어 모델 잡음 또는 지식그래프 연결 오류에 의한 위양성일 가능성이 높습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 안전성 고려사항

안전성 정보(주요 경고, 금기, 약물 상호작용)가 현재 확보되지 않았습니다. 허가 당국의 안전성 자료(예: 경고문/금기 사항) 확인이 필요합니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
근거 수준이 L5(모델 예측만 존재)이며 관련 임상시험·문헌이 전무합니다. 또한 예측된 적응증(비증후군성 식도 기형)은 구조적 선천 기형으로, 철분 보충제의 알려진 약리 기전과 연결할 병태생리학적 근거가 없어 위양성 가능성이 높습니다.

**진행하려면 필요한 것:**
- 작용 기전(MOA) 상세 데이터 확보
- 허가사항 경고/금기 정보 확보 (Blocking 데이터 갭 해결)
- 철 대사와 식도 발생 간 연관성을 뒷받침하는 전임상/기전 연구
- 최소 1건 이상의 관찰연구 또는 문헌 근거 확보 후 재평가
