# Oxcarbazepine: 부분발작성 뇌전증에서 시각 유발성 뇌전증(Visual Epilepsy)으로

## 한 문장 요약

Oxcarbazepine은 부분발작(국소성 발작) 치료에 사용되는 항경련제(AED)입니다.
TxGNN 모델은 **시각 유발성 뇌전증(Visual Epilepsy)**에도 효과가 있을 수 있다고 예측하며(예측 점수 **99.95%**),
현재 **1건의 임상시험**과 **20편의 문헌**이 뇌전증 전반에 대한 oxcarbazepine의 효능을 뒷받침하지만,
이 특정 반사성 뇌전증 아형을 직접 겨냥한 근거는 아직 부족합니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 부분발작성(국소성) 뇌전증 — 문헌 근거 기반, 허가 데이터 없음 |
| 예측 신규 적응증 | 시각 유발성 뇌전증 (Visual Epilepsy) |
| TxGNN 예측 점수 | 99.95% |
| 근거 수준 | L4 |
| 한국 시판 현황 | 미시판 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터가 없습니다. 다만 수집된 문헌에 따르면 oxcarbazepine은 항경련제(AED)의 일종으로,
carbamazepine의 keto 유도체이며 부분발작 및 이차성 전신발작 치료에서 단독요법·병용요법 모두 효능이 입증되어 있습니다
(예: PMID 11772334, PMID 10530693).

시각 유발성 뇌전증은 특정 시각 자극(예: 점멸광)에 의해 유발되는 반사성 뇌전증의 한 아형입니다.
기존 임상 근거는 oxcarbazepine의 광범위한 항경련 작용(나트륨 채널 차단)을 뒷받침하지만, 확보된 임상시험과 문헌은
모두 국소성 뇌전증 전반을 다루고 있을 뿐, 시각 유발성 뇌전증이라는 특정 반사성 아형을 직접 검증한 연구는 없습니다.
따라서 이 예측은 기전적으로는 개연성이 있으나, 대상 질환 특이적 임상 검증이 필요한 단계입니다.

## 안전성 고려사항

안전성 정보는 허가사항을 참조하세요.

> ⚠ 한국 허가사항(경고, 금기, DDI)에 해당하는 데이터가 확보되지 않았습니다(Blocking gap, DG001). 이 항목이 채워지기 전까지는 안전성 초기 평가(S1)를 진행할 수 없습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
- 시각 유발성 뇌전증을 특이적으로 검증한 임상시험·문헌이 없고, 확보된 근거는 국소성 뇌전증 전반에 대한 간접 근거(L4)에 그칩니다.
- 한국 내 미시판 상태(허가증 0건)이며, TFDA/식약처 수준의 경고·금기 정보가 Blocking gap으로 남아 있어 안전성 초기 평가(S1)를 진행할 수 없습니다.

**진행하려면 필요한 것:**
- TFDA(또는 국내 규제기관) 허가사항 원문 확보 및 경고·금기·DDI 정보 파싱 (DG001 해소)
- DrugBank API를 통한 상세 작용 기전(MOA) 확보 (DG002 해소)
- 시각 유발성 뇌전증(반사성 뇌전증 아형)에 특이적인 사례보고 또는 소규모 임상 연구 추가 확보
- 확보 후 근거 수준 재평가 및 S1 안전성 초기 평가 진행
