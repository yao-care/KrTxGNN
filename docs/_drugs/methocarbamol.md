# Methocarbamol: 근골격계 질환에서 마미 증후군으로

## 한 문장 요약

Methocarbamol은 중추 작용 골격근 이완제로, 한국에서 단일 성분제(정제 및 주사제)로 널리 시판되고 있습니다. TxGNN 모델은 **마미 증후군(cauda equina syndrome)**에 효과가 있을 수 있다고 예측하지만, 현재 이를 지지하는 **임상시험은 0건, 직접 관련된 문헌도 0편**입니다. 모델 예측만 있는 단계입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 확인 불가 (허가 적응증 본문이 아닌 허가 문서 링크만 제공됨) |
| 예측 신규 적응증 | 마미 증후군 (Cauda Equina Syndrome) |
| TxGNN 예측 점수 | 99.98% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 20건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. Methocarbamol은 중추 작용 골격근 이완제로 알려져 있으나 정확한 기전은 충분히 규명되지 않았습니다. 근육 경련이나 요통과 관련된 증상 완화에는 쓰일 수 있습니다.

그러나 마미 증후군은 신경 압박으로 인한 응급 질환으로, 치료의 핵심은 수술적 감압입니다. Methocarbamol이 이 질환의 경과를 바꿀 수 있다고 볼 만한 근거는 없으며, 연관성은 모델 점수에 의존한 추정에 그칩니다.

참고로 점수 상위 10개 예측(과민성 장 증후군, 범포도막염, 아나필락시스, 포도막염 등)도 모두 L5 수준이며, 마미 증후군이 가장 높은 점수를 받았습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

마미 증후군에 대해 검색된 문헌이 없습니다. 참고로, 상위 예측 중 아나필락시스 항목에서 검색된 문헌 2편은 이번 예측(마미 증후군)과 직접 관련이 없어 표에 포함하지 않았습니다.

## 안전성 고려사항

- **약물 상호작용**: 총 100건이 조회되었으며, 주요 항목은 다음과 같습니다.
  - **Major**: Morphine, Morphine(리포좀) — 중추신경 억제 가중 가능성에 유의해야 합니다.
  - **Moderate**: Dronabinol, Nabilone, Metoclopramide, Opium, Sibutramine
- **지식그래프 기반 금기 연관 질환**(허가 문구가 아닌 모델 지식그래프 기준): 간질, 신장 질환, 간 질환, 담낭 질환, 혈소판감소증, 소화성 궤양, 통풍, 약물 남용/의존, 혈우병, 빈혈, 위염, 라이증후군, 알츠하이머병, 폰 빌레브란트병 등. 참고용이며 허가사항 확인이 필요합니다.

허가사항의 경고 및 주의사항은 별도로 확인하세요.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
TxGNN 점수는 매우 높지만(99.98%), 임상시험과 직접 관련 문헌이 전혀 없고 기전상 타당성도 약합니다. 마미 증후군은 수술적 감압이 필요한 질환이어서 재창출 후보로 진행할 근거가 부족합니다.

**진행하려면 필요한 것:**
- 허가 문서(MFDS)에서 허가 적응증, 경고, 금기 확인
- DrugBank 등에서 작용 기전(MOA) 데이터 확보
- 마미 증후군 관련 증상(근경련, 통증) 완화 목적의 사용에 대한 전임상·임상 근거 탐색
- 근거가 없다면 다른 상위 예측(예: 과민성 장 증후군)이나 증상 완화 목적의 보조 요법으로 방향 재검토
