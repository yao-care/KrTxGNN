# Prucalopride: 만성 변비(장운동 저하)에서 저알파지단백혈증으로

## 한 문장 요약

Prucalopride는 5-HT4 수용체 작용제로, 장 평활근과 장신경계에 작용해 만성 변비 등 장운동 저하 관련 질환에 사용되어 온 약물입니다(한국 미허가). TxGNN 모델은 **저알파지단백혈증(Hypoalphalipoproteinemia)**에 효과가 있을 수 있다고 예측했으나, 이를 뒷받침하는 **임상시험이나 문헌은 현재 확인되지 않았으며**, 평가 근거 자체도 "지질대사 경로와 알려진 기전상 중첩이 없다"고 명시하고 있어 근거 수준은 모델 예측에만 의존하는 **L5**입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 만성 변비 / 장운동 저하 (해외 적응증, 한국 미허가) |
| 예측 신규 적응증 | 저알파지단백혈증 (Hypoalphalipoproteinemia) |
| TxGNN 예측 점수 | 99.82% |
| 근거 수준 | L5 (모델 예측만 존재, 임상시험·문헌 없음) |
| 한국 시판 현황 | 미출시 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

Drug-level MOA 필드는 데이터 갭 상태이지만, 평가 근거 텍스트에 따르면 Prucalopride는 **5-HT4 수용체 작용제**로 장 평활근과 장신경계에 작용해 장운동을 촉진하는 기전을 가집니다.

그러나 저알파지단백혈증은 HDL(고밀도지단백) 결핍을 특징으로 하는 지질대사 질환으로, 장운동 촉진 기전과 지질대사 경로 사이에 알려진 생물학적 연결고리가 없습니다. 평가 근거 자체에서도 "無機轉合理性(기전상 타당성 없음)"이라고 명시하고 있어, 이 예측은 TxGNN 그래프상의 간접 연결에 의존하는 것으로 보이며 실질적인 기전 뒷받침이 부족합니다.

참고로 같은 평가 세트 내 **amyloidosis** 및 **primary amyloidosis**(순위 6, 9위)는 상대적으로 더 나은 근거 수준(L4, Research Question 단계)을 보였습니다. 이들 질환은 자율신경병증을 통해 만성 장관 가성폐쇄(CIPO)를 유발할 수 있어, Prucalopride의 기존 적응증(장운동 저하)과의 병태생리학적 연관성이 존재합니다. 다만 관련 문헌은 질환 자체를 기술할 뿐 Prucalopride 치료 효과를 직접 다루지는 않았습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
TxGNN 예측 점수(99.82%)는 높지만, 저알파지단백혈증을 뒷받침하는 임상시험이나 문헌 근거가 전무하며, 평가 근거 자체가 기전상 타당성이 없다고 명시하고 있습니다. 또한 이 약물은 한국에 시판되지 않고 있으며, TFDA 수준의 경고·금기 정보(Blocking 등급 데이터 갭)도 미확보 상태로 안전성 초기 평가(S1) 진입이 불가능합니다.

**진행하려면 필요한 것:**
- 작용기전(MOA) 상세 데이터 확보 (DrugBank API 조회)
- 안전성 라벨 정보(경고/금기) 확보 — 현재 Blocking 등급 데이터 갭으로 안전성 평가 진입 자체가 불가
- 저알파지단백혈증 관련 예측을 진행하려면 전임상 기전 연구 또는 지질대사 경로와의 연결고리를 뒷받침하는 문헌이 우선 필요
- 대안으로, 상대적으로 근거 수준이 높은 amyloidosis 관련 적응증(순위 6, 9위)에 대해 Prucalopride의 직접적 치료 효과를 다루는 문헌 및 사례 조사를 우선 검토할 것을 권장
