# Neratinib: HER2 양성 유방암에서 정상 유방형(Normal-like) 유방암 아형으로

## 한 문장 요약

Neratinib은 비가역적 pan-HER(EGFR/HER2/HER4) 티로신키나제 억제제로, HER2 양성 유방암 치료제로 알려져 있습니다(단, 본 Evidence Pack에는 공식 기존 적응증 데이터가 확보되지 않아 데이터 갭으로 표시되어 있습니다). TxGNN 모델은 **정상 유방형(Normal breast-like) 유방암 아형**에 효과가 있을 수 있다고 예측하지만, 현재 **1건의 소규모 Phase 2 임상시험**만 간접적으로 관련되어 있고 직접 문헌 근거는 없습니다.

## 이 예측이 타당한 이유는?

Neratinib은 HER2/EGFR 신호전달 경로를 표적으로 하는 비가역적 pan-HER 티로신키나제 억제제입니다. 다만 이 Evidence Pack 자체가 명시하듯, "정상 유방형(Normal-like)"은 PAM50 분자 아형 중 하나로 HER2 비증폭, 저악성도 조직 특성을 보이는 그룹이며, HER2/EGFR 억제제인 neratinib이 이 아형에 직접 작용해야 할 기전적 근거는 약한 편입니다.

현재 확보된 임상시험(NCT01670877)의 대상 집단은 "HER2 mutant, HER2 non-amplified 전이성 유방암"으로, 정상 유방형 아형과 개념적으로는 겹치는 부분이 있으나 PAM50 분류 기준으로 정확히 대응하는 시험은 아닙니다. 즉 이 예측은 TxGNN 지식그래프상의 간접적 연관성에 기반하며, 기전적 타당성은 제한적입니다.
