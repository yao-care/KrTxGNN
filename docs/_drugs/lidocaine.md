# Lidocaine: 적응증 미상에서 점상 상피성 각결막염(Punctate Epithelial Keratoconjunctivitis)으로

## 한 문장 요약

Lidocaine(리도카인)은 국소마취제 계열 약물로 널리 알려져 있으나, 본 Evidence Pack에는 기존 적응증과 작용기전(MOA) 데이터가 확보되지 않았습니다. TxGNN 모델은 **점상 상피성 각결막염(Punctate Epithelial Keratoconjunctivitis)**에 효과가 있을 수 있다고 예측했으며(예측 점수 **99.99%**), 그러나 이를 뒷받침하는 **임상시험 0건, 문헌 0편**으로 현재로서는 근거가 전혀 없는 순수 모델 예측 단계입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 정보 없음 (Evidence Pack 미확보) |
| 예측 신규 적응증 | 점상 상피성 각결막염 (Punctate Epithelial Keratoconjunctivitis) |
| TxGNN 예측 점수 | 99.99% |
| 근거 수준 | L5 (모델 예측만 존재, 실제 연구 없음) |
| 한국 시판 현황 | 시판되지 않음 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용기전(MOA) 데이터가 확보되어 있지 않습니다. 또한 이번 Evidence Pack에는 Lidocaine의 기존 승인 적응증 정보도 포함되어 있지 않아, 기존 적응증과 신규 예측 적응증 간의 연관성을 판단할 근거가 없습니다.

TxGNN이 산출한 예측 점수는 매우 높지만(99.99%, rank 640), 이를 뒷받침하는 임상시험이나 문헌이 전혀 검색되지 않았습니다. 즉, 이 예측은 지식그래프 상의 패턴 매칭에만 의존한 결과이며, 기전적·임상적 타당성을 검증할 수 있는 근거가 아직 존재하지 않습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 한국 시판 정보

현재 한국 내 허가 정보가 없습니다 (시판되지 않음, 허가증 0건).

**사유:**
