# Methoxy Polyethylene Glycol-Epoetin Beta: 신장병성 빈혈에서 일차 혈소판 방출 장애로

## 한 문장 요약

Methoxy polyethylene glycol-epoetin beta(제품명 미쎄라, Mircera)는 지속형 적혈구 생성 촉진제(ESA)로, 원래 만성 신장병에 동반된 빈혈 치료에 사용되었습니다.
TxGNN 모델은 **일차 혈소판 방출 장애(primary release disorder of platelets)**에 효과가 있을 수 있다고 예측하지만, 현재 이를 뒷받침하는 **임상시험은 0건**, **문헌도 0편**입니다. 모델 예측만 존재하는 단계입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 만성 신장병에 동반된 빈혈 (한국 허가증에는 허가사항 문서 링크만 확인되며, 적응증 본문은 이 보고서에 수록된 데이터에 없습니다) |
| 예측 신규 적응증 | 일차 혈소판 방출 장애 (primary release disorder of platelets) |
| TxGNN 예측 점수 | 99.36% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 9건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면 이 약은 에리스로포이에틴 수용체에 작용하는 지속형 ESA이며, 만성 신장병 빈혈에서의 효능이 확립되어 있습니다.

그러나 ESA의 작용이 혈소판 과립 방출 결함을 교정한다고 볼 만한 기전적 근거는 확인되지 않습니다. 높은 TxGNN 점수는 지식 그래프상의 연결 관계를 반영한 계산상 예측일 뿐, 생물학적 타당성이 입증된 것은 아닙니다.

또한 ESA는 혈전 위험과 연관되어 있어, 혈소판 기능 질환에 사용할 때 안전성 측면의 우려가 있습니다.

### 참고: 다른 예측 적응증

같은 예측 목록의 다른 질환들도 모두 L5이며 Hold로 평가되었습니다.

| 순위 | 예측 질환 | TxGNN 점수 | 평가 요약 |
|-----|---------|-----------|---------|
| 2 | Glanzmann 혈소판무력증 | 99.30% | 인테그린 αIIbβ3 결함은 EPO 수용체 작용으로 해결되지 않음 |
| 3 | 가성 폰빌레브란트병 | 99.25% | GPIbα 기능 획득 결함에 대한 ESA의 직접 효과 없음 |
| 4 | 중증 비증식성 당뇨망막병증 | 99.15% | 망막 생물학에서 EPO 연구가 있어 가설은 있으나, 병적 신생혈관 촉진 우려가 있어 안전성 검토 필요 |
| 5 | 헤파린 보조인자 2 결핍 | 99.10% | 혈전 위험 악화 가능, 기전적 근거 없음 |
| 6 | 안티트롬빈 결핍 2형 | 99.07% | 혈전 위험 증가로 해로울 수 있음 |
| 7 | 제5인자 과다 및 자발성 혈전증 | 99.04% | 혈전색전증 우려로 치료보다 안전성 문제가 큼 |

## 안전성 고려사항

안전성 정보는 허가사항을 참조하세요.

참고로, 예측 근거 검토 과정에서 ESA 계열의 혈전색전증 위험과 당뇨망막병증에서의 주의 필요성이 지적되었습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
예측 점수는 높지만 임상시험과 문헌이 전혀 없고, 기전적 연결 고리도 확인되지 않습니다. ESA의 혈전 위험은 혈소판 기능 질환에서 오히려 안전성 우려가 됩니다.

**진행하려면 필요한 것:**
- 허가사항(MFDS)의 경고 및 금기 정보 확보 (안전성 선별 진행을 위한 필수 사항)
- 약물의 상세 작용 기전(MOA) 데이터 확보
- ESA 작용과 혈소판 방출 기능 간의 기전적 연관성을 보여주는 전임상 근거
- 혈전 위험에 대한 별도의 안전성 검토
- 상대적으로 가설이 있는 당뇨망막병증의 경우, 병적 신생혈관 촉진 위험을 포함한 전용 안전성 평가
