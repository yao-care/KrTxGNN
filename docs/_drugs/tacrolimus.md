# 타크로리무스(Tacrolimus): 장기이식 면역억제 및 아토피피부염에서 지루피부염으로

## 한 문장 요약

타크로리무스는 칼시뉴린 억제제로, 한국에서 경구·주사제(이식 면역억제)와 외용 연고제(아토피피부염)로 허가되어 사용되어 왔습니다. TxGNN 모델은 **지루피부염(Seborrheic Dermatitis)**에 효과가 있을 수 있다고 예측하며, 현재 **2건의 직접 관련 임상시험**(완료된 3상 1건 포함)과 **약 20편의 문헌**이 이 방향을 지지합니다.

> 참고: 이번 보고서에 취합된 허가 정보에는 적응증 원문이 링크로만 제공되어, 위 기존 적응증은 제품 유형(경구·주사·연고)과 일반적으로 알려진 허가 범위를 기준으로 정리했습니다. 정확한 허가 문구는 허가증 링크에서 확인해야 합니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가 적응증 원문은 링크로만 제공됨(경구·주사제는 이식 거부반응 억제, 연고제는 아토피피부염이 일반적인 허가 범위) |
| 예측 신규 적응증 | 지루피부염 (Seborrheic Dermatitis) |
| TxGNN 예측 점수 | 99.26% |
| 근거 수준 | L2 (완료된 3상 1건, 4상 1건. 3상이 1건뿐이라 L1 기준 미충족) |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 20건 (모두 유효, 단일제) |
| 권장 결정 | Proceed with Guardrails |

## 이 예측이 타당한 이유는?

타크로리무스는 칼시뉴린을 억제해 NFAT 의존적 T세포 활성화를 차단하고, IL-2, IFN-γ, TNF-α 같은 염증성 사이토카인의 분비를 줄입니다. 이 보고서에 취합된 데이터에는 약물 수준의 상세한 작용 기전 항목이 비어 있습니다. 위 기전은 예측 근거 분석에 기재된 내용과 알려진 약리 정보를 따랐습니다.

지루피부염은 *Malassezia* 효모에 대한 염증 반응과 피부 장벽 손상이 관여하는 만성 염증성 피부질환입니다. 외용 칼시뉴린 억제는 홍반, 인설, 소양감을 줄일 수 있다고 추정됩니다. *Malassezia*에 대한 일부 항진균 활성도 보고되어 있습니다. 같은 약물이 이미 아토피피부염 외용제로 허가되어 있어 약물의 피부 적용 경험이 축적되어 있습니다. 또한 높은 TxGNN 점수(99%)는 아래 임상시험 결과와 방향이 일치합니다.

## 안전성 고려사항

허가사항의 경고·금기 원문은 이번 보고서에 포함되지 않았으므로 허가사항을 직접 확인하세요. 아래는 지식그래프와 상호작용 데이터베이스에서 확인된 정보입니다.

- **지식그래프 기반 금기 관련 질환** (허가 문구가 아닌 모델 지식그래프의 약물-질환 연결): 고혈압, QT 연장 증후군, 심실빈맥(torsades de pointes), 간부전, 신장질환, 고혈당·당뇨병, 감염성 질환(단순포진, 대상포진 등), 암·림프종, 진행성 다초점 백질뇌병증, 후백질뇌병증 증후군, 간질 등
- **약물 상호작용**: 총 868건이 확인되었습니다. 주요(Major) 등급은 다음과 같습니다.
  - Amphotericin B (일반 제형 및 지질 복합체)
  - Loperamide
  - Mesalazine
  - Balsalazide
  - Omeprazole
- **중등도(Moderate) 상호작용 예**: 아카보스, 파모티딘, 라베프라졸, 하이드로코르티손, 메트포르민, 피오글리타존, 덱사메타손, 메트로니다졸, 부데소니드

외용 연고제는 전신 흡수가 적지만, 암 위험에 대한 경고(boxed warning)가 있습니다. 최근 메타분석에서는 암 위험이 낮게 보고되었습니다([36370744](https://pubmed.ncbi.nlm.nih.gov/36370744/), 2023).

## 결론 및 다음 단계

**결정: Proceed with Guardrails**

**사유:**
성인 안면 지루피부염에서 타크로리무스 연고를 평가한 완료된 3상(n=120)과 4상(n=104) 시험이 있고, 외용 제형이 한국에서 이미 시판 중입니다. 다만 3상이 1건뿐이고 대규모 위약대조 결과가 확인되지 않아 근거는 L2 수준입니다.

**진행하려면 필요한 것:**
- 완료된 두 시험(NCT02004860, NCT01591070)의 결과 데이터를 확인하고, 이를 바탕으로 검증용 3상 RCT 필요 여부를 판단
- 허가사항(경고, 금기, 적응증 원문)을 확인해 안전성 검토 완료
- 외용 사용 시 장기 안전성 모니터링 계획(악성종양 경고 반영), 감염 피부 사용 제한, 자외선 차단 지침 수립
- 한국 허가 연고제(0.03%, 0.1%)를 지루피부염에 적용할 때의 용량·사용 기간 근거 정리
- 허가 외 사용에 해당하는 적응증 확대 추진 시 규제 경로 검토
