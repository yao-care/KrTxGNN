# Darolutamide: 전이성 전립선암에서 동형접합 가족성 고콜레스테롤혈증으로

## 한 문장 요약

Darolutamide는 비스테로이드성 안드로겐 수용체 길항제로, 한국에서 전립선암 치료제로 허가·시판되고 있습니다.
TxGNN 모델은 **동형접합 가족성 고콜레스테롤혈증(Homozygous Familial Hypercholesterolemia)**에 효과가 있을 수 있다고 예측하지만, 이를 뒷받침하는 **임상시험은 0건, 문헌도 0편**입니다.
모델 예측만 존재하는 단계이므로 현재로서는 보류를 권장합니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가증에 적응증 원문이 링크 형태로만 제공되어 구체적인 문구를 확인할 수 없음 (안드로겐 수용체 길항제로서 전립선암 영역에 사용) |
| 예측 신규 적응증 | 동형접합 가족성 고콜레스테롤혈증 (Homozygous Familial Hypercholesterolemia) |
| TxGNN 예측 점수 | 99.11% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 1건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면 Darolutamide는 비스테로이드성 안드로겐 수용체 길항제이며, 전립선암 치료 영역에서 사용되는 약물입니다.

반면 동형접합 가족성 고콜레스테롤혈증은 LDL 수용체 경로의 결함으로 발생하는 유전성 질환입니다. 안드로겐 수용체 차단과 이 질환의 병태생리 사이에서 타당한 기전적 연결고리는 확인되지 않았습니다.

따라서 높은 예측 점수는 지식 그래프 기반의 네트워크 예측 결과일 뿐이며, 임상적·문헌적 뒷받침이 없습니다. 기전상 적용 가능하다고 보기 어렵습니다.

## 안전성 고려사항

- **약물 상호작용**: 총 100건의 상호작용이 기록되어 있으며, 그중 주요(Major) 등급은 다음과 같습니다.
  - Dexamethasone
  - Eluxadoline
  - Rosuvastatin

  중등도(Moderate) 등급에는 Clarithromycin, Empagliflozin, Glyburide, Repaglinide, Simvastatin, Sulfasalazine, Cobicistat, Deferasirox, Eltrombopag 등이 포함됩니다. 특히 고콜레스테롤혈증 치료에 쓰이는 스타틴계(Rosuvastatin, Simvastatin)와의 상호작용이 있어, 이 방향으로 검토할 경우 실제적인 우려 사항이 됩니다.

주요 경고와 금기 정보는 허가사항을 참조하세요.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
예측 점수는 높지만(99.11%) 임상시험과 문헌 근거가 없고 기전적 연결고리도 확인되지 않아 L5 수준에 머뭅니다. 게다가 스타틴계와의 주요 상호작용이 보고되어 있어 이 적응증으로 진행할 근거가 부족합니다.

**진행하려면 필요한 것:**
- 안드로겐 수용체 신호와 LDL 수용체 경로 간 연관성을 보여주는 전임상·기전 연구
- 허가사항(경고·금기) 확인 및 안전성 검토
- 상세한 약물 작용 기전(MOA) 데이터 확보
