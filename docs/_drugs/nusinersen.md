# Nusinersen: 척수성 근위축증(SMA)에서 고알도스테론증으로

## 한 문장 요약

Nusinersen은 SMN2 유전자의 스플라이싱을 표적으로 하는 척수강내(intrathecal) 투여 안티센스 올리고뉴클레오티드로, 일반적으로 척수성 근위축증(SMA) 치료에 사용되는 약물로 알려져 있습니다(단, 본 Evidence Pack에는 공식 원 적응증 자료가 기재되어 있지 않습니다).
TxGNN 모델은 **고알도스테론증(Hyperaldosteronism)**에 효과가 있을 수 있다고 예측했으나, 예측 점수는 **50%(모델 판정 임계값)**, 전체 순위는 약 **203만 위**로 사실상 하위권이며, 이를 지지하는 임상시험과 문헌은 **각각 0건**입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 정보 없음 (한국 미시판, 원 적응증 미기재 — 기전 설명상 SMA 치료제로 알려짐) |
| 예측 신규 적응증 | 고알도스테론증 (Hyperaldosteronism) |
| TxGNN 예측 점수 | 50% (모델 판정 임계값, 예측적 의미 낮음) |
| 근거 수준 | L5 (모델 예측만 존재, 실증 연구 없음) |
| 한국 시판 현황 | 미시판 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 Nusinersen의 상세 작용기전(MOA) 데이터는 확보되지 않았습니다. 알려진 정보에 따르면 Nusinersen은 SMN2 유전자 스플라이싱을 조절하는 척수강내 투여 안티센스 올리고뉴클레오티드(ASO) 계열 약물입니다.

예측된 신규 적응증인 고알도스테론증은 RAAS(레닌-안지오텐신-알도스테론) 계 및 부신피질 알도스테론 분비 조절과 관련된 질환으로, SMN2 스플라이싱 조절 기전과 분자경로상 알려진 중첩점이 없습니다. Evidence Pack의 자체 기전 분석에서도 "TxGNN score 0.5는 모델의 판정 임계값으로, 예측적 의미를 갖지 않는다"고 명시하고 있어, 이 예측을 뒷받침할 기전적 근거는 현재로선 확인되지 않습니다.

또한 이번에 제시된 10개 예측 적응증 전부가 동일하게 score 0.5, 근거 수준 L5, 권장 Hold로 산정되어 있으며, 대부분(고알도스테론증, 안구구더기증, 신세포암 아형 다수, 갈락토오스혈증, 비염, 저칼륨혈증, 혈관육종 등)이 SMN2 스플라이싱 조절과 생물학적 연관성이 낮다고 스스로 평가하고 있습니다. 이는 지식그래프상의 통계적 노이즈에 가까울 가능성을 시사하며, 추가 실험적 검증 없이는 기전적 타당성을 인정하기 어렵습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 한국 시판 정보

이 약물은 현재 한국에서 시판되지 않으며(미시판), 등록된 허가 정보가 없습니다.

## 안전성 고려사항

안전성 정보(주요 경고, 금기, 약물 상호작용)는 현재 확보되지 않았습니다. 특히 허가사항/사용상 주의사항 데이터는 **차단(Blocking) 등급 결손**으로 분류되어 있어, 안전성 초기평가(S1) 단계 자체를 진행할 수 없는 상태입니다. 한국 미시판 약물이므로, 진행 시 해외(FDA/EMA) 공식 라벨 확인이 선행되어야 합니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
- 예측된 10개 적응증 모두 TxGNN score 0.5(모델 임계값)·근거 수준 L5(모델 예측만 존재)에 머물러 있으며, 이를 뒷받침하는 임상시험·문헌 등 실증 근거가 전무합니다.
- 안전성 데이터 결손(차단 등급)으로 인해 안전성 초기평가(S1)조차 진행할 수 없습니다.
- 작용기전(MOA) 데이터 결손(High 등급)으로 기전적 타당성을 판단할 근거가 부족합니다.
- 한국 내 시판 이력이 없어(허가 0건) 현지 시판·규제 데이터를 통한 교차검증도 불가능합니다.

**진행하려면 필요한 것:**
- Nusinersen의 공식 작용기전(MOA) 및 원 적응증 자료 확보 (DrugBank API 재조회 또는 해외 규제기관 라벨 참조)
- 허가사항 수준의 안전성 정보(경고, 금기, DDI) 확보 — 한국 미시판 약물이므로 FDA/EMA 라벨 우선 검토 필요
- 고알도스테론증을 포함한 예측 적응증에 대한 전임상/기전 연구 존재 여부 재검색(현재 검색 결과 전부 0건)
- TxGNN score가 0.5(임계값)에 근접한 예측은 통계적으로 유의하지 않을 가능성이 높으므로, 상위 순위(고신뢰도) 예측 후보로 재스코어링 후 재평가 권장
