# Mephenesin: 적응증 미상에서 전이성 흑색종으로

## 한 문장 요약

Mephenesin은 한국(대만)에서 시판되지 않은 약물로, 기존 적응증 및 작용기전(MOA) 정보가 현재 확보되지 않았습니다.
TxGNN 모델은 **전이성 흑색종(Metastatic Melanoma)**에 효과가 있을 수 있다고 예측했지만,
관련 임상시험과 문헌이 **0건**으로 이를 뒷받침할 실제 근거는 없습니다.

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터가 없습니다. Mephenesin은 한국에서 시판 이력이 없고 기존 적응증 기록도 확인되지 않아, 전이성 흑색종과의 기전적 연관성을 판단할 근거 자체가 존재하지 않습니다.

또한 상위 10개 예측 적응증을 살펴보면, "melanoma" 계열 질환(전이성 흑색종, 비피부성 흑색종, 상피양세포 흑색종, 안검 흑색종)과 "cataract" 계열 질환(미숙 백내장, 당뇨병성 백내장, 성숙 백내장 등)이 각각 거의 동일한 점수로 군집을 이루고 있습니다. 특히 백내장 관련 5개 항목은 소수점까지 완전히 동일한 점수(0.9547017216682434)를 보이는데, 이는 개별 약리학적 근거보다는 지식그래프 임베딩 상 특정 질환 노드군에 대한 전반적 편향(embedding artifact)일 가능성을 시사합니다. 따라서 이번 예측은 기전적 타당성보다는 모델 산출값 자체로만 해석해야 합니다.
