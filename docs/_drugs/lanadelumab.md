# Lanadelumab: 유전성 혈관부종에서 C1 억제제 결핍증으로

## 한 문장 요약

Lanadelumab은 혈장 칼리크레인(plasma kallikrein)을 억제하는 단클론항체로, 유전성 혈관부종(HAE) 발작 예방에 사용되어 왔습니다.
TxGNN 모델은 **C1 억제제 결핍증(C1 inhibitor deficiency)**에 효과가 있을 수 있다고 예측하며, 현재 **5건의 임상시험**과 **20편의 문헌**이 이 방향을 지지합니다.
다만 C1 억제제 결핍증은 HAE의 원인 질환이므로, 이 예측은 새로운 적응증이라기보다 이미 승인된 핵심 적응증과 사실상 같은 영역입니다.

## 빠른 개요

| 항목 | 내용 |

| 기존 적응증 | 허가증에 적응증 원문 대신 MFDS 문서 링크만 수록되어 있어 구체적 문구 확인 불가 (유전성 혈관부종 발작 예방으로 알려져 있음) |

| TxGNN 예측 점수 | 99.996% |
| 근거 수준 | L1 (데이터 기준 판정, 아래 참고) |
| 한국 시판 현황 | ✓ 시판 중 |

| 권장 결정 | Proceed with Guardrails |

> **근거 수준 참고:** 완료된 Phase 3 시험은 3건(NCT05460325, NCT04070326, NCT04180163)이나 모두 소규모 단일군 공개 시험입니다. 무작위 대조 시험(RCT)으로는 JAMA 2018 HELP 연구가 있어 L1로 판정되었지만, 엄밀히는 RCT 기준의 L1보다 근거 설계가 약한 부분이 있습니다.

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터는 수집되지 않았습니다. 다만 알려진 정보에 따르면 Lanadelumab은 혈장 칼리크레인(KLKB1)을 표적으로 하는 완전 인간 단클론항체입니다. C1 억제제 결핍(SERPING1 변이)이 있으면 혈장 칼리크레인 활성이 조절되지 않아 브래디키닌이 과다 생성되고, 이것이 혈관부종 발작을 일으킵니다.

따라서 칼리크레인을 직접 억제하면 이 경로를 차단할 수 있어 기전상 타당합니다. 앞서 언급한 대로 이는 이미 승인된 핵심 적응증(HAE 예방)이므로 엄밀한 의미의 약물 재창출은 아닙니다.

## 안전성 고려사항

- **약물 상호작용**: 약리학 데이터상 표적인 칼리크레인 B1(KLKB1)과의 상호작용만 확인되었으며, 이는 약물의 작용 표적을 의미합니다. 병용 약물과의 임상적 상호작용 수준은 제시되지 않았습니다.

그 외 경고 및 금기 정보는 허가사항을 참조하세요.

## 결론 및 다음 단계

**결정: Proceed with Guardrails**

**사유:**
C1 억제제 결핍(HAE)에서 Lanadelumab은 RCT(HELP), 공개 연장 시험, 3건의 완료된 Phase 3 시험, 다수의 실사용 연구로 효능과 안전성이 뒷받침됩니다. 다만 이는 이미 승인된 핵심 적응증이므로 재창출이라기보다 기존 적응증의 재확인이며, 한국 허가 문구와 안전성 정보가 확인되지 않았습니다.

**진행하려면 필요한 것:**
- MFDS 허가사항 PDF에서 허가 적응증, 경고, 금기 내용 확인
- DrugBank 등에서 작용 기전(MOA) 데이터 보완
- 한국 허가 연령(예: 12세 이상 여부)과 소아 근거(SPRING 등) 간 적용 범위 확인

> **참고:** 예측 순위 2~10위(serpinopathy, 췌장염, 가성 폰빌레브란트병, 혈소판 분비 장애 등)는 임상시험과 문헌 근거가 없는 모델 예측 단계(L5)이며, 기전상 연관성도 약하거나 불분명하여 모두 보류(Hold)로 판정됩니다.
