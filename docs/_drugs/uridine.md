# Uridine: 미승인 물질에서 Actinic Cheilitis(광선구순염)로

## 한 문장 요약

Uridine(DrugBank ID: DB02745)은 한국에 허가된 제품이 없고 알려진 승인 적응증도 확인되지 않는 핵산 계열 물질입니다.
TxGNN 모델은 **Actinic Cheilitis(광선구순염)**에 효과가 있을 수 있다고 예측(점수 98.63%)하지만,
현재 이를 뒷받침하는 **임상시험이나 문헌 근거는 전혀 없습니다**.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 확인된 승인 적응증 없음 |
| 예측 신규 적응증 | Actinic Cheilitis (광선구순염) |
| TxGNN 예측 점수 | 98.63% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✗ 미상영 (한국 미허가) |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 Uridine의 상세한 작용기전(MOA) 데이터와 기존 승인 적응증 정보가 모두 확보되지 않았습니다.
TxGNN 그래프 신경망이 산출한 예측 점수(98.63%)만 존재할 뿐, uridine과 actinic cheilitis 사이의 연관성을 뒷받침하는 기전 문헌이나 임상 근거는 확인되지 않습니다.

참고로 동일 Evidence Pack 내 다른 예측 적응증 중에는 uridine이 P2Y 퓨린 수용체를 통해 각막 상피 재생을 돕는다는 전임상·초기 임상 근거(dry eye syndrome, 근거수준 L3)나, uridine phosphorylase 효소가 종양 예후와 관련된다는 기전 문헌(squamous cell carcinoma, 근거수준 L4)이 존재합니다. 그러나 이번 보고서의 대상인 actinic cheilitis는 그러한 뒷받침이 전혀 없는 순수 모델 예측 단계입니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 안전성 고려사항

안전성 정보가 수집되지 않았습니다. TFDA/KFDA 등 규제기관의 경고·금기 문서가 아직 확보되지 않아(약물상호작용 조회 결과도 없음) 안전성 초기평가(S1) 단계에 진입할 수 없는 상태입니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
Actinic cheilitis 적응증은 TxGNN 예측 점수 외에 임상시험, 문헌, 기전적 근거가 전혀 없는 L5 단계이며, 안전성 평가에 필요한 규제 문서(경고/금기)조차 확보되지 않아 다음 단계로 진행할 근거가 부족합니다.

**진행하려면 필요한 것:**
- TFDA(또는 KFDA) 허가사항(경고·금기) 확보 — 안전성 초기평가(S1) 진입 필수 조건
- Uridine의 작용기전(MOA) 데이터 확보
- Actinic cheilitis에 대한 기전 연구 또는 임상 데이터 신규 축적
- (참고) 동일 후보 약물의 다른 예측 적응증 중 **dry eye syndrome**(근거수준 L3)과 **squamous cell carcinoma**(근거수준 L4)이 상대적으로 근거가 풍부하여 우선 검토 대상으로 고려할 가치가 있음
