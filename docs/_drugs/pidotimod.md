# Pidotimod: 적응증 정보 없음에서 골관절염(Osteoarthritis)으로

## 한 문장 요약

Pidotimod은 면역조절제로 알려져 있으나, 현재 확보된 자료에는 기존 승인 적응증과 작용기전(MOA) 정보가 없습니다.
TxGNN 모델은 **골관절염(Osteoarthritis)**에 효과가 있을 수 있다고 예측했으나(예측 점수 98.56%),
이를 뒷받침하는 임상시험이나 문헌은 **0건**이며, 모델 자체 분석에서도 "기전상 근거가 약하고 임베딩 유사성에 의한 잡음(noise) 가능성"이 지적되었습니다.

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 확보된 자료에 따르면 Pidotimod은 면역조절제(immunomodulator) 계열로 분류되지만, 구체적인 MOA와 기존 승인 적응증 정보는 확인되지 않았습니다.

모델이 제시한 기전 가설(`repurposing_rationale.mechanistic_link`)에 따르면, 골관절염은 주로 기계적·퇴행성 관절 질환으로 전형적인 면역 매개 질환이 아닙니다. 저강도 활막염(synovitis) 성분에서 간접적 연관 가능성이 언급되나, 이를 뒷받침하는 직접적 기전 증거는 없으며, TxGNN 임베딩 유사성에 의한 잡음(noise) 예측일 가능성이 높다고 평가되었습니다.

순위 2~10위 예측 적응증(골관절염 감수성, 류마티스 관절염, 간성 포르피린증, 가성연골무형성증 등)도 동일하게 임상 근거가 전무하며, 모델 자체 분석에서 대부분 "기전 관련성 없음" 또는 "구조적 위양성 가능성"으로 평가되었습니다. 특히 류마티스 관절염의 경우, Pidotimod의 면역 **증강** 기전이 RA 치료에 필요한 면역 **억제/하향조절** 방향과 반대되어 기전 논리가 약합니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
- 예측 신규 적응증(골관절염)을 뒷받침하는 임상시험 및 문헌 근거가 전무하며(근거 수준 L5), 모델 자체 평가에서도 기전 잡음(noise) 가능성이 지적되었습니다.
- 약물의 MOA, 기존 적응증, 안전성 경고/금기 정보가 모두 확보되지 않아 S1 안전성 초평가 자체가 불가능한 상태입니다.
- 한국 내 시판 이력이 없어(미상장, 허가증 0건) 현지 규제·안전성 참고 자료도 없습니다.
- 순위 2~10위 예측 적응증 역시 동일하게 근거가 없고, 다수가 기전상 무관하거나 구조적 위양성으로 판단되어 이번 배치 전체에서 우선 진행할 후보가 없습니다.

**진행하려면 필요한 것:**
- TFDA(또는 해당 규제기관) 공식 허가사항의 경고/금기 자료 확보 (DG001, Blocking)
- DrugBank 등에서 상세 작용기전(MOA) 확보 (DG002, High)
- 골관절염 관련 전임상 또는 초기 임상 근거 확보 — 현재는 모델 예측 외 실제 연구가 전혀 없음
- 기존 승인 적응증 데이터 확보를 통한 기전적 연관성 재검증
