# Zinc Oxide: 기저 적응증에서 여드름(Acne)으로

## 한 문장 요약

산화아연(Zinc Oxide)은 한국에서 주로 외용 연고·크림 및 아연 보충용 정제로 허가되어 있습니다.
TxGNN 모델은 **여드름(acne)**에 효과가 있을 수 있다고 예측하지만, 현재 등록된 **임상시험은 0건**이며 간접적으로 관련된 **문헌 3편**만 확인되었습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 임신 및 수유기, 발육기, 노년기의 비타민 D 보급; 뼈나 이의 발육불량, 구루병 예방; 셀레늄·아연 보급 (정제 허가 기준) |
| 예측 신규 적응증 | 여드름 (Acne) |
| TxGNN 예측 점수 | 99.86% |
| 근거 수준 | L4 (전임상·기전 수준의 간접 근거) |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 5건 |
| 권장 결정 | Hold (추가 연구 질문 단계) |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면, 산화아연은 외용 피부 보호제와 아연 보충제로 사용되고 있으며, 아연 이온의 항염 작용이 여드름 염증과 관련될 수 있습니다.

아연 이온은 가벼운 항염 효과가 있고 피지 관련 염증을 줄일 수 있습니다. 또한 산화아연 입자는 활성산소종 생성과 세포막 손상을 통해 여드름균(*Cutibacterium acnes*)에 대한 항균 활성을 보입니다. 국소 및 경구 여드름 치료 요법에 아연이 사용되기도 하여 생물학적 개연성은 있습니다.

다만 확인된 문헌은 간접적으로만 관련되어 있고, 산화아연의 여드름 사용을 직접 뒷받침하는 등록 임상시험은 없습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
TxGNN 점수는 매우 높지만(99.86%), 임상시험 등록이 없고 문헌도 간접 근거에 그칩니다. 현재는 연구 질문 단계(L4)로 보는 것이 적절합니다. 나머지 예측 적응증(항문 협착, 항문 용종, 유두성 결막염, 감염 후 혈관염)은 모델 예측만 있는 L5 수준이며 기전적 연관성도 확인되지 않았습니다.

**진행하려면 필요한 것:**
- 허가사항의 경고·금기 정보 확보 (허가증 PDF 확인)
- 상세한 작용 기전(MOA) 데이터 확보
- 여드름에 대한 산화아연 외용제의 직접적인 임상 근거 (무작위 대조시험 등) 검토
- 수출용 허가 제품이 많으므로 국내 사용 가능한 제형·경로 적합성 확인
