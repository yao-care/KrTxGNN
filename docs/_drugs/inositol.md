# Inositol: 기존 허가 적응증에서 원발성 문맥 혈전증으로

## 한 문장 요약

Inositol(DrugBank DB13178)은 한국에서 연질캡슐 제제로 허가되어 있지만, 이번 보고서용으로 정리된 데이터에는 허가 적응증 본문이 없고 허가사항 문서 링크만 있습니다.
TxGNN 모델은 **원발성 문맥 혈전증(Primitive Portal Vein Thrombosis)**에 효과가 있을 수 있다고 예측하며, 예측 점수는 99.98%입니다.
다만 이 질환을 직접 뒷받침하는 **임상시험은 0건, 문헌도 0편**이어서 현재는 모델 예측 단계(L5)입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가 적응증 본문 미확인 (허가사항 문서 링크만 제공됨) |
| 예측 신규 적응증 | 원발성 문맥 혈전증 (Primitive Portal Vein Thrombosis) |
| TxGNN 예측 점수 | 99.98% (모델 내 순위 878위) |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✓ 시판 중 (단, 확인된 허가 제품은 수출용) |
| 허가증 수 | 1건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 이 보고서용으로 정리된 자료에서는 Inositol의 기존 적응증과 기전을 확인할 수 없어, 기존 적응증과 문맥 혈전증 사이의 기전적 연결고리를 제시할 수 없습니다.

이 예측은 지식그래프 기반 계산 결과일 뿐입니다. 문맥 혈전증 외에도 가족성 비경변성 문맥압항진증, 간문맥 경화증, 간폐증후군 등 간·문맥 혈관 질환 여러 개가 정확히 같은 점수(0.99980)를 받았습니다. 이는 질환별 근거라기보다 그래프상 공통 신호를 반영했을 가능성이 높습니다. 따라서 점수가 높다는 사실만으로 실제 효능을 추정해서는 안 됩니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 안전성 고려사항

허가사항의 경고·금기 정보와 약물 상호작용 데이터는 확보되지 않았으므로 허가사항을 참조하세요.

**지식그래프 기반 금기 질환 (허가사항이 아닌 모델 지식그래프의 약물-질환 금기 연결 정보)**

문맥 혈전증은 혈전성 질환이므로 아래 항목은 특히 주의 깊게 검토해야 합니다.
- **혈전·혈관 관련**: 혈액응고 질환, 혈소판감소증, 급성 관상동맥 증후군, 관상동맥 질환, 관상동맥 혈전증, 심근경색, 뇌졸중, 뇌혈관 질환, 뇌경색, 뇌동맥 폐색, 뇌간 경색, 저혈압성 질환
- **간·담낭·소화기**: 간 질환, 담낭 질환, 소화성 궤양
- **대사·기타**: 고혈당, 당뇨병, 당뇨병성 케토산증, 통풍, 저인산혈증, 혈색소병증, 물질 남용/의존

이 목록은 라벨 근거가 아니라 지식그래프에서 추출한 것이므로, 실제 허가사항과 대조해 확인해야 합니다.

## 참고: 다른 예측 적응증의 근거 현황

1위 예측 적응증은 근거가 전혀 없지만, 하위 예측 중에는 간접 근거가 있는 것이 있습니다. 모두 임상시험은 없고 Inositol 자체의 치료 효과를 입증하지는 못합니다.

- **울혈성 심부전 (L4, 점수 99.44%)**: 혈장 myo-inositol 상승과 예후의 연관성을 보고한 코호트 연구(PMID 39121579)가 있습니다. 이는 바이오마커 연관성이며 치료 효과가 아닙니다. 나머지 문헌은 대부분 전임상 연구 또는 리뷰입니다.
- **고지질단백혈증 (L3, 점수 99.40%)**: 1976~1983년의 독일 임상 보고(PMID 6683558, 196436, 1253701, 203832)가 있습니다. 이 보고들은 clofibrate와 inositol nicotinate의 복합요법을 다루므로 Inositol 단독 효과를 분리할 수 없습니다. clofibrate는 현재 거의 쓰이지 않는 약물이며, nicotinate 에스테르의 niacin 유사 작용이 혼재되어 있습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
원발성 문맥 혈전증에 대해서는 임상시험과 문헌이 없고 기전 데이터도 없어, 모델 예측(L5)만 존재합니다. 지식그래프상 혈전·응고 관련 질환이 금기 후보로 나타난 점도 이 적응증에는 불리한 신호입니다.

**진행하려면 필요한 것:**
- 허가사항 PDF에서 적응증, 경고, 금기 정보 확보
- 작용 기전(MOA) 데이터 확보 (DrugBank 조회)
- 문맥 혈전증 및 간·문맥 질환에서 Inositol의 효과를 다룬 전임상·임상 문헌 검색
- 혈전·응고 관련 지식그래프 금기 항목의 실제 근거 확인
- 국내 처방용 제형 존재 여부와 투여 경로 적합성 확인 (현재 확인된 허가는 수출용)
