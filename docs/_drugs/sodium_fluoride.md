# Sodium Fluoride: 기존 적응증 미상에서 후두개염(Epiglottitis)으로

## 한 문장 요약

Sodium Fluoride(DrugBank ID: DB09325)는 원본 적응증과 작용기전(MOA) 정보가 현재 확인되지 않는 약물입니다.
TxGNN 모델은 **후두개염(Epiglottitis)**에 효과가 있을 수 있다고 예측(점수 99.92%)하지만,
이를 뒷받침하는 임상시험이나 문헌은 **0건**이며, 기전상 연결고리도 확인되지 않아 근거 수준이 매우 낮습니다(L5).

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 확인되지 않음 (자료 없음) |
| 예측 신규 적응증 | 후두개염 (Epiglottitis) |
| TxGNN 예측 점수 | 99.92% |
| 근거 수준 | L5 (모델 예측만 존재, 실제 연구 없음) |
| 한국 시판 현황 | ✗ 미시판 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

Sodium Fluoride의 작용기전(MOA) 데이터는 현재 확보되지 않았으며, 기존 승인 적응증 정보도 존재하지 않습니다.
이 때문에 예측된 신규 적응증과의 기전적 연관성을 평가할 근거 자체가 부족합니다.

Evidence Pack에 포함된 기전 분석(repurposing_rationale)에 따르면, 후두개염은 주로 *H. influenzae* 등 세균 감염에 의해 발생하는데, 불화나트륨(Sodium Fluoride)은 항균/항염 기전이 알려져 있지 않아 생물학적 개연성이 없다고 명시되어 있습니다. 이는 TxGNN의 지식그래프(KG) 임베딩 기반 고득점이 **위양성(false positive)일 가능성**을 시사합니다.

동일한 패턴이 예측 순위 2~6위(요로감염, Ureaplasma 요도염, 임질성 요도염, 자궁염증질환, 황색육아종성 신우신염)에서도 반복되며, 모두 근거 수준 L5·Hold 판정입니다. 7위 후두염(laryngitis)의 경우 문헌은 검색되었으나, 실제로는 18F-NaF PET 골스캔 조영제 관련 영상의학 증례·독성학 연구로, 치료적 근거와는 무관합니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 한국 시판 정보

현재 한국 내 시판 허가가 없습니다 (총 허가 건수: 0건).

## 안전성 고려사항

본 약물의 경고사항, 금기, 약물상호작용 정보가 모두 확인되지 않았습니다. 이는 Evidence Pack에서 **차단(Blocking) 등급의 자료 공백**으로 분류되어 있으며, 안전성 초기 평가(S1) 진입 자체가 불가능한 상태입니다. 진행 전 원 제조국 또는 참조국의 정식 라벨(허가사항)을 확보해 확인해야 합니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
- 예측 신규 적응증(후두개염)에 대한 임상시험·문헌 근거가 전무하며, 근거 수준 L5(모델 예측만 존재)에 해당합니다.
- 기전 분석 결과 생물학적 개연성이 없으며, TxGNN 고득점이 KG 임베딩 위양성일 가능성이 명시적으로 제기되었습니다.
- 약물 MOA 및 안전성 라벨 정보가 모두 자료 공백(Data Gap) 상태이며, 안전성 라벨 부재는 차단(Blocking) 등급입니다.
- 상위 7개 예측 적응증 모두 동일하게 Hold 권고이며, 유의미한 재창출 후보로 보기 어렵습니다.

**진행하려면 필요한 것:**
- TFDA(또는 원 제조국 규제기관) 공식 허가사항/라벨 확보 (경고·금기·DDI) — 차단 항목(DG001)
- DrugBank API 등을 통한 Sodium Fluoride 작용기전(MOA) 확인 — High 우선순위(DG002)
- 후두개염 및 기타 예측 적응증에 대한 최소 전임상/기전 연구 확보 (현재 L4 이상 근거 없음)
- 위 자료 공백 해소 전까지 추가 개발 자원 투입 보류 권고
