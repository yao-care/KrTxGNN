## Oxiracetam: 인지기능 개선제에서 불면증으로
{: .text-alpha }

## 한 문장 요약

Oxiracetam은 라세탐(racetam) 계열 약물로, 한국에서 수출용 단일제 정제로 허가되어 있습니다. TxGNN 모델은 **불면증(Insomnia)**에 효과가 있을 수 있다고 예측하지만, 이를 직접 뒷받침하는 임상시험은 **0건**이며 관련 문헌도 **1편**(불면증 환자의 동반 질환과 약물 사용에 대한 실사용 분석)에 그칩니다. 현재는 모델 예측 단계의 가설입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가 적응증 텍스트를 확인할 수 없음 (허가증에 PDF 링크만 있음) |
| 예측 신규 적응증 | 불면증 (Insomnia) |
| TxGNN 예측 점수 | 0.9986 |
| 근거 수준 | L5 |
| 한국 시판 현황 | Unknown (source lacks cancellation status) |
| 허가증 수 | 2건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. Oxiracetam은 인지기능 개선(nootropic) 목적의 라세탐 계열 약물로 알려져 있으며, 콜린성 및 글루타메이트 신경전달 조절과 관련된다고 일반적으로 설명됩니다. 다만 이는 이번에 정리된 데이터로 확인된 내용이 아닙니다.

불면증과의 기전적 연결은 현재 데이터로는 성립하지 않습니다. 오히려 라세탐 계열은 각성·자극 효과가 보고되기도 해서, 수면 개선과 반대 방향으로 작용할 가능성도 배제할 수 없습니다. 이 예측의 유일한 근거는 TxGNN 모델(딥러닝)의 높은 점수이며, 이 점수는 모델이 관련 질환 간에 학습한 유사성을 반영할 수 있을 뿐 생물학적 근거는 아닙니다. 실험적·임상적 검증은 없습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
불면증에 대한 근거는 모델 예측 점수뿐이며, 임상시험이 없고 문헌도 약물 효능과 직접 관련이 없습니다. 작용 기전 데이터가 없고 라세탐 계열의 각성 효과 가능성이 있어, 현 단계에서는 진행을 권장하기 어렵습니다.

**진행하려면 필요한 것:**
- 허가사항(허가증 PDF)에서 기존 적응증, 경고, 금기 정보 확인
- 작용 기전(MOA) 데이터 확보 및 수면 조절과의 기전적 연결 분석
- Oxiracetam과 수면·불면증 관련 전임상 또는 임상 연구 문헌 탐색
- 수출용 허가 품목이므로 국내 사용 가능성과 제형·투여 경로 적합성 검토
