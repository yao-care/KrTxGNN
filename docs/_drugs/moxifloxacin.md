# Moxifloxacin: 세균 감염증에서 다클론성 과점도 증후군(Polyclonal Hyperviscosity Syndrome)으로

## 한 문장 요약

Moxifloxacin은 여러 근거 텍스트에서 fluoroquinolone계 항균제로 언급되는 약물이나, 한국(대만 규제 데이터 기준)에는 등재된 허가 정보가 없습니다.
TxGNN 모델은 **다클론성 과점도 증후군(Polyclonal Hyperviscosity Syndrome)**에 효과가 있을 것으로 예측했지만(예측 점수 99.98%), 이를 뒷받침하는 임상시험이나 문헌은 **전혀 없으며**, 근거 텍스트 자체가 "기전상 지지 근거 없음, 순수 예측 점수에 불과"함을 명시하고 있습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 자료 없음 (한국 허가 정보 없음, DrugBank 원 적응증 미기재) |
| 예측 신규 적응증 | Polyclonal Hyperviscosity Syndrome (다클론성 과점도 증후군) |
| TxGNN 예측 점수 | 99.98% |
| 근거 수준 | L5 (모델 예측만 존재, 실제 연구 없음) |
| 한국 시판 현황 | 미출시 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터가 없습니다(데이터 갭, 심각도: High). 다만 근거 팩 내 다른 예측 항목들의 서술을 보면 moxifloxacin은 fluoroquinolone계 항균제로 반복적으로 언급되고 있습니다.

그러나 이번 1순위 예측(다클론성 과점도 증후군)에 대해서는 근거 텍스트가 다음과 같이 명확히 밝히고 있습니다:

> "無任何臨床證據，無機轉支持抗菌藥治療高黏滯血症候群，純屬 TxGNN 預測分數，未經驗證。"
> (임상 근거 전무, 항균제가 과점도 증후군을 치료할 기전적 근거 없음, 순수 TxGNN 예측 점수에 불과하며 검증되지 않음)

즉 이 예측은 지식그래프 상의 통계적 연관성만을 반영할 뿐, 약리학적으로 타당성을 뒷받침할 기전이 확인되지 않았습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 한국 시판 정보

한국에 등재된 허가 정보가 없습니다 (미출시, 허가증 0건).

## 안전성 고려사항

안전성 정보는 허가사항을 참조하세요. (주요 경고, 금기, DDI 모두 데이터 갭 — DDI 조회 결과 없음)

※ 참고: TFDA 첨부문서/경고·금기 정보 확보는 이 평가에서 "Blocking" 등급 데이터 갭으로 분류되어 있어, 안전성 초기 평가(S1) 단계 진입이 현재 불가능한 상태입니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
1순위 예측(다클론성 과점도 증후군)은 임상시험·문헌 근거가 전무하고, 근거 텍스트 자체가 기전적 타당성을 부정하고 있습니다(L5, 모델 예측만 존재). 또한 한국 시판 정보와 MOA, 안전성 데이터가 모두 결여되어 있어 임상적 판단을 내릴 근거가 없습니다.

**진행하려면 필요한 것:**
- TFDA(규제기관) 첨부문서 확보 및 경고·금기사항 파싱 (Blocking 등급 데이터 갭, S1 안전성 초평 진입 전제조건)
- DrugBank API 조회를 통한 작용기전(MOA) 데이터 확보 (High 등급 데이터 갭)
- 다클론성 과점도 증후군에 대한 최소한의 전임상/기전 연구 확보 — 현재는 전무
- **참고**: 동일 예측 목록 내 10순위 **선페스트(bubonic plague)** 항목은 L3 근거 수준(전임상 동물모델·PK/PD 연구 6편, "Research Question" 단계)과 명확한 기전적 타당성(fluoroquinolone의 DNA gyrase 억제 → *Yersinia pestis* 살균, 동일 계열 약물의 기허가 사례)을 갖추고 있어, 별도 평가 대상으로 우선 검토할 가치가 있습니다.
