# 니모디핀: 적응증 정보 미기재 상태에서 동형접합 가족성 고콜레스테롤혈증으로

## 한 문장 요약

현재 확보된 근거 자료(Evidence Pack)에는 니모디핀(DB00393)의 기존 승인 적응증과 작용기전(MOA) 정보가 기록되어 있지 않습니다. TxGNN 모델은 **동형접합 가족성 고콜레스테롤혈증(Homozygous Familial Hypercholesterolemia)**에 효과가 있을 수 있다고 예측(점수 99.29%)하지만, 현재 이를 뒷받침하는 **임상시험 0건, 문헌 0건**으로 순수 모델 예측 단계에 머물러 있습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 자료에 기재된 정보 없음 |
| 예측 신규 적응증 | 동형접합 가족성 고콜레스테롤혈증 (Homozygous Familial Hypercholesterolemia) |
| TxGNN 예측 점수 | 99.29% (전체 순위 11,124위) |
| 근거 수준 | L5 (모델 예측만 있음, 임상시험/문헌 없음) |
| 한국 시판 현황 | 미출시 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

> 참고: TxGNN은 두 번째 후보로 **신장성 항이뇨 부적절 증후군(Nephrogenic SIAD)**에도 99.05%의 예측 점수(순위 13,860위)를 부여했으나, 이 역시 임상시험·문헌 근거가 전혀 없어 본 보고서와 동일하게 L5 단계입니다.

## 이 예측이 타당한 이유는?

현재 니모디핀의 상세 작용기전(MOA) 데이터와 기존 승인 적응증 데이터가 모두 확보되지 않았습니다(DrugBank 조회 결과 미기재). 이 때문에 동형접합 가족성 고콜레스테롤혈증과의 기전적 연관성이나 기존 적응증과의 유사성을 현재 자료만으로는 설명할 수 없으며, 예측은 TxGNN의 지식그래프 기반 점수(99.29%)에만 의존하고 있는 상태입니다.

기전 근거를 보강하려면 DrugBank API 재조회 또는 원문 라벨 확인을 통해 MOA와 기존 적응증을 우선 확보해야 예측의 타당성을 평가할 수 있습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 한국 시판 정보

현재 한국에서 시판 중인 허가 제품이 없습니다 (미출시, 허가증 0건).

## 안전성 고려사항

안전성 정보는 허가사항을 참조하세요. (약물상호작용 조회 결과도 등록된 내역이 없습니다.)

## 결론 및 다음 단계

**결정: Hold**

**사유:**
작용기전, 기존 적응증, 임상시험, 문헌 근거가 모두 확보되지 않았고 한국에 시판 중인 제품도 없어, 현재로서는 재창출 가능성을 평가할 최소한의 근거조차 부족합니다. TxGNN 예측 점수만으로 다음 단계 진행을 결정하기에는 이릅니다.

**진행하려면 필요한 것:**
- 니모디핀의 작용기전(MOA) 및 기존 승인 적응증 데이터 확보 (DrugBank 재조회)
- 식약처(MFDS) 허가사항 및 안전성 경고·금기사항 확보 (현재 Blocking 등급 데이터 갭)
- 동형접합 가족성 고콜레스테롤혈증 관련 전임상·기전 연구 문헌 탐색 확대
- 두 번째 후보 적응증(NSIAD)에 대한 병행 검토 여부 결정
