# Budesonide: 알레르기·기도 염증 질환에서 아토피 피부염으로

## 한 문장 요약

Budesonide는 한국에서 비강 분무제와 흡입제 형태로 허가된 글루코코르티코이드 계열 약물입니다. TxGNN 모델은 **아토피 피부염(atopic eczema)**에 효과가 있을 수 있다고 예측하지만, 현재 이를 직접 뒷받침하는 **임상시험은 0건**이며, 직접 관련된 문헌도 전임상 제형 연구 1편에 그칩니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가 적응증 원문 텍스트는 확인되지 않음 (허가증은 7건이며, 비강 분무제와 흡입제로 시판 중) |
| 예측 신규 적응증 | 아토피 피부염 (Atopic Eczema) |
| TxGNN 예측 점수 | 99.96% |
| 근거 수준 | L4 (전임상·기전 수준) |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 7건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면 budesonide는 강력한 글루코코르티코이드로, Th2 사이토카인과 호산구·비만세포 활성을 억제하는 광범위한 항염증·면역억제 작용을 가집니다. 이 약은 한국에서 비염, 천식·COPD 등 점막 염증 질환에 사용됩니다.

아토피 피부염도 Th2 중심의 알레르기성 염증 질환이므로, 기전상으로는 적용 가능성이 있습니다. 다만 국소 코르티코스테로이드는 이미 이 질환의 표준 치료로 확립되어 있고, budesonide 고유의 임상 근거는 없습니다. 높은 TxGNN 점수는 모델 예측일 뿐 임상적 검증이 아닙니다.

참고로 지식그래프에는 "dermatitis, atopic"(순위 3, 점수 99.81%)이 같은 질환의 동의어로 별도 등재되어 있으며, 근거가 중복 집계되지 않도록 하나로 합쳐 해석했습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

아토피 피부염과 직접 관련된 budesonide 문헌은 제한적이며, 대부분 접촉 감작이나 안전성에 관한 것입니다.

## 안전성 고려사항

- **약물 상호작용**: 상호작용 조회 결과 총 100건이 확인되었습니다. 주요(Major) 등급으로는 adalimumab, fosamprenavir가 있습니다. 중등도(Moderate) 등급에는 nifedipine, ibuprofen, ketorolac, fluvoxamine, ethinylestradiol, isotretinoin, aldesleukin, alemtuzumab 등이 포함됩니다. formoterol과 salbutamol은 경미(Minor) 등급입니다.
- **지식그래프 기반 금기 질환** (허가 문서가 아닌 예측 모델 데이터 기준): 고혈압, 간질, 간질환, 담낭질환, 고혈당, 홍역, 울혈성 심부전, 단순헤르페스 각막염, 뇌하수체 기능저하 관련 질환 등이 포함됩니다.
- **피부 적용 시 고려사항**: 코르티코스테로이드 접촉 감작, 소아에서의 성장 억제와 부신 억제 가능성이 문헌에서 보고되었습니다.

상세한 경고·금기는 허가사항을 참조하세요.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
아토피 피부염에 대한 budesonide 임상시험이 없고 직접 근거는 전임상 제형 연구뿐입니다. 국소 스테로이드가 이미 표준 치료로 확립되어 있어 budesonide만의 추가 가치도 불분명합니다.

**진행하려면 필요한 것:**
- 허가사항(경고·금기·적응증) 확보: 현재 허가 문서 내용이 확인되지 않아 안전성 1차 검토를 진행할 수 없음
- 작용 기전(MOA) 데이터 확보 (DrugBank 등)
- 한국 시판 제형이 비강·흡입제이므로 피부 외용제형 개발 가능성 검토
- 기존 국소 스테로이드 대비 budesonide의 차별성을 보여주는 비교 임상 근거

## 참고: 기타 예측 적응증

- **기관지염 (점수 99.81%, 근거 수준 L2, 연구 질문 단계)**: 기관지염 관련 임상시험 10건이 검색되었으나 다수가 연관성이 낮습니다. 의미 있는 시험은 budesonide/formoterol의 이식 후 세기관지염(Phase 2, 각 32명) 등이며, 소규모·비통제 설계, 복합제, 질환 실체가 서로 다르다는 한계가 있습니다. 호산구성 기관지염에서 흡입 budesonide의 효과를 보고한 문헌(PMID 10780759)이 있으나, COPD 메타분석에서는 폐렴 위험 등 안전성 문제가 제기되었습니다. 아토피 피부염보다 근거가 강하므로 적응증을 정밀하게 정의한 후속 평가를 권장합니다.
- **비강·부비동 폴립 관련 예측 (중이 용종, 전두동 용종)**: 만성 부비동염 비용종 연구에서 간접적 근거만 있으며 해당 부위에 특이적인 자료는 없습니다.
- **성대 용종, 상피종(epulis), 섬유상피성 용종, 자궁 용종, 외이도 용종**: 모델 예측만 있고 지지 근거가 없습니다.
