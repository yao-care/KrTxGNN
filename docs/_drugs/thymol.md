# Thymol: 기존 적응증 정보 불명에서 심실중격 동맥류로

## 한 문장 요약

Thymol은 백리향(thyme) 정유의 주성분인 모노터펜 페놀 화합물로, 한국에서는 외용 겔 제품으로 허가되어 있습니다.
TxGNN 모델은 **심실중격 동맥류(interventricular septum aneurysm)**에 효과가 있을 수 있다고 예측하지만, 이 예측을 지지하는 **임상시험은 0건, 직접 관련 문헌도 0편**입니다.
현재로서는 모델 예측만 존재하는 단계입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가 적응증 텍스트가 링크로만 제공되어 구체적인 내용을 확인할 수 없음 |
| 예측 신규 적응증 | 심실중격 동맥류 (interventricular septum aneurysm) |
| TxGNN 예측 점수 | 99.25% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 1건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. Thymol은 항균, 항산화, 항염 활성을 가진 것으로 알려진 모노터펜 페놀이지만, 이러한 약리 특성이 심장의 구조적 결손과 연결된다는 근거는 확인되지 않았습니다.

심실중격 동맥류는 구조적 심장 질환이며, 기존 적응증과의 연관성도 평가할 수 없습니다. 이 예측 점수는 TxGNN 지식 그래프 기반의 계산적 추론에서 나온 것으로, 기전상 타당성을 뒷받침하는 별도의 근거가 없습니다.

참고로 상위 10개 예측(폐동맥판 질환, Laubry-Pezzi 증후군, Pierre Robin 증후군, 구순구개열 증후군, 염색체 결실 질환 등)도 대부분 선천성·유전성 구조 질환이며, 소분자 페놀 화합물이 교정하기 어려운 영역입니다. 이는 예측 전반의 신뢰도를 낮추는 요소입니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

참고: 순위 8번 예측(fucoglycosan 합성 장애)에서는 thymol 관련 문헌 20편이 검색되었으나, 대부분 thymol/백리향에 대한 일반 리뷰와 전임상 연구였고 해당 질환과는 관련이 없어 약물명 기준으로 검색된 것으로 보입니다. 1순위 예측인 심실중격 동맥류와도 무관하므로 근거로 인정하지 않았습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
임상시험과 직접 관련된 문헌이 없고 기전적 연결고리도 확인되지 않아, 근거 수준은 L5(모델 예측만 존재)입니다. 해당 허가 제품은 외용 겔이며 수출용으로 허가되어, 심장 구조 질환에 적용할 수 있는 투여 경로와도 맞지 않습니다.

**진행하려면 필요한 것:**
- 허가사항(허가 적응증, 경고, 금기)의 확보 및 분석
- 작용 기전(MOA) 데이터 확보
- 심실중격 동맥류와 thymol 사이의 기전적·전임상 근거
- 투여 경로 적합성 평가(현재 외용제형만 확인됨)
