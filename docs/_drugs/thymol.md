# Thymol: 미승인 성분에서 심실중격동맥류로

## 한 문장 요약

Thymol은 백리향(Thymus vulgaris) 등에서 추출되는 천연 페놀 화합물로, 한국에서는 현재 허가받은 의약품으로 시판되지 않으며 공식 작용기전(MOA) 자료도 확인되지 않습니다.
TxGNN 모델은 **심실중격동맥류(Interventricular Septum Aneurysm)**에 효과가 있을 것으로 예측했으나, 이를 포함한 상위 10개 예측 적응증 전부가 **근거 수준 L5(모델 예측만 존재, 실제 임상·문헌 근거 없음)**에 해당합니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 없음 (한국 내 미시판, 공식 승인 적응증 확인 안 됨) |
| 예측 신규 적응증 | 심실중격동맥류 (Interventricular Septum Aneurysm) |
| TxGNN 예측 점수 | 99.25% |
| 근거 수준 | L5 |
| 한국 시판 현황 | 미시판 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 DrugBank 등록 정보에 공식적인 작용기전(MOA) 데이터가 없습니다. 다만 참고 문헌에 따르면 thymol은 백리향 정유의 주요 성분인 페놀계 모노테르펜으로, 항균·항산화·항염 작용이 보고되어 있습니다(PMID [29785774](https://pubmed.ncbi.nlm.nih.gov/29785774/)).

그러나 1순위 예측인 심실중격동맥류는 선천성 또는 후천성 심장 구조 결함으로, thymol의 알려진 약리작용(항균·항산화·항염)과 병태생리학적 연관성을 찾기 어렵습니다. 평가 데이터 자체도 "구조적 심장 결함으로 thymol의 기전과 무관"이라고 명시하고 있어, 이 예측은 지식그래프 임베딩상의 노이즈일 가능성이 높습니다.

실제로 상위 10개 예측 적응증(심실중격동맥류, 폐동맥판 질환, Laubry-Pezzi 증후군, Pierre Robin 증후군, 구순구개열 증후군, 22번 염색체 장완 부분결실, 7번 염색체 장완 부분결실, Jeune 증후군 등)은 대부분 **선천성 구조 이상 또는 염색체·유전 증후군**으로, 소분자 약물의 약리학적 개입으로 교정 가능한 병태가 아니라는 공통점이 있습니다. 유일하게 문헌이 검색된 8순위 예측(당원당(fucoglycosan) 합성장애)도 검토 결과, 검색된 20편의 문헌이 항산화·항균·항콜린에스테라아제·자궁내막증·패혈증 등 일반적인 thymol 연구일 뿐 해당 희귀질환과는 무관한 **키워드 오매칭(위양성)**으로 판단됩니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 안전성 고려사항

현재 안전성 자료(주요 경고, 금기, 약물 상호작용)가 확인되지 않습니다. 한국 내 시판 허가가 없어 참조할 공식 첨부문서도 없습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
1순위 예측인 심실중격동맥류를 포함해 상위 10개 예측 적응증 모두 근거 수준 L5(모델 예측만 존재)에 머물러 있으며, 대부분 구조적·유전적 질환으로 thymol의 알려진 약리기전과 병태생리학적 연관성이 없습니다. 유일하게 문헌이 발견된 8순위 예측조차 키워드 오매칭에 의한 위양성으로 확인되어, 현재 근거로는 재창출 후보로 진행할 수 없습니다.

**진행하려면 필요한 것:**
- 식약처 수준의 공식 첨부문서(경고·금기 정보) 확보 — Blocking gap (DG001)
- DrugBank 등 공식 MOA 데이터 확보 — High severity gap (DG002)
- 한국 내 실제 시판/허가 현황 재확인
- 재평가 시 KG 임베딩 노이즈 가능성이 낮은 다른 후보 적응증(항균·항산화·항염 기전과 실제 연관된 질환군) 우선 탐색 필요
