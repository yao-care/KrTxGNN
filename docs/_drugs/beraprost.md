# Beraprost: 순환기계 질환에서 선천성 심장질환 동반 폐동맥 고혈압으로

## 한 문장 요약

Beraprost는 경구용 프로스타사이클린 유사체로, 한국에서 단일제 정제로 허가·시판되고 있습니다.
TxGNN 모델은 **선천성 심장질환 동반 폐동맥 고혈압(PAH-CHD)**에 효과가 있을 수 있다고 예측하며, 현재 **1건의 임상시험**과 **9편의 문헌**이 이 방향을 지지합니다.
다만 근거는 소규모 연구 위주이며 Phase 3 RCT는 없습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가 적응증 원문이 문서 링크로만 제공되어 구체적인 적응증 텍스트는 확인되지 않음 |
| 예측 신규 적응증 | 선천성 심장질환 동반 폐동맥 고혈압 (pulmonary arterial hypertension associated with congenital heart disease) |
| TxGNN 예측 점수 | 97.99% |
| 근거 수준 | L3 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 5건 |
| 권장 결정 | Hold (추가 연구 필요 과제로 분류) |

> 참고: 이 보고서는 예측 점수 1위(폐동맥 동정맥 기형)가 아니라, 근거가 가장 충분한 2위 후보를 중심으로 작성했습니다. 1위 후보는 임상시험과 문헌이 없고 기전상 근거도 불분명합니다. 후보별 평가는 마지막 부분에 정리했습니다.

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면 Beraprost는 경구 프로스타사이클린(IP 수용체) 작용제로, 폐혈관 확장, 혈소판 응집 억제, 평활근 증식 억제 작용을 가집니다.

이러한 작용은 폐동맥 고혈압(PAH)의 병태생리를 직접 겨냥합니다. PAH-CHD는 PAH의 하위군이므로 기전상 적용 가능성이 있습니다. 또한 Beraprost는 일부 지역에서 이미 PAH 치료에 사용되고 있어, 이 예측은 새로운 질환이라기보다 기존 사용 영역 안의 하위군에 가깝습니다.

다만 CHD 하위군에 대한 근거는 소규모 연구에 국한됩니다. 이 보고서에서는 한국 허가 적응증 원문을 확인할 수 없어, 한국 허가 범위와의 일치 여부는 별도 확인이 필요합니다.

## 안전성 고려사항

안전성 정보는 허가사항을 참조하세요.

참고로, 다른 후보 질환 중 유전성 출혈성 모세혈관확장증(HHT)과 폐동맥 동정맥 기형은 Beraprost의 항혈소판·혈관확장 작용이 출혈이나 우-좌 단락을 악화시킬 가능성이 이론적으로 제기됩니다.

## 결론 및 다음 단계

**결정: Hold (추가 연구 필요 과제로 분류)**

**사유:**
PAH-CHD에 대한 근거는 완료된 소규모 Phase 4 시험 1건(결과 미제공)과 소규모 코호트·증례 연구뿐이며, 완료된 Phase 3 RCT가 없습니다. 기전은 타당하지만 안전성 정보와 허가 적응증 원문을 확인하지 못해 진행 여부를 판단하기에 근거가 부족합니다.

**진행하려면 필요한 것:**
- 허가사항(경고·금기)과 허가 적응증 원문 확보 (현재 안전성 검토를 진행할 수 없는 차단 수준의 데이터 공백)
- 상세한 작용 기전(MOA) 데이터
- NCT03431649의 결과 데이터 확인
- PAH-CHD 하위군에 대한 대조 임상시험 근거 확보
