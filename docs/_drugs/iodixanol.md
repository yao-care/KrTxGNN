# Iodixanol: 조영제(CT 조영촬영)에서 골관절염 감수성(Osteoarthritis Susceptibility)으로

## 한 문장 요약

Iodixanol은 원래 치료 목적이 아닌 CT/혈관조영술에 사용되는 비이온성 요오드화 조영제입니다.
TxGNN 모델은 **골관절염 감수성(Osteoarthritis Susceptibility)**에 효과가 있을 수 있다고 예측하지만,
이를 뒷받침하는 임상시험이나 문헌은 **0건**으로, 순수 그래프 예측 점수에만 의존하고 있습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 조영제(CT/혈관조영용) — 공식 허가 적응증 데이터 없음 |
| 예측 신규 적응증 | 골관절염 감수성 (Osteoarthritis Susceptibility) |
| TxGNN 예측 점수 | 99.16% |
| 근거 수준 | L5 (모델 예측만 있음, 실제 연구 없음) |
| 한국(관할) 시판 현황 | 미시판 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 Iodixanol의 상세 작용기전(MOA) 데이터는 확보되지 않았습니다(Data Gap, 심각도 High). 다만 근거 자료에 따르면 Iodixanol은 비이온성 요오드화 조영제로, 알려진 약리학적 표적이나 치료적 MOA가 없으며 CT/혈관조영 영상 촬영 시 조영 효과만을 목적으로 사용됩니다.

예측 1순위인 "골관절염 감수성"에는 뒷받침하는 임상시험이나 문헌이 전혀 없습니다. 평가 근거에 따르면 이 고득점 예측은 "조영제를 이용해 골관절 영상을 관찰한 연구"들과의 그래프 공존 패턴에서 비롯된 위양성(false positive)일 가능성이 높다고 명시되어 있습니다.

참고로 상위 10개 예측 적응증을 모두 검토한 결과, 2순위 "osteoarthritis"에 관한 문헌 7편이 확인되었으나 전부 조영제를 연골/연골하골 영상 연구의 도구로 사용한 방법론 논문이며, Iodixanol을 골관절염 치료 목적으로 사용한 근거는 아닙니다. 3~4순위(류마티스 관절염, 혈색소병증) 역시 조영제 부작용·영상 품질 관련 논문일 뿐 치료적 근거가 아니며, 5~10순위는 문헌·시험이 전무한 희귀 골격이형성증으로 그래프 예측 잡음(noise)으로 판단됩니다. 즉 상위 10개 예측 전체가 치료적 재창출 근거로는 성립하지 않습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 한국(관할) 시판 정보

현재 미시판 상태이며, 등록된 허가증이 없습니다(허가증 0건).

## 결론 및 다음 단계

**결정: Hold**

**사유:**
1순위 예측 적응증(골관절염 감수성)은 임상시험·문헌 근거가 전무하며, 근거 수준 L5(순수 모델 예측)입니다. 상위 10개 예측을 모두 검토해도 치료적 재창출을 뒷받침하는 실질적 근거가 없고, 오히려 조영제 영상 연구와의 그래프 공존에 의한 위양성 패턴으로 평가됩니다.

**진행하려면 필요한 것:**
- TFDA(또는 해당 관할 규제기관) 첨부문서의 경고·금기 정보 확보 (DG001, Blocking — S1 안전성 초평가 진입 전제조건)
- Iodixanol의 작용기전(MOA) 데이터 확보 (DG002, High)
- 골관절염과의 실제 기전적 연관성을 뒷받침하는 전임상/임상 근거 신규 확보 (현재는 없음)
- 위 데이터 갭이 해소되기 전까지는 다음 평가 단계(S1)로 진행 보류 권고
