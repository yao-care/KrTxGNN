# 폴리에틸렌글리콜: 만성 변비에서 선천성 어린선양 홍피증으로

## 한 문장 요약

폴리에틸렌글리콜(PEG)은 장 내 수분을 유지해 변을 부드럽게 하는 삼투성 완하제로, 원래 **변비** 치료에 사용되었습니다.
TxGNN 모델은 **선천성 어린선양 홍피증(Congenital Ichthyosiform Erythroderma)**에 효과가 있을 수 있다고 예측하지만, 현재 이를 뒷받침하는 **임상시험은 0건, 문헌도 0편**으로 모델 예측만 존재하는 단계입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 소아의 변비 증상 치료 |
| 예측 신규 적응증 | 선천성 어린선양 홍피증 (Congenital Ichthyosiform Erythroderma) |
| TxGNN 예측 점수 | 99.03% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 20건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면 PEG는 장에서 거의 흡수되지 않고, 장 내강에 수분을 붙잡아 두는 방식으로 국소적으로 작용하는 삼투성 완하제입니다. 한국에서 허가된 적응증은 모두 변비 관련입니다.

선천성 어린선양 홍피증은 표피 각질화 과정의 유전질환(TGM1, ALOX12B, ALOXE3, ABCA12 등의 변이)으로, 피부 장벽 기능이 손상되어 있습니다. 이 질환과 PEG 사이에는 **확립된 기전적 연관성이 없습니다.** 높은 예측 점수(0.990)는 지식 그래프 기반의 계산 결과일 뿐입니다.

PEG가 외용 기제나 보습제 기반 성분으로 쓰일 가능성을 추측해 볼 수는 있습니다. 그러나 이는 제공된 근거로 뒷받침되지 않으며, 전신 약물 재창출과는 성격이 다릅니다.

## 안전성 고려사항

안전성 정보는 허가사항을 참조하세요.

참고로, 지식 그래프에는 다음과 같은 질환이 금기 관계로 연결되어 있습니다(허가 문서에서 확인된 내용이 아니므로 참고용): 장폐색, 장 폐쇄, 마비성 장폐쇄, 독성 거대결장, 충수염, 유문 협착, 신장 질환, 무뇨, 울혈성 심부전, 당뇨병성 케톤산증 등.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
선천성 어린선양 홍피증에 대한 임상시험과 문헌이 전혀 없고, PEG의 국소 장관 작용 기전과 이 피부 질환 사이에 기전적 연결고리도 확인되지 않습니다. 근거 수준은 L5(모델 예측만 존재)입니다.

**진행하려면 필요한 것:**
- 작용 기전(MOA) 데이터 확보 및 피부 각질화 장애와의 기전적 연관성 검토
- 관련 전임상 연구, 임상시험, 문헌 탐색
- 투여 경로 적합성 평가 (현재 경구 제형만 시판되며, 피부질환에는 외용 등 다른 경로가 필요할 수 있음)
- 허가사항의 경고 및 금기 정보 확보
