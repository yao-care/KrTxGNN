## Digoxin: 심부전·심방세동에서 십이지장 폐쇄로
{: .text-alpha }

## 한 문장 요약

이 보고서에 사용된 데이터에는 디곡신의 기존 허가 적응증 문구가 담겨 있지 않고, 허가 문서 링크만 확인됩니다. TxGNN 모델은 **십이지장 폐쇄(Duodenal Obstruction)**에 효과가 있을 수 있다고 예측하지만, 이 질환을 직접 다룬 임상시험과 문헌은 **0건**입니다. 모델 예측만 있는 단계(L5)입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가 적응증 문구 확인 불가 (한국 허가 문서 링크만 확인됨) |
| 예측 신규 적응증 | 십이지장 폐쇄 |
| TxGNN 예측 점수 | 0.9970 |
| 근거 수준 | L5 |
| 한국 시판 현황 | 시판 중 (유효 허가 4건 / 전체 4건) |
| 허가증 수 | 4건 (유효 4건) |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 일반적으로 디곡신은 Na+/K+-ATPase를 억제하여 심근 수축력을 높이고 미주신경 작용을 나타내는 강심배당체로 알려져 있습니다. 다만 이는 이번에 정리된 데이터로 확인된 내용이 아니며, 이 작용이 기계적 십이지장 폐쇄의 완화와 연결된다는 근거는 어디에도 없습니다.

오히려 디곡신은 오심, 구토, 식욕부진 같은 위장관 이상반응을 일으킬 수 있어 증상을 악화시킬 가능성이 있습니다. 0.997이라는 높은 예측 점수는 모델 계산값일 뿐, 이를 뒷받침하는 임상시험이나 문헌이 없습니다.

참고로 TxGNN이 제시한 다른 후보(십이지장 궤양 0.9959, 십이지장위 역류 0.9953, 저알파지단백혈증 0.9920)도 모두 L5이며 기전적 연결 근거가 없습니다. 십이지장 궤양에서 검색된 문헌 1편(PMID 14664653)은 프로톤펌프억제제의 약리를 다룬 리뷰로, 디곡신과 무관해 근거로 인정하지 않습니다.

## 안전성 고려사항

허가사항의 경고·금기 정보는 이번 데이터에 포함되어 있지 않으므로 허가사항을 참조하세요.

- **지식 그래프상 금기 관계**: 지식 그래프(PrimeKG)에 금기로 기록된 질환은 신장 질환, 저칼륨증, 고칼슘혈증, 심근경색, 방실차단, 동기능부전증후군, 심실세동, 비대심근병증, 울프-파킨슨-화이트 증후군, 심근염, 갑상선기능저하증 등입니다. 이는 허가 문서의 금기 문구가 아닌 지식 그래프의 관계입니다.
- **약물 상호작용**: 100건이 조회되었습니다. 주요 항목은 다음과 같습니다.
  - 중등도: 아카보오스, 라베프라졸, 독시사이클린, 에피네프린, 하이드로코르티손, 메트포르민, 암포테리신 B, 부프로피온, 덱사메타손, 아스피린 등
  - 경미: 알비글루타이드, 아트로핀, 히오시아민, 글리코피로늄
- 치료역이 좁은 약물이므로 병용약 검토가 필요합니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
십이지장 폐쇄를 직접 다룬 임상시험과 문헌이 없고 기전적 연결도 확인되지 않아 모델 예측 단계(L5)에 머뭅니다. 위장관 이상반응 가능성과 좁은 치료역을 고려하면 현재로서는 진행 근거가 부족합니다.

**진행하려면 필요한 것:**
- 한국 허가 문서에서 허가 적응증, 경고, 금기 확인
- 디곡신의 작용 기전 데이터 확보 및 십이지장 폐쇄와의 기전 연결 분석
- 십이지장 폐쇄를 직접 다룬 전임상·임상 연구 탐색
- 시판 현황(취소 여부) 확인
