# Apixaban: 혈전·색전증 예방 치료제에서 편두통으로

## 한 문장 요약

Apixaban은 Xa 인자를 억제하는 경구 항응고제로, 한국에서 20건의 단일제 허가를 받아 시판 중입니다.
TxGNN 모델은 **편두통(migraine disorder)**에 효과가 있을 수 있다고 예측하지만(점수 99.02%), 직접적인 임상시험 근거는 없고 **증례 보고 위주의 문헌 3편**만 있으며 그마저도 서로 상반됩니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가증에 적응증 원문이 포함되어 있지 않아(허가 문서 링크만 확인됨) 확인할 수 없음 |
| 예측 신규 적응증 | 편두통 (Migraine disorder) |
| TxGNN 예측 점수 | 99.02% |
| 근거 수준 | L4 (직접 근거 없는 모델 예측 수준에 가까움) |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 20건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면 Apixaban은 Xa 인자 억제 계열의 단일제 항응고제이며, 혈전 관련 질환에서 효능이 확립되어 있습니다. 그러나 Xa 인자 억제가 편두통을 예방한다는 확립된 기전은 없습니다.

가설적 연결고리는 전조 편두통에 혈전색전증 또는 역설색전(예: 난원공 개존, 항인지질항체)이 관여할 수 있다는 점입니다. 다만 이는 추측 수준입니다. 관련 증례 보고는 서로 모순됩니다. 한 건은 Apixaban 시작 후 편두통이 악화되었고, 다른 한 건은 와파린에서는 호전되었으나 Apixaban에서는 호전되지 않았습니다. 따라서 모델의 높은 점수는 임상적 근거로 뒷받침되지 않습니다.

## 임상시험 근거

| 시험 번호 | 단계 | 상태 | 참여자 수 | 주요 발견 |
|---------|------|------|----------|---------|
| [NCT00562289](https://clinicaltrials.gov/study/NCT00562289) | Phase 3 | 완료 | 664 | 뇌졸중 재발 예방을 위한 난원공 개존 폐쇄술 vs 항응고제/항혈소판제 비교. 편두통이 연구 대상이 아니며 Apixaban이 특정 중재도 아니므로 편두통에 대한 직접 근거가 되지 않음 |

Phase 3 시험이지만 편두통과 직접 관련이 없어 근거 수준 상향(L1)에 사용할 수 없습니다.

## 안전성 고려사항

**약물 상호작용**: 데이터가 수집된 상호작용은 총 100건이며, 그중 주요(Major) 등급 항목은 다음과 같습니다.
- Acetylsalicylic acid (아스피린)
- Cobicistat
- Deferasirox
- Ibritumomab tiuxetan
- Tositumomab (I-131 포함)

중등도(Moderate) 등급 항목에는 Clarithromycin, Dexamethasone, Aprepitant, Miconazole, Clotrimazole 등이 포함됩니다. 그 외 경고 및 금기 정보는 허가사항을 참조하세요.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
편두통에 대한 근거는 서로 모순되는 증례 보고와 소규모 후향 연구뿐이며, 이 중 한 건은 Apixaban 투여 후 악화를 보고합니다. 확립된 기전도 없고 연결된 Phase 3 시험도 편두통과 무관하므로, 높은 모델 점수만으로는 진행하기 어렵습니다.

**진행하려면 필요한 것:**
- Apixaban의 상세한 작용 기전 데이터 및 편두통과의 기전적 연결 가설 검증
- 허가사항(경고·금기·적응증)의 확인 및 정리. 현재 안전성 선별 단계로 넘어갈 수 없는 상태
- 항인지질항체 양성 또는 난원공 개존 동반 편두통 등 특정 하위 집단에 대한 탐색적 전향 연구
- 편두통 악화 가능성을 다룬 안전성 신호 추가 평가

**참고(다른 예측 후보):** 같은 약물의 다른 예측 중 류마티스 관절염(전임상에서 JAK2/STAT3·MAPK 경로를 통한 항관절염 효과, L4)과 폐고혈압(혈전성 기전 가능성, L4)은 "연구 과제" 수준으로 평가되며, 둘 다 임상 근거는 아직 없습니다.
