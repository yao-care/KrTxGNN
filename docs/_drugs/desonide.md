# Desonide: 국소 코르티코스테로이드에서 아토피 습진으로

## 한 문장 요약

Desonide는 저역가 국소 코르티코스테roid로, 한국에서 크림과 로션 제형으로 시판되고 있습니다.
TxGNN 모델은 **아토피 습진(atopic eczema)**에 효과가 있을 수 있다고 예측하며, 현재 **6건의 임상시험**과 **20편의 문헌**이 이 방향을 지지합니다.
다만 아토피 피부염은 미국에서 이미 desonide 제품의 허가 적응증이어서, 새로운 재창출이라기보다 기존 적응증을 재확인하는 성격이 강합니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 한국 허가증에서 적응증 텍스트를 확인할 수 없음 (허가 정보가 링크로만 제공됨) |
| 예측 신규 적응증 | 아토피 습진 (Atopic Eczema) |
| TxGNN 예측 점수 | 99.96% |
| 근거 수준 | L1 (아래 참고) |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 16건 |
| 권장 결정 | Proceed with Guardrails |

> 근거 수준 참고: 완료된 Phase 3 임상시험이 2건(NCT03386032, NCT01467362)이지만, 둘 다 desonide가 시험 약물인지 확인되지 않았습니다. 직접 근거는 완료된 Phase 4 시험 1건과 무작위 대조시험 문헌들입니다. 따라서 L1은 엄격하게 적용하기보다 다소 낙관적인 판정이며, 보수적으로는 L2~L3 수준으로 볼 수 있습니다.

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터는 없습니다. 알려진 정보에 따르면 desonide는 글루코코르티코이드 수용체 작용제인 저역가(class VI) 국소 코르티코스테로이드입니다. 항염증 및 면역억제 작용으로 아토피 피부염의 사이토카인 매개 피부 염증을 억제합니다.

아토피 피부염은 저~중역가 국소 코르티코스테로이드가 치료의 기본이 되는 질환입니다. 특히 소아에서는 안전성이 중요한데, desonide는 저역가여서 어린 환자에게 적합합니다. 하이드로겔, 폼, 연고, 크림 등 여러 제형의 연구가 있으며, 미국에서는 이미 아토피 피부염 적응증으로 사용되고 있습니다. TxGNN의 높은 점수는 이러한 기존 약리 지식과 일치합니다.

한국 허가증의 기존 적응증은 텍스트가 아닌 링크로만 제공되어, 한국 허가 적응증과의 일치 여부는 이번 데이터로 직접 확인하지 못했습니다.

## 결론 및 다음 단계

**결정: Proceed with Guardrails**

**사유:**
아토피 피부염에서 desonide를 직접 평가한 Phase 4 시험과 여러 무작위 대조시험 문헌이 있고, 기전도 알려진 약리와 일치합니다. 다만 이는 이미 확립된 적응증의 확인에 가까우며, 한국 허가 적응증과의 일치 여부는 이번 데이터로 검증되지 않았습니다.

**진행하려면 필요한 것:**
- 한국 허가증 적응증 텍스트와 허가사항의 경고·금기 확인 (현재 링크로만 제공됨)
- 상세한 작용 기전 데이터 (MOA)
- 한국 허가 적응증에 아토피 피부염이 포함되는지 확인
- 소아 등 특정 인구집단에 대한 안전성 모니터링 계획 (장기 사용 시 피부 위축과 전신 흡수 포함)

**참고:** 2~10순위 예측(성대 폴립, 중이 폴립, 외이도 폴립, 전두동 폴립, 요관 폴립, 외음부 폴립, 섬유상피 폴립, 신생물성 폴립, 치은종)은 모두 임상시험과 문헌 근거가 없고(L5), 기전상 타당성도 낮아 **Hold**를 권고합니다.
