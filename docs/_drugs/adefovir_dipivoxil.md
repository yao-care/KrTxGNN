# 아데포비어 디피복실(Adefovir Dipivoxil): 만성 B형 간염에서 만성 C형 간염으로

## 한 문장 요약

아데포비어 디피복실은 원래 만성 B형 간염 치료에 사용되는 뉴클레오티드 유사체 항바이러스제입니다.
TxGNN 모델은 **만성 C형 간염(chronic hepatitis C virus infection)**에 효과가 있을 수 있다고 예측했지만, 이 예측을 직접 지지하는 **임상시험은 0건**입니다. 연결된 **10편의 문헌**도 모두 B형 간염 또는 바이러스성 간염 일반을 다루며, C형 간염에서 아데포비어를 평가한 문헌은 없습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 만성 B형 간염 (한국 허가 문서는 링크로만 제공되어 본문은 확인하지 못했으며, 이 항목은 문헌과 임상시험 정보를 근거로 기재) |
| 예측 신규 적응증 | 만성 C형 간염 (chronic hepatitis C virus infection) |
| TxGNN 예측 점수 | 99.97% |
| 근거 수준 | L5 (모델 예측만 있고 직접 근거 없음) |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 9건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 이 보고서용 자료에 없습니다. 알려진 정보에 따르면 아데포비어는 세포 안에서 활성형인 아데포비어 이인산으로 바뀌어 B형 간염 바이러스(HBV)의 DNA 중합효소(역전사효소)를 억제하고 바이러스 DNA 사슬 합성을 중단시킵니다.

그러나 C형 간염 바이러스(HCV)는 DNA 중간체 없이 RNA 의존성 RNA 중합효소로 복제하는 RNA 바이러스입니다. 따라서 아데포비어가 HCV에 활성을 가질 기전적 근거는 확인되지 않습니다. 예측 점수가 매우 높은 이유는 B형 간염과 C형 간염이 지식 그래프에서 '바이러스성 간염'이라는 맥락을 공유하기 때문으로 보이며, 실제 약리 연관성을 반영한 결과로 보기는 어렵습니다. C형 간염은 현재 직접작용항바이러스제(DAA)가 표준 치료입니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다. 이 적응증과 연결된 시험은 없으며, 같은 약물의 다른 예측 적응증에서 참조된 시험(HBV/HCV/HIV 3중 감염 대상 Phase 2, 중도 철회, 등록 0명)이 있을 뿐입니다.

## 안전성 고려사항

- **금기(지식 그래프 기반, 허가사항 본문 아님)**: 신장 질환, 화농성 요관(pyoureter), 비만 질환, 단일유전자 비만, 지방간 질환, 비알코올성 지방간염, 젖산산증이 연관 질환으로 표시되어 있습니다.
- **신독성**: HIV 대상 연구에서 고용량(120 mg)은 용량 제한 신독성을 보였고, B형 간염 장기 치료에서도 신기능과 인산염 모니터링이 필요합니다.
- **약물 상호작용**: 조회된 상호작용은 총 25건이며, 모두 중증도 등급은 '미상'입니다. 대표적으로 판토프라졸, 오메프라졸, 란소프라졸, 라베프라졸, 라니티딘, 파모티딘, 모르핀, 와파린, 헤파린, 이부프로펜, 프레드니솔론, 카나마이신, 메토클로프라미드, 리도카인, 염화칼륨, 락툴로오스 등이 있습니다.

허가사항의 경고·금기 본문은 이 보고서용 자료에 없으므로 허가사항을 직접 확인하세요.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
C형 간염에 대한 임상시험이 없고 문헌도 모두 B형 간염 중심이어서 근거 수준이 L5입니다. 아데포비어는 DNA 중합효소를 억제하는 약이라 RNA 바이러스인 HCV에 작용할 기전적 근거가 없고, 이미 효과가 입증된 DAA 치료제가 있어 재창출 필요성도 낮습니다.

**진행하려면 필요한 것:**
- HCV 복제체(replicon) 등 전임상 연구에서 아데포비어의 항HCV 활성 확인 (현재 이를 시사하는 자료 없음)
- 한국 허가사항 본문(적응증, 경고, 금기) 확보
- 작용 기전(MOA) 데이터 보완

참고로 같은 약물의 다른 예측 중 **B형 간염**은 Phase 3 시험이 여러 건 완료되어 근거 수준이 L1입니다. 다만 이는 기존 허가 적응증이므로 신규 재창출이 아닙니다.
