# Pembrolizumab: 원 적응증 정보 미확보에서 치은 섬유종증(Fibromatosis, Gingival)으로

## 한 문장 요약

Pembrolizumab은 DrugBank ID DB09037로 등록된 약물이나, 본 Evidence Pack에는 기존 적응증과 작용 기전(MOA) 정보가 확보되지 않았습니다.
TxGNN 모델은 **치은 섬유종증(Fibromatosis, Gingival)**에 효과가 있을 수 있다고 예측(점수 99.40%)하지만,
이를 뒷받침하는 **임상시험과 문헌이 단 한 건도 없으며**, 모델 자체의 기전 분석에서도 "생물학적 근거 없음"으로 판정되었습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 데이터 없음 (원 적응증·작용기전 정보 미확보 – Data Gap) |
| 예측 신규 적응증 | 치은 섬유종증 (Fibromatosis, Gingival) |
| TxGNN 예측 점수 | 99.40% |

| 한국 시판 현황 | 미상 (Not marketed) |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터와 기존 적응증 정보가 모두 확보되지 않았습니다(Data Gap DG001·DG002). 이로 인해 기존 적응증과 신규 적응증 간의 기전적 연관성을 분석할 근거 자체가 없습니다.

더 중요한 점은, 이 예측 자체의 `repurposing_rationale`에서 "치은 섬유종병은 양성 결합조직 증식 질환으로, PD-1/PD-L1 면역회피 기전과 관련이 없으며, 면역관문억제제 개입을 지지할 합리적인 생물학적 근거가 없다"고 명시하고 있습니다. 즉 모델의 예측 점수(99.40%)와 실제 기전적 타당성 평가가 서로 모순되는 상황이며, 이는 알고리즘상의 오탐(false positive)일 가능성이 높습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 한국 시판 정보

한국에 등록된 허가 제품이 없습니다 (시판 현황: 미상, 허가증 0건).

## 결론 및 다음 단계

**결정: Hold**

**사유:**
- 예측 1순위(치은 섬유종증)는 임상시험·문헌 근거가 전무(L5)하며, 모델 자체 기전 분석에서도 생물학적 타당성이 부정되었습니다.
- 약물의 MOA·기존 적응증·안전성(경고/금기) 정보가 모두 확보되지 않아 안전성 초기 평가(S1) 단계에 진입할 수 없습니다(DG001, Blocking).
- 한국에 미허가·미시판 상태입니다.

**진행하려면 필요한 것:**
- TFDA/식약처 원본 허가사항(경고·금기) 확보 및 파싱 (Blocking)
- DrugBank API를 통한 MOA 및 기존 적응증 데이터 보강
- 증거 수집 파이프라인 재검토: 이번 배치의 10개 후보 중 다수(순위 2, 6, 9, 10)에서 질환명과 무관한 문헌이 매칭되는 오류가 확인되어, 검색 로직(질환명 기반이 아닌 약물명 기반 과매칭) 점검이 필요합니다.
- 참고로 순위 4(폐문암, lung hilum carcinoma)만 L4/Research Question 단계에 도달했으나, 관련 문헌 2건은 효능이 아닌 이상반응(뇌하수체저하증, 초진행) 사례 보고로, 이 역시 별도의 효능 근거 확보가 필요합니다.
