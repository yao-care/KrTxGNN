# Remdesivir: 원 적응증 미상에서 다발성 내분비 신생물로

## 한 문장 요약

Remdesivir(레미데시비르)는 Evidence Pack상 원 적응증과 작용기전(MOA) 정보가 확보되지 않은 상태입니다.
TxGNN 모델은 **다발성 내분비 신생물(Multiple Endocrine Neoplasia)**에 효과가 있을 수 있다고 예측했으나(**예측 점수 99.50%**),
이를 뒷받침하는 **임상시험 0건, 문헌 0편**으로 근거가 전혀 없으며, 자체 기전 분석에서도 **생물학적 연관성이 없는 모델 노이즈(위양성)**로 판정되었습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 정보 없음 (Evidence Pack에 원 적응증 데이터 미확보) |
| 예측 신규 적응증 | 다발성 내분비 신생물 (Multiple Endocrine Neoplasia) |
| TxGNN 예측 점수 | 99.50% |
| 근거 수준 | L5 |
| 한국 시판 현황 | 미판매 (미상 등재 없음) |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 확보되지 않았습니다(DrugBank 조회 결과 [Data Gap]). Remdesivir는 일반적으로 아데노신 뉴클레오타이드 유사체로 바이러스 RNA 의존성 RNA 중합효소(RdRp)를 억제하여 RNA 바이러스 복제를 저해하는 항바이러스제로 알려져 있습니다.

반면 다발성 내분비 신생물(MEN)은 *RET* 또는 *MEN1* 유전자 돌연변이로 발생하는 유전성 내분비 종양 증후군으로, 항바이러스 기전과는 생물학적 연관성이 없습니다. 실제로 이 예측에는 **어떠한 임상시험이나 문헌 근거도 첨부되어 있지 않으며**, 분석 결과 "KG embedding 잡음/위양성 예측"으로 명시적으로 판정되었습니다. 즉, 이 예측은 기전상 타당성을 갖추지 못한 것으로 판단됩니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 안전성 고려사항

안전성 정보는 확보되지 않았습니다(주요 경고, 금기, 약물상호작용 모두 데이터 없음). 원 개발국(미국 FDA 등)의 최신 허가사항(Veklury 라벨)을 별도로 확인하시기 바랍니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
예측 신규 적응증(다발성 내분비 신생물)을 뒷받침하는 임상시험이나 문헌이 전무하며, 자체 기전 분석에서도 항바이러스제 MOA와 유전성 내분비 종양 병태생리 간 생물학적 연관성이 없다고 판정되어 모델 예측이 위양성(노이즈)일 가능성이 높습니다.

**진행하려면 필요한 것:**
- Remdesivir의 상세 MOA 및 원 적응증 데이터 확보 (DrugBank API 재조회)
- 규제기관 허가사항(경고/금기) 확보 — 현재 Blocking 등급 데이터 갭(DG001)으로 안전성 초기 평가(S1) 진입 불가
- 참고: 동일 Evidence Pack 내 2순위 예측(HIV infectious disease)은 L1 근거 수준으로 산정되었으나, 첨부된 임상시험·문헌 23건 전량이 실제로는 COVID-19/SARS-CoV-2 연구로 확인되어 **적응증 라벨 오매칭(label mismatch)**으로 판단됨. 근거 수준 산정 로직에 실제 질병-근거 일치 여부 검증 단계 추가가 필요함
- MEN 관련 실제 전임상/기전 연구가 확인되기 전까지 추가 검증 보류 권장
