# Atracurium besylate: 근이완(신경근 차단)에서 자간전증으로

## 한 문장 요약

Atracurium besylate는 비탈분극성 신경근 차단제로, 한국에서는 주사제로 허가되어 있습니다.
TxGNN 모델은 **자간전증(preeclampsia)**에 효과가 있을 수 있다고 예측하지만,
현재 이를 뒷받침하는 **임상시험은 0건**, **문헌도 0편**이어서 모델 예측만 있는 단계입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가증에 적응증 본문이 아닌 허가 문서 링크만 등재되어 있어 구체적 문구를 확인할 수 없음 (신경근 차단제로서 마취 시 근이완 용도로 알려져 있음) |
| 예측 신규 적응증 | 자간전증 (Preeclampsia) |
| TxGNN 예측 점수 | 99.97% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 3건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면 Atracurium은 신경근접합부의 니코틴성 아세틸콜린 수용체를 길항하는 비탈분극성 신경근 차단제이며, 호프만 소거(Hofmann elimination)로 분해됩니다.

자간전증의 병태생리는 태반 기능 이상, 혈관내피 손상, 고혈압이 핵심이며, 신경근 차단과의 직접적인 기전적 연관성은 확립되어 있지 않습니다. 자간전증의 경련 예방에는 Atracurium이 아닌 황산마그네슘이 사용됩니다. 임신부에서 Atracurium은 마취 상황에 한정되어 사용됩니다.

따라서 이번 예측은 지식그래프 기반의 통계적 연관성에 가까우며, 기전적 근거로 뒷받침되지는 않습니다. 같은 질환군의 하위 유형(중증 자간전증, 경증 자간전증)도 높은 점수를 받았으나 독립적인 근거로 볼 수 없습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
자간전증 예측은 TxGNN 점수(99.97%)만 높을 뿐, 임상시험과 문헌이 전혀 없고(L5) 기전적 연관성도 확립되어 있지 않습니다. 자간전증의 표준 경련 예방 약물은 황산마그네슘이며, Atracurium은 치료 목적이 아닌 제왕절개 마취 시의 보조 용도로만 쓰입니다.

**진행하려면 필요한 것:**
- 허가 문서에서 허가 적응증 및 경고·금기 정보 확보 (안전성 검토의 선행 조건)
- 상세한 약물 작용 기전(MOA) 데이터 보강
- 자간전증 병태생리와의 기전적 연관성을 뒷받침하는 전임상 또는 문헌 근거
- 기존 적응증과의 유사성 및 투여 경로 적합성 평가

참고로, 같은 약물의 다른 예측 질환(뇌척수신경근 증후군인 마미증후군, 안검경련, 편두통, 과민성 대장 증후군 등)도 모두 근거 수준 L5로 임상시험·문헌이 없습니다. 특히 안검경련과 편두통은 보툴리눔 독소와의 그래프 연관성이 점수를 높였을 가능성이 있으나, Atracurium은 작용 부위와 지속 시간이 달라 실현 가능성이 낮습니다. 혈전성 질환은 기전적 연관성이 확인되지 않았고, "obsolete neurogenic bladder"는 폐기된 온톨로지 용어여서 현행 용어로 재매핑이 필요합니다.
