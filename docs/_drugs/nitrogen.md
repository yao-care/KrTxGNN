# Nitrogen: 의료용 가스에서 16q24.1 미세결실 증후군으로

## 한 문장 요약

Nitrogen(질소)은 한국에서 의료용 가스로 허가·시판 중인 불활성 기체입니다.
TxGNN 모델은 **16q24.1 미세결실 증후군(16q24.1 microdeletion syndrome)**에 효과가 있을 수 있다고 예측하지만, 이를 지지하는 **임상시험은 0건, 문헌도 0편**입니다. 모델 점수만 있고 실제 근거가 없는 예측입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 의료용 질소 (허가 적응증 상세 텍스트는 확인되지 않음) |
| 예측 신규 적응증 | 16q24.1 미세결실 증후군 (16q24.1 microdeletion syndrome) |
| TxGNN 예측 점수 | 99.73% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 20건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면 질소는 생리적으로 불활성인 의료용·산업용 기체이며, 치료 약리 작용이 알려져 있지 않습니다.

16q24.1 미세결실 증후군은 FOXF1 영역의 결실과 관련된 유전 질환으로, 폐포 모세혈관 이형성증 등을 동반합니다. 기체 흡입으로는 이러한 유전적 결손을 교정할 수 없습니다. 따라서 기전상 타당한 연결고리를 찾기 어렵습니다.

높은 TxGNN 점수(99.73%)는 생물학적 신호가 아니라 지식 그래프상의 인위적 결과로 판단됩니다. 같은 이유로 다른 예측 질환(소아 특발성 간질성 폐질환, 폐 모세혈관염, 선천성 폐림프관확장증, 부신 양성 신생물 등)도 모두 뒷받침되는 근거가 없습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

- **지식 그래프상 금기 질환**: 메트헤모글로빈혈증, 설프헤모글로빈혈증, 심부전 (허가사항이 아닌 TxGNN 지식 그래프의 약물-질환 금기 연결 기반이므로 참고용)

그 외 안전성 정보는 허가사항을 참조하세요.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
질소는 불활성 기체로 제시된 예측 질환들과 기전상 연결이 없고, 임상시험과 직접 관련된 문헌이 없습니다. 부신 양성 신생물 및 치주 관련 증후군에서 검색된 문헌은 질소 관련 용어가 키워드로 일치한 것일 뿐 질소 치료 근거가 아닙니다.

**진행하려면 필요한 것:**
- 허가사항(경고·금기·적응증) 원문 확보 및 분석
- 작용 기전(MOA) 데이터 보완
- 예측 질환에 대한 질소 자체의 치료 효과를 직접 평가한 임상 또는 전임상 연구
- 질소 단독 투여와 질소 기반 혼합 가스(예: 일산화질소)를 구분한 근거 검토
