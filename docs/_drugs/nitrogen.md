# Nitrogen: 적응증 정보 없음에서 16q24.1 미세결실 증후군으로

## 한 문장 요약

Nitrogen(질소, DrugBank ID: DB09152)은 기존 적응증과 작용기전(MOA) 정보가 모두 확인되지 않았으며, 현재 한국에는 허가된 시판 제품이 없습니다(미시판, 허가증 0건). TxGNN 모델은 **16q24.1 미세결실 증후군(16q24.1 microdeletion syndrome)**에 효과가 있을 수 있다고 예측했으나(예측 점수 99.73%), 관련 임상시험과 문헌은 각각 **0건**으로 실제 근거는 전무하며, 이 예측은 생물학적 기전 가설이 아니라 지식그래프 임베딩 유사도의 잡음(noise)으로 평가되었습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 정보 없음 (등록된 적응증·허가 이력 없음) |
| 예측 신규 적응증 | 16q24.1 미세결실 증후군 (16q24.1 microdeletion syndrome) |
| TxGNN 예측 점수 | 99.73% |
| 근거 수준 | L5 (모델 예측만 있음, 실제 연구 없음) |
| 한국 시판 현황 | 미시판 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 Nitrogen의 상세한 작용 기전(MOA) 데이터는 확보되지 않았습니다([Data Gap], DrugBank 재조회 필요). 알려진 바로는 Nitrogen은 불활성 기체이며, 기존에 승인된 치료 적응증도 확인되지 않아 신규 적응증과의 약리학적 연결고리를 뒷받침할 근거가 없습니다.

예측된 16q24.1 미세결실 증후군은 염색체 미세결실로 인한 유전 질환으로, 질소(불활성 가스)와 이러한 유전질환 사이에는 식별 가능한 생물학적 경로가 없습니다. 관련 임상시험과 문헌도 전혀 존재하지 않아(0건/0편), 99.73%라는 높은 TxGNN 점수는 실제 기전 가설이 아니라 **지식그래프 임베딩 유사도상의 잡음(noise)**으로 해석하는 것이 타당합니다.

참고로 이번 평가에서 함께 검토된 2~10순위 예측 적응증(소아 간질성 폐질환, 고립성 폐모세혈관염, 선천성 폐림프관확장증, 부신 양성 종양, 치주 동반 기형 증후군, Dandy-Walker 기형 동반 증후군, 모발 이상, 다모증 등)에서도 동일한 패턴이 확인되었습니다 — 일부는 문헌이 존재했지만(부신 종양 20편, 치주 20편), 검토 결과 대부분 "nitrogen"과 "nitric oxide(일산화질소)", "urinary nitrogen(요중 질소)", "nitrogenous bisphosphonate(함질소 비스포스포네이트)" 등 전혀 다른 물질을 혼동한 검색 잡음으로 판정되었으며, 실제로 질소 자체를 치료제로 시험한 연구는 하나도 없었습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
- 예측 근거 수준이 L5(모델 예측만 존재, 실제 연구 없음)로 최하위 수준이며, 최상위 예측 적응증(16q24.1 미세결실 증후군)에 대한 임상시험·문헌이 전혀 없습니다.
- 함께 검토한 2~10순위 예측 적응증들도 표면적으로는 문헌이 존재하는 경우가 있었으나, 검토 결과 모두 질소와 무관한 화합물(일산화질소, 함질소 비스포스포네이트 등)과의 키워드 혼동으로 확인되어 실질적 근거가 없습니다.
- 한국 내 시판 허가가 없고(허가증 0건), 작용기전(MOA) 및 안전성 경고·금기 정보가 모두 확보되지 않은 상태(Blocking 등급 데이터 갭 포함)로, 안전성 초기 평가(S1) 단계 진입 자체가 불가능합니다.

**진행하려면 필요한 것:**
- 식약처(또는 원 출처) 허가사항/경고·금기 정보 확보 — 현재 Blocking 등급 데이터 갭으로, 이 항목이 해결되기 전에는 안전성 초기 평가를 진행할 수 없습니다.
- DrugBank API를 통한 작용기전(MOA) 정보 재조회 — 기전 관련성 분석의 최소 전제조건입니다.
- 위 두 데이터 갭이 해소되지 않는 한, 그리고 16q24.1 미세결실 증후군에 대한 실제 전임상·임상 근거가 새로 확보되지 않는 한 이 후보는 추가 조사 없이 보류(Hold) 상태를 유지하는 것을 권장합니다.
