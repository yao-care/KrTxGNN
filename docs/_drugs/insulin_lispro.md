# Insulin Lispro: 당뇨병에서 자가면역성 난소염으로

## 한 문장 요약

Insulin lispro는 속효성 인슐린 유사체로, 원래 혈당 조절을 위한 당뇨병 치료에 사용되어 왔습니다.
TxGNN 모델은 **자가면역성 난소염(autoimmune oophoritis)**에 효과가 있을 수 있다고 예측하지만, 현재 이를 지지하는 **임상시험은 0건**, **직접 관련 문헌도 없습니다**.
이 예측은 모델 점수만 있는 단계이며, 실제 치료 효과를 뒷받침하는 근거는 확인되지 않았습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 당뇨병 혈당 조절 (허가 적응증 원문은 링크 형태로만 제공되어 상세 문구 확인 불가) |
| 예측 신규 적응증 | 자가면역성 난소염 (autoimmune oophoritis) |
| TxGNN 예측 점수 | 99.78% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 6건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면, Insulin lispro는 인슐린 수용체에 작용해 혈당을 낮추는 속효성 인슐린 유사체이며, 당뇨병에서의 효능이 확립되어 있습니다.

자가면역성 난소염은 면역 매개성 난소 질환으로, 제1형 당뇨병이 포함된 자가면역 다내분비 증후군과 함께 나타나는 경우가 많습니다. 높은 TxGNN 점수는 이러한 자가면역·내분비 연관성에 따른 네트워크상의 근접성을 반영한 것으로 보입니다. 치료 기전이 확인된 것은 아닙니다.

인슐린은 동반된 당뇨병을 치료할 수는 있어도 난소염 자체를 치료한다고 보기는 어렵습니다. 따라서 직접적인 기전상 연결고리는 확립되지 않았습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
임상시험과 문헌이 전혀 없고 모델 예측(L5)만 있습니다. 인슐린은 동반 당뇨병을 치료할 수는 있지만, 난소염 자체에 대한 치료 기전은 확인되지 않았습니다.

**진행하려면 필요한 것:**
- 허가사항(MFDS 첨부문서)의 경고·금기 정보 확보 (현재 안전성 심사를 진행할 수 없는 상태)
- 작용 기전(MOA) 데이터 보충
- 자가면역성 난소염에서 인슐린의 직접적 효과를 시사하는 전임상 또는 임상 근거
- 자가면역 다내분비 증후군에 동반된 당뇨병 관리와 난소염 자체의 치료를 구분하는 분석
