# Insulin Lispro: 당뇨병에서 자가면역성 난소염(Autoimmune Oophoritis)으로

## 한 문장 요약

Insulin Lispro는 속효성 인슐린 제제로, 원래 당뇨병 환자의 혈당 조절에 사용됩니다.
TxGNN 모델은 **자가면역성 난소염(Autoimmune Oophoritis)**에 효과가 있을 수 있다고 예측(점수 99.78%)하지만,
현재 이를 뒷받침하는 **임상시험이나 문헌은 전혀 없으며**, 근거 자체가 지식그래프 내 "자가면역" 노드의 간접 공존(co-occurrence)에서 비롯된 것일 가능성이 제기됩니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 당뇨병 (인슐린 제제의 공통 적응증; 한국 허가 정보는 미확보) |
| 예측 신규 적응증 | 자가면역성 난소염 (Autoimmune Oophoritis) |
| TxGNN 예측 점수 | 99.78% |
| 근거 수준 | L5 (모델 예측만 있음, 실제 연구 없음) |
| 한국 시판 현황 | 미시판 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터가 없습니다(DrugBank 조회 필요, Blocking 등급 데이터 갭 DG002). 알려진 정보에 따르면 Insulin Lispro는 인슐린 수용체를 매개로 세포 내 포도당 흡수·대사를 조절하는 속효성 인슐린 유사체입니다.

Evidence Pack에 포함된 자체 기전 분석에 따르면, 자가면역성 난소염은 T세포/항체 매개 난소 조직 파괴 질환으로 인슐린 신호전달 경로와 직접적인 기전 연관성이 확인되지 않습니다. TxGNN의 높은 점수는 지식그래프 내 "자가면역(autoimmune)" 노드를 공유하는 간접 공존 관계를 반영했을 가능성이 있으며, 인과적 치료 근거로 보기 어렵습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
- 근거 수준이 L5(모델 예측뿐, 실제 연구 없음)이며, 관련 임상시험·문헌이 전무합니다.
- 기전 분석 자체가 이 예측을 "인과관계보다 지식그래프상의 간접 공존일 가능성"으로 판단하고 있어, 추가 검증 없이 진행할 근거가 부족합니다.
- 안전성 초기 평가(S1)에 필요한 TFDA 경고/금기 정보가 아직 확보되지 않았습니다 (Blocking 데이터 갭).

**진행하려면 필요한 것:**

- 자가면역 난소염-인슐린 신호전달 간 실제 기전적 가설 및 전임상 근거 확보
