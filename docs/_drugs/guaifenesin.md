# Guaifenesin: 거담제에서 비강 질환으로

## 한 문장 요약

Guaifenesin은 호흡기 점액의 점도를 낮춰 배출을 돕는 거담제 성분입니다.
TxGNN 모델은 **비강 질환(Nasal Cavity Disease)**에 효과가 있을 수 있다고 예측하며,
현재 **1건의 완료된 Phase 2 임상시험**과 **2편의 문헌**이 이 방향을 뒷받침합니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 데이터 없음 (한국 내 허가 정보 없음, 다만 일반적으로 거담제로 알려짐) |
| 예측 신규 적응증 | 비강 질환 (Nasal Cavity Disease) |
| TxGNN 예측 점수 | 99.98% |
| 근거 수준 | L2 |
| 한국 시판 현황 | 미시판 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터는 확보되지 않았습니다. 다만 근거팩에 포함된 재창출 근거에 따르면,
Guaifenesin은 거담제로서 호흡기·비강 점막 분비물의 수분 함량을 높이고 점도를 낮춰 배출을 촉진하는 약리작용을 가진 것으로 알려져 있습니다.

이러한 기전은 만성 비염, 부비동염 등 점막 폐쇄성 질환을 포괄하는 "비강 질환" 범주와 직접적으로 관련이 있어, 기전상 합리적인 노후 약물 재창출 가설로 판단됩니다.

실제로 소아 만성 비염을 대상으로 한 파일럿 임상시험에서 유의미한 방향성이 확인되었으나, 확증적 대규모 연구는 아직 부재합니다.
