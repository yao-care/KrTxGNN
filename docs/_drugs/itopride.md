# Itopride: 원 적응증 정보 없음에서 소장형 크론병(예측)으로

## 한 문장 요약

Itopride(DrugBank ID: DB04924)는 한국 내 허가·시판 이력이 없는 약물로, 원 적응증 데이터도 확보되지 않았습니다. TxGNN 모델은 **소장형 크론병(small bowel Crohn disease)**에 효과가 있을 수 있다고 예측했으나(예측 점수 99.90%), 이를 뒷받침하는 임상시험이나 문헌은 현재 **0건**이며, 근거 자체의 기전적 타당성도 낮게 평가됩니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 자료 없음 (원 적응증·MOA 데이터 미확보) |
| 예측 신규 적응증 | 소장형 크론병 (small bowel Crohn disease) |
| TxGNN 예측 점수 | 99.90% |
| 근거 수준 | L5 (임상시험·문헌 모두 없음) |
| 한국 시판 현황 | 미시판 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 Itopride의 상세한 작용 기전(MOA) 데이터는 확보되지 않았습니다. 다만 근거팩에 포함된 예측 근거 설명에 따르면, Itopride는 도파민 D2 수용체 길항작용과 아세틸콜린에스테라아제 억제를 통해 위장관 운동을 촉진하는 약물로 알려져 있습니다.

그러나 크론병은 면역 조절 이상과 장 점막 장벽 손상이 주된 병리기전인 자가면역/염증성 장질환으로, Itopride의 促動力·D2 길항 기전과 직접적인 연관성이 없습니다. 근거팩 자체의 평가에서도 이 높은 TxGNN 점수는 지식그래프 상의 간접 연결(약물-증상-질병 공동 출현 등)로 인한 위양성일 가능성이 지적되었으며, 이를 뒷받침하는 임상시험이나 문헌은 전혀 확인되지 않았습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 안전성 고려사항

안전성 정보는 허가사항을 참조하세요.

> 참고: TFDA 경고문/금기 정보(DG001)는 확보되지 않았으며, 이는 안전성 초기 평가(S1) 진입을 막는 Blocking 등급 데이터 공백입니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
- 근거 수준 L5(모델 예측만 존재, 실제 연구 없음)이며, 임상시험·문헌 증거가 전무합니다.
- 근거팩의 기전 분석 자체가 이 예측을 지식그래프 위양성 가능성이 높다고 평가하고 있어, 추가 검증 전 진행할 근거가 부족합니다.

**진행하려면 필요한 것:**
- TFDA 허가사항(경고/금기) 확보 — 현재 Blocking 등급 공백(DG001)
- Itopride의 상세 작용 기전(MOA) 데이터 확보 (DG002)
- 소장형 크론병에 특화된 전임상 또는 초기 임상 데이터 축적

**참고 사항:**
동일 근거팩 내 다른 후보 중 **식도궤양(esophageal ulcer, rank 5)**은 L4/S1 단계로 문헌 2건(ENGIP-II 코호트 연구 포함)이 확인되어, 현 후보보다 상대적으로 검토 우선순위가 높습니다. 이는 별도 평가가 필요합니다.
