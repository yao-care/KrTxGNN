# Zolmitriptan: 편두통에서 뇌간 조짐 편두통으로

## 한 문장 요약

Zolmitriptan은 5-HT1B/1D 수용체 작용제(트립탄 계열) 약물로, 일반적으로 편두통 급성기 치료에 사용되어 왔습니다(한국 허가 정보는 확보되지 않음). TxGNN 모델은 **뇌간 조짐 편두통(Migraine with Brainstem Aura)**에 효과가 있을 수 있다고 예측(점수 99.99%)했으나, 현재 **관련 임상시험은 전무**하고 19편의 문헌 중 이 아형을 직접 다룬 RCT는 없어 근거 수준이 제한적입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 편두통 급성기 치료 (일반형) — 한국 허가 정보 없음 |
| 예측 신규 적응증 | 뇌간 조짐 편두통 (Migraine with Brainstem Aura) |
| TxGNN 예측 점수 | 99.99% |

| 한국 시판 현황 | 미시판 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터는 확보되지 않았습니다. 다만 근거 자료의 기전 분석에 따르면, Zolmitriptan은 선택적 5-HT1B/1D 수용체 작용제("트립탄" 계열)로 삼차신경혈관계 활성화를 억제하여 일반 편두통에 효과를 나타냅니다. 이 기전은 편두통 전반에 적용 가능하다는 점에서 뇌간 조짐 편두통 예측과 표면적으로 연결됩니다.

그러나 뇌간 조짐 편두통(과거 basilar-type migraine)은 뇌간·척추기저동맥 순환과 관련된 아형으로, 트립탄류의 혈관수축 작용이 이론적으로 뇌간 허혈을 악화시킬 위험이 있어 다수의 임상 가이드라인에서 상대적 금기 또는 신중 투여 대상으로 분류됩니다. 확보된 19편의 문헌은 모두 일반 편두통, 조짐이 있는 편두통 전반, 또는 다른 아형(월경 편두통, 전정 편두통 등)을 다루고 있을 뿐, 이 아형에 특이적인 RCT는 없습니다. 즉 TxGNN이 제시한 기전적 연관성은 존재하나, 오히려 안전성 측면에서 신중해야 할 신호로 해석해야 합니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 한국 시판 정보

현재 한국에는 허가된 제품이 없으며, 미시판 상태입니다.

## 안전성 고려사항

현재 허가사항(경고, 금기)과 약물상호작용(DDI) 정보가 전혀 확보되지 않았습니다. 이는 안전성 초기 평가(S1 단계) 진입 자체를 막는 **Blocking 등급 데이터 갭**으로 분류되어 있어 최우선 보완이 필요합니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
- TxGNN 예측 점수는 99.99%로 높지만, 뇌간 조짐 편두통은 트립탄 계열 약물이 이론적으로 금기 또는 신중 투여 대상으로 분류되는 아형이며, 확보된 문헌 19편 중 이 아형을 직접 검증한 RCT는 없습니다.
- 안전성 핵심 데이터(경고, 금기)가 Blocking 등급으로 누락되어 있어 S1 안전성 초기 평가 자체가 불가능한 상태입니다.
- 한국 미시판 상태로 허가 근거도 없습니다.

**진행하려면 필요한 것:**
- 허가 당국(MFDS 등)의 경고·금기 정보 확보 (Blocking, 최우선)
- Zolmitriptan의 상세 작용 기전(MOA) 데이터 확보
- 뇌간 조짐 편두통에 특이적인 임상 연구 또는 증례 축적 — 이론적 혈관수축 위험을 실증적으로 배제할 필요
- 한국 내 상시 가능성 검토

---
참고: TxGNN이 제시한 하위 순위 예측(atrophoderma vermiculata, ulerythema ophryogenesis)은 임상시험·문헌 근거가 전혀 없어(L5, S0) 모델 노이즈로 판단되며 본 보고서에서 다루지 않았습니다.
