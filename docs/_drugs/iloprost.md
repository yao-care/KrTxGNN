# Iloprost: 기존 적응증에서 폐동맥 고혈압(선천성 심장질환 동반)으로

## 한 문장 요약

Iloprost는 한국에서 흡입액제(벤타비스)로 허가·시판 중인 프로스타사이클린(PGI2) 유사체입니다.
TxGNN 모델은 여러 예측 질환 중 근거가 가장 충실한 **선천성 심장질환 동반 폐동맥 고혈압(PAH-CHD)**에 효과가 있을 수 있다고 예측하며, 현재 등록된 임상시험은 없지만 **20편의 문헌**(대부분 관찰 연구, 증례 시리즈, 리뷰)이 이 방향을 지지합니다.

> 참고: 모델 예측 점수 1위는 "두피 단순 모발 희소증(hypotrichosis simplex of the scalp)"이나 근거가 전혀 없어, 이 보고서는 근거가 가장 풍부한 3위 예측을 중심으로 평가하고 나머지 예측은 부록에서 요약합니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 확인 불가 (허가 적응증 정보가 문서 링크로만 제공되어 허가사항 원문 확인 필요) |
| 예측 신규 적응증 | 선천성 심장질환 동반 폐동맥 고혈압 (Pulmonary arterial hypertension associated with congenital heart disease) |
| TxGNN 예측 점수 | 99.32% |
| 근거 수준 | L3 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 1건 |
| 권장 결정 | Proceed with Guardrails |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면 Iloprost는 안정화된 프로스타사이클린(PGI2) 유사체로, IP 수용체를 통해 cAMP를 높여 폐혈관을 확장하고 혈소판 응집과 평활근 증식을 억제합니다.

PAH는 이미 이 계열 약물의 확립된 사용 영역입니다. 따라서 이번 질문은 새로운 질환 기전이 아니라 선천성 심장질환 동반 하위군(CHD-PAH, 아이젠멩거 증후군 포함)에서도 효과와 안전성이 유지되는가입니다.

문헌에는 CHD-PAH 환자의 바이오마커 변화 연구, 소아 급성 혈역학 연구, 아이젠멩거 증후군 장기 치료 연구가 포함되어 있어 임상적 타당성을 뒷받침합니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 안전성 고려사항

- **질환 지식그래프상 금기 관련 질환**(허가 문서가 아닌 모델 지식그래프 기준): 간부전, 만성 폐쇄성 폐질환(COPD), 저혈압, 폐부종, 기관지 질환
- **약물 상호작용**(총 100건 중 일부): 에피네프린, 아세틸살리실산(아스피린), SGLT2 억제제(canagliflozin, dapagliflozin, empagliflozin, ertugliflozin), 흡입 인슐린, 만니톨, 에페드린, 펜플루라민, 글리세린, 파파베린, 시부트라민 등이 중등도(Moderate)로 분류됩니다.

세부 경고 및 금기는 허가사항을 참조하세요.

## 결론 및 다음 단계

**결정: Proceed with Guardrails**

**사유:**
선천성 심장질환 동반 PAH에서 iloprost를 다룬 관찰 연구, 증례 시리즈, 소규모 교차시험이 있고, PAH 자체가 이 계열 약물의 확립된 사용 영역이라 기전적 타당성이 높습니다. 다만 등록된 임상시험과 하위군 특이적 RCT가 없어 근거는 L3 수준입니다.

**진행하려면 필요한 것:**
- 허가사항(적응증, 경고, 금기) 원문 확보 및 분석. 현재 안전성 선별을 진행할 수 없는 상태입니다.
- 상세한 작용 기전(MOA) 데이터 보완
- CHD-PAH 하위군(아이젠멩거 증후군 포함)에 대한 전향적 시험 설계 검토
- 저혈압, 폐부종, COPD 환자에 대한 모니터링 계획
- 한국 허가 적응증과 신규 적응증 범위 간 차이 확인
