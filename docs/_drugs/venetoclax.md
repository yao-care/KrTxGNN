# Venetoclax: 원 적응증 정보 미확보 상태에서 프리제르미널센터 CLL/SLL로

## 한 문장 요약

Venetoclax(DrugBank ID: DB11581)는 선택적 BCL-2 억제제(BH3-mimetic) 계열 약물이나, 이번 Evidence Pack에는 원 적응증·작용기전 데이터가 확보되지 않았고(Blocking 데이터 갭) 한국에는 아직 상장되지 않았습니다.
TxGNN 모델은 1순위로 **프리제르미널센터(IGHV 미변이형) 만성 림프구성 백혈병/소림프구성 림프종(CLL/SLL)**에 효과가 있을 수 있다고 예측하나, 현재 이를 직접 뒷받침하는 임상시험은 없고 문헌 1편(리뷰)만 확인됩니다.
참고로 동일 후보약물의 10개 예측 적응증 중 4순위 "골수성 백혈병(myeloid leukemia)"은 다수의 Phase 2/3 RCT로 뒷받침되며(L1 근거), 근거 자료 자체에도 "실질적으로 이미 승인된 적응증"이라 기술되어 있어 함께 참고할 가치가 있습니다.

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다(Evidence Pack DG002, High severity). 알려진 정보에 따르면, Venetoclax는 선택적 BCL-2 억제제(BH3-mimetic) 계열의 표적치료제이며, BCL-2 의존적으로 생존하는 혈액암 세포의 아폽토시스를 유도하는 기전을 가지고 있습니다.

CLL/SLL 세포는 전반적으로 BCL-2를 과발현하여 생존 신호에 의존하는 것으로 알려져 있습니다. 이 중 프리제르미널센터(미변이 IGHV) 아형은 예후가 상대적으로 나쁘고 B세포수용체(BCR) 신호전달이 더 강한 특징을 가지는데, 이론상으로는 이 아형 역시 BCL-2 의존성 범주에 속할 것으로 추정됩니다. 다만 본 Evidence Pack에는 이 특정 분자 아형을 표적으로 한 전향적 임상시험이 존재하지 않아, 현재로서는 기전적 추론 단계에 머물러 있습니다.

| 항목 | 내용 |
|------|------|
| 세포독성 분류 | 표적치료제 (선택적 BCL-2 억제제, BH3-mimetic) — 전통적 세포독성 화학요법과는 구분됨 |
| 골수억제 위험 | 중~고 (호중구감소증이 대표적 이상반응으로 널리 보고됨) |
| 구토 유발성 등급 | 저 (경구 표적치료제로 전통적 세포독성제 대비 낮은 편) |
| 모니터링 항목 | CBC(호중구 포함), 신기능·전해질(종양용해증후군 감시), 간기능 |
| 취급 방호 | 본 Evidence Pack에는 관련 데이터가 없어 허가사항의 경고 및 주의사항을 참조하세요 |

## 결론 및 다음 단계

**결정: Hold**

**사유:**
- 1순위 예측 적응증(프리제르미널센터 IGHV 미변이형 CLL/SLL)은 직접 임상시험 근거가 전무하고 리뷰 문헌 1편만 존재하여 근거 수준이 L3(관찰/리뷰 수준)에 그칩니다.
- TFDA 경고·금기 정보(DG001, **Blocking** severity)가 확보되지 않아 S1 안전성 초기평가 자체가 불가능한 상태입니다.
- 한국 내 미상장 상태로 허가 경로 및 원 적응증 정보도 부재합니다.

**진행하려면 필요한 것:**
- TFDA(또는 원 제조사) 허가사항 PDF 확보 및 경고/금기 파싱 (DG001 해소, Blocking)
- DrugBank API 조회를 통한 상세 MOA·독성 프로파일 확보 (DG002 해소)
- 프리제르미널센터(IGHV 미변이형) CLL/SLL 아형에 특화된 전향적 임상시험 또는 하위군 분석 데이터 확보
- 참고: 동일 약물의 "골수성 백혈병(AML)" 적응증(본 Evidence Pack 4순위)은 L1 수준 근거(Phase 2/3 RCT 다수, VIALE-A/C 계열)를 보유하고 있어 별도 후보로 우선순위 검토를 권장합니다.
