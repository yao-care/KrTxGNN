# Icodextrin: 복막투석 용액에서 과민성 장 증후군으로

## 한 문장 요약

Icodextrin은 고분자 포도당 중합체로, 복막투석 용액의 삼투제로 사용되는 약물입니다.
TxGNN 모델은 **과민성 장 증후군(Irritable Bowel Syndrome)**에 효과가 있을 수 있다고 예측하지만, 현재 이를 지지하는 **임상시험은 0건**, **문헌도 0편**입니다. 모델 예측만 있는 단계입니다.

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면 Icodextrin은 복막투석에 쓰이는 고분자 포도당 중합체 삼투제이며, 복강에서 흡수가 거의 되지 않습니다.

과민성 장 증후군과 기전상 연결되는 근거는 확인되지 않았습니다. 높은 예측 점수(0.985)는 지식 그래프 기반 연관성에서 나온 계산상의 결과일 뿐이며, 이를 뒷받침하는 임상시험이나 문헌이 없습니다.

참고로 같은 약물에 대해 예측된 다른 질환(식도 기형, C1 억제제 결핍증, 칼륨 결핍증, 유전성 혈관부종, 세뇨관성 산증 등)도 모두 L5 수준이며 기전상 근거가 없는 것으로 평가되었습니다.
