# Omidenepag isopropyl: 녹내장에서 췌장염(Pancreatitis)으로

## 한 문장 요약

Omidenepag isopropyl은 선택적 EP2 수용체 작용제로, 해외에서 녹내장/안압 조절 목적으로 사용되는 약물입니다(국내 허가 자료 없음). TxGNN 모델은 **췌장염(Pancreatitis)**에 효과가 있을 수 있다고 예측하지만, 이를 뒷받침하는 임상시험이나 문헌은 **현재 없으며**, 기전상 연관성도 확인되지 않았습니다.

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터가 없습니다. 알려진 정보에 따르면, Omidenepag isopropyl은 선택적 **EP2 수용체 작용제**이며, 안압을 낮추는 방식으로 녹내장 치료에 사용됩니다.

EP2 수용체 작용과 췌장 염증 경로 사이에는 알려진 직접적 연관성이 없습니다. 이 예측은 TxGNN 지식그래프상의 노드 근접성에 기반한 추론일 뿐, 약리학적 기전이나 실제 임상·전임상 근거로 뒷받침되지 않습니다. 따라서 현재로서는 기전상 타당성을 확인할 수 없는 상태입니다.
