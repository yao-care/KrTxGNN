# Lanreotide: 적응증 미상 → 다모증(Hypertrichosis)으로 (예측)

## 한 문장 요약

Lanreotide는 이번 Evidence Pack에서 기존 적응증과 작용 기전(MOA) 정보가 모두 확인되지 않았습니다.
TxGNN 모델은 **다모증(Hypertrichosis, disease)**에 효과가 있을 수 있다고 예측했으나, 이를 뒷받침하는 임상시험이나 문헌은 **0건**입니다. 상위 5개 예측 후보가 모두 모발/각질 관련 희귀질환군에 몰려 있어, 실제 신호라기보다 모델의 구조적 편향(그래프 임베딩 노이즈)일 가능성이 있습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 확인 안 됨 (등록된 허가·적응증 데이터 없음) |
| 예측 신규 적응증 | 다모증 (Hypertrichosis, disease) |
| TxGNN 예측 점수 | 99.97% |
| 근거 수준 | L5 (모델 예측만 존재, 실제 연구 없음) |
| 대만 시판 현황 | 미출시 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. Lanreotide의 원 적응증과 MOA가 모두 데이터 공백(Data Gap) 상태이기 때문에, 기존 적응증과 다모증 사이의 기전적 연관성을 판단할 근거가 없습니다.

더 우려되는 점은, 이번 예측 배치에서 상위 5개 후보(다모증, 치아·치주 발달 이상 증후군, Dandy-Walker 기형 증후군, 유전성 모발 축 이상, Ambras형 선천성 전신 다모증)가 거의 동일한 TxGNN 점수(0.9996~0.9997)로 몰려 있고, 그중 다수가 모발·각질 관련 희귀질환입니다. 이는 약물 특이적 신호라기보다 특정 질환 노드 군집에 대한 모델의 시스템적 고득점 경향, 즉 그래프 구조 노이즈일 가능성을 시사합니다. 임상시험, ICTRP 등록, 관련 문헌이 모두 0건이라는 점도 이 우려를 뒷받침합니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

> 참고: 순위 2위 후보(치아·치주 발달 이상 증후군)에서는 PubMed 검색 결과 20편이 조회되었으나, 전수가 일반 치주염 병태생리 리뷰(당뇨-치주염 관계, 치은 섬유모세포 역할 등)로 Lanreotide 또는 소마토스타틴 유사체와의 직접적 연관성을 언급한 문헌은 없었습니다. 키워드 매칭에 의한 비관련 문헌으로 판단되어 근거로 채택하지 않았습니다.

## 안전성 고려사항

TFDA 허가사항(경고·금기) 데이터가 아직 확보되지 않아(Blocking 등급 데이터 공백) 안전성 초기 평가(S1) 진행이 불가능한 상태입니다. 약물상호작용(DDI) 조회 결과도 없음으로 확인되었습니다. 안전성 정보는 별도로 허가사항 원본을 확인해야 합니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
- 5개 예측 후보 모두 임상시험·ICTRP·유의미한 문헌 근거가 전무한 L5 수준이며, 다수가 동일 질환군에 비정상적으로 몰려 있어 모델 편향(노이즈) 가능성이 큽니다.
- 약물의 원 적응증·MOA·TFDA 허가 정보가 모두 데이터 공백 상태로, 기전적 타당성 검토 및 안전성 초기 평가(S1) 자체가 불가능합니다.

**진행하려면 필요한 것:**
- TFDA 허가 사항(경고/금기) 원문 확보 — 안전성 평가 진행을 위한 필수 선행 조건 (DG001, Blocking)
- DrugBank 등에서 Lanreotide의 작용 기전(MOA) 확인 (DG002)
- 다모증 예측이 실제 생물학적 신호인지, 모델의 질환 군집 편향인지 구분하기 위한 추가 검증 (예: 다른 소마토스타틴 유사체의 동일 질환군 예측 여부 비교)
- 원 적응증 정보 확보 후 재평가
