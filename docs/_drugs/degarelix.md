# Degarelix: 전립선암 치료제에서 다모증(Hypertrichosis)으로

## 한 문장 요약

Degarelix는 GnRH 수용체 길항제로, 한국에서 퍼마곤주라는 제품명으로 허가되어 시판 중입니다. TxGNN 모델은 **다모증(hypertrichosis)**에 효과가 있을 수 있다고 예측하지만, 현재 이를 지지하는 **임상시험은 0건, 문헌도 0편**입니다. 따라서 이 예측은 모델 기반 가설 수준이며, 실제 근거는 없습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가증에는 적응증 본문 대신 허가 문서 링크만 확인되어, 구체적인 기존 적응증 문구는 이 보고서의 데이터로 확인되지 않음 |
| 예측 신규 적응증 | 다모증 (hypertrichosis) |
| TxGNN 예측 점수 | 99.99% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 2건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터는 없습니다. 알려진 정보에 따르면 Degarelix는 GnRH 수용체 길항제로, LH/FSH 분비를 억제하여 테스토스테론과 하위 안드로겐을 낮춥니다.

다만 다모증은 일반적으로 안드로겐 의존성이 아니어서(안드로겐 의존성인 다모증 hirsutism과는 구별됨) 기전상 연관성은 약합니다. 99.99%라는 높은 점수는 지식 그래프에 기반한 계산상의 예측일 뿐이며, 이를 뒷받침하는 임상시험이나 문헌은 없습니다.

참고로 상위 10개 예측 중 대부분(Ambras형 다모증, Dandy-Walker 기형 증후군, 모간 이상, 두드러기 등)도 기전적 근거나 임상 근거가 없습니다. 기전상 가장 그럴듯한 후보는 **중추성 성조숙증(순위 9, 점수 99.67%)**입니다. GnRH 축 차단이 이론적으로 타당하지만, 표준 치료는 이미 GnRH 작용제이고 소아 데이터가 없습니다. 가족성 남성 한정 성조숙증(순위 8)은 LH 수용체 활성화 변이가 원인이어서 상위 단계에서 작용하는 Degarelix로는 차단하기 어렵습니다.

|---------|------|------|-----------|

두 제품 모두 한국페링제약(주)이 보유한 단일제 허가입니다.

## 안전성 고려사항

- **관련 질환(지식 그래프 기반, 허가사항 아님)**: 긴QT증후군, 가족성 긴QT증후군, 토사드 드 포앙트(torsades de pointes), 간질환, 담낭질환, 칼륨 결핍증이 금기 관계로 연결되어 있습니다.
- **약물 상호작용**: 총 100건이 확인되었으며, 이 중 일부를 표시합니다. QT 연장과 관련된 약물이 많습니다.
  - **Major**: Cisapride, Dolasetron
  - **Moderate**: Famotidine, Loperamide, Bisacodyl, Clarithromycin, Levofloxacin, Ondansetron, Granisetron, Palonosetron 및 여러 하제(Lactulose, Magnesium citrate 등)
  - **Minor**: Metronidazole
- 이 밖에 Degarelix 자체에서 주사 부위 반응과 과민반응이 나타날 수 있어, 두드러기 예측에는 불리한 요소입니다.

허가사항의 경고 및 금기 항목은 확인되지 않았으므로 허가사항을 참조하세요.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
상위 예측 모두 임상시험과 문헌 근거가 없는 L5 수준이며, 1순위인 다모증은 기전상 연관성도 약합니다. QT 연장 관련 안전성 우려도 있어 현 시점에서 진행할 근거가 부족합니다.

**진행하려면 필요한 것:**
- 허가 문서(MFDS 첨부문서)의 적응증, 경고, 금기 정보 확보
- 상세한 작용 기전(MOA) 데이터 확보
- 다모증과 안드로겐 억제 사이의 병태생리적 연관성에 대한 전임상 또는 문헌 근거
- 기전상 가장 타당한 중추성 성조숙증은 별도 연구 질문으로 검토(소아 안전성·제형 적합성 포함)
