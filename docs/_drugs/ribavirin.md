## Ribavirin: 기존 허가 용도에서 만성 B형 간염으로
{: .text-alpha }

## 한 문장 요약

Ribavirin(리바비린)은 한국에서 단일성분 캡슐제로 허가증 20건이 확인되지만, 허가 적응증 원문은 링크만 있어 구체적인 기존 적응증을 확인할 수 없습니다.
TxGNN 모델은 **만성 B형 간염(chronic hepatitis B virus infection)**에 효과가 있을 수 있다고 예측하며, 관련 임상시험 16건과 문헌 20편이 검색되었습니다.
다만 B형 간염을 직접 다룬 시험은 일부이고 문헌은 모두 리뷰 수준이어서, 근거는 **제한적**입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 확인 불가 (허가 적응증 텍스트 없이 원문 링크만 제공됨) |
| 예측 신규 적응증 | 만성 B형 간염 |
| TxGNN 예측 점수 | 0.9986 |
| 근거 수준 | L2 (B형 간염을 직접 다룬 완료된 Phase 3 시험 1건, Phase 2/3 파일럿 1건) |
| 한국 시판 현황 | 시판 중 (유효 허가 20건 / 전체 20건) |
| 허가증 수 | 20건 (유효 20건) |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터가 없습니다. 일반적으로 알려진 바로는 리바비린은 구아노신 유사 뉴클레오시드로, IMPDH 억제와 GTP 풀 감소, 면역조절 작용을 통해 광범위한 항바이러스 활성을 보입니다.

이 기전은 바이러스성 간염이라는 공통점 때문에 B형 간염에도 적용 가능성이 있습니다. 그러나 리바비린 단독으로는 B형 간염 바이러스(HBV)에 대한 활성이 약합니다. 페그인터페론과 병용할 때 면역조절 효과를 더할 수 있다는 가설이 있으나, 이를 뒷받침하는 근거는 제한적입니다.

엔테카비르와 테노포비르 같은 기존 HBV 뉴클레오(티)드 유사체는 근거가 훨씬 강합니다. 리바비린이 추가로 줄 수 있는 가치는 그만큼 작습니다.

## 임상시험 근거

## 안전성 고려사항

허가사항의 경고·금기 정보는 이번에 수집되지 않았습니다. 정확한 내용은 허가사항을 참조하세요.

- **지식 그래프에 기록된 금기 관계**: 아래는 허가 문서 내용이 아니라 지식 그래프(PrimeKG)에 기록된 약물-질환 금기 관계입니다.
  - 혈액 질환: 빈혈, 용혈성 빈혈, 겸상적혈구빈혈, 혈색소병증, 범혈구감소증, 선천성 재생불량빈혈
  - 심혈관 질환: 심근경색, 관상동맥질환, 죽상경화증, 심근허혈
  - 호흡기 질환: 만성 폐쇄성 폐질환(COPD), 천식, 간질성 폐질환, 유육종증
  - 간·신장·췌장 질환: 간경변, 자가면역간염, 신기능 저하, 췌장염
  - 기타: 치주염
- **약물 상호작용**: 조회된 상호작용은 총 100건입니다. 목록에 표시된 항목은 칼시트리올, 판토프라졸, 글리메피리드, 메살라진, 독시사이클린, 클로트리마졸, 모르핀, 메트포르민, 오메프라졸, 프레드니손, 암포테리신 B 등입니다. 모두 위험 등급이 분류되지 않은 상태("미분류")이므로, 임상적 중요도는 별도로 확인해야 합니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
B형 간염을 직접 다룬 완료 시험은 Phase 3 1건과 Phase 2/3 파일럿 1건이며, 문헌은 리뷰뿐입니다. 리바비린 단독의 HBV 활성이 약하고 기존 HBV 치료제의 근거가 훨씬 강해 추가 가치가 불분명합니다. 허가사항의 안전성 정보와 작용 기전 데이터도 확보되지 않았습니다.

**진행하려면 필요한 것:**
- MFDS 허가사항 원문에서 적응증, 경고, 금기 확인 (특히 용혈성 빈혈과 심혈관 질환 관련)
- NCT00114361(PARC)과 NCT00275938의 결과를 확인해, 리바비린이 페그인터페론 단독 대비 실제로 추가 효과를 주는지 검증
- DrugBank 등에서 작용 기전(MOA) 데이터 확보
- NCT03759782 등 진행 중이거나 상태 불명인 시험의 최신 결과 확인
- 현행 HBV 표준 치료(엔테카비르, 테노포비르) 대비 리바비린의 임상적 위치 평가
- 한국 시판 여부(취소 여부 포함) 및 수출용 허가 비중 재확인
