# Cefroxadine: 미상 적응증에서 골관절염으로

## 한 문장 요약

Cefroxadine(DB11367)은 제1세대 세팔로스포린계 항생제로 추정되나, 국내 허가 이력이 없어 원래 적응증 정보 자체가 확보되지 않았습니다. TxGNN 모델은 **골관절염(Osteoarthritis)**에 효과가 있을 수 있다고 예측했으나(점수 98.32%), 이를 뒷받침하는 임상시험이나 문헌은 **0건**이며, 평가 팩 자체도 이 예측에 기전상 근거가 없다고 명시하고 있습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 확인 불가 (원 적응증 데이터 없음, MOA도 [Data Gap]) |
| 예측 신규 적응증 | 골관절염 (Osteoarthritis) |
| TxGNN 예측 점수 | 98.32% |
| 근거 수준 | L5 (모델 예측만 존재, 실증 연구 없음) |
| 한국 시판 현황 | 미상 (미시판, 허가 0건) |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 Cefroxadine의 상세 작용 기전(MOA) 데이터는 확보되지 않았습니다([Data Gap]). 다만 평가 팩의 기전 분석 메모에 따르면 Cefroxadine은 세균 세포벽 합성(PBP 결합)을 억제하는 제1세대 세팔로스포린계 항생제로 분류됩니다.

골관절염은 연골 퇴행과 국소 염증이 핵심 병리인 질환으로, 세균 세포벽 합성 억제라는 항생제 기전과는 알려진 약리학적 연결고리가 없습니다. 평가 팩 자체도 이 예측을 "TxGNN 지식그래프 임베딩 유사도에 의한 결과일 뿐, 기전적 지지 근거가 없음"이라고 명시적으로 판단하고 있어, 현시점에서는 생물학적 가설이 아닌 통계적 패턴 매칭에 가깝습니다.

참고로 2~10위 후보(류마티스 관절염, 통풍, 가성연골무형성증, 단신형척추이형성증, 혈색소병증 등) 역시 동일하게 기전적 연결이 없으며, 이 중 다수는 유전성 구조 질환(약물로 되돌릴 수 없는 병리)으로 평가 팩에서 "KG 노드 군집으로 인한 임베딩 잡음"으로 별도 표시되어 있습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 한국 시판 정보

Cefroxadine은 국내 미시판 상태이며, 확보된 허가증이 없습니다.

## 안전성 고려사항

DDI, 주요 경고, 금기 정보 모두 확인되지 않았습니다([Data Gap] DG001: TFDA 등 규제기관 허가사항/경고문 미확보, Blocking 등급). 안전성 초기 평가(S1 단계)조차 진행할 수 없는 상태입니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
- 근거 수준이 L5(모델 예측만 존재)로 최하위이며, 지지하는 임상시험·문헌이 전무합니다.
- 평가 팩 자체가 이 예측에 기전적 타당성이 없다고 명시했고, 2~10위 후보도 대부분 기전 무관 또는 유전성 구조 질환으로 판단되어 예측 세트 전반의 신뢰도가 낮습니다.
- 원 적응증·MOA·안전성 정보가 모두 결측(DG001 Blocking, DG002 High)이라 S1 안전성 초평가 진입 자체가 불가능합니다.

**진행하려면 필요한 것:**
- DrugBank API 등을 통한 Cefroxadine 원 적응증 및 MOA 확보 (DG002)
- 규제기관 허가사항/경고문·금기 확보 (DG001, Blocking — 해결 전까지 후속 진행 차단)
- 골관절염 관련 전임상·기전 연구 존재 여부 재탐색 (문헌 0건 상태 재확인)
- 위 데이터 보강 전까지 본 후보는 추가 자원 투입 보류 권장
