## Carbetocin: 자궁 이완증 관련 산후출혈 예방에서 이소트레티노인 유사 증후군으로
{: .text-alpha }

## 한 문장 요약

Carbetocin은 옥시토신 유사체로, 원래 자궁 무력증(uterine atony)으로 인한 산후출혈 예방에 사용되었습니다.
TxGNN 모델은 **이소트레티노인 유사 증후군(isotretinoin-like syndrome)**에 효과가 있을 수 있다고 예측하지만, 현재 이를 뒷받침하는 **임상시험은 0건, 문헌도 0편**입니다.
즉, 이 예측은 모델 점수에만 근거하며 실제 연구 근거는 아직 없습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 자궁 무력증으로 인한 산후출혈 예방 (한국 허가증에는 적응증 본문 대신 허가사항 문서 링크만 확인되어, 약리 데이터의 임상 용도를 참고함) |
| 예측 신규 적응증 | 이소트레티노인 유사 증후군 (isotretinoin-like syndrome) |
| TxGNN 예측 점수 | 0.9915 |
| 근거 수준 | L5 |
| 한국 시판 현황 | Unknown (source lacks cancellation status) |
| 허가증 수 | 2건 |
| 권장 결정 | Hold |

참고: 같은 모델이 두 번째로 예측한 적응증은 Goodman 증후군(점수 0.9906)이며, 이 역시 임상시험과 문헌 근거가 없어 보류 대상입니다.

## 이 예측이 타당한 이유는?

현재 이 예측을 설명할 만한 기전적 연결고리는 확인되지 않습니다. 이 보고서를 위해 수집된 데이터에는 상세한 작용 기전 정보가 없습니다. 알려진 정보에 따르면 carbetocin은 자궁 평활근의 옥시토신 수용체(OXTR)에 작용하는 작용제(agonist)이며, 자궁 수축을 유도해 산후출혈을 예방합니다.

이소트레티노인 유사 증후군(레티노산 배아병증)은 발달 과정에서 레티노이드 신호가 교란되어 생기는 기형 증후군입니다. 옥시토신 수용체 작용과 이 질환 사이에 이어지는 경로는 보이지 않으며, 선천성 기형 증후군은 자궁수축제의 일반적인 치료 표적도 아닙니다.

따라서 높은 TxGNN 점수(0.9915)는 생물학적 근거라기보다, TxGNN 모델(딥러닝)이 관련 질환 간에 학습한 유사성을 반영한 모델 예측일 가능성이 큽니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
임상시험과 문헌 근거가 모두 없고(L5), 옥시토신 수용체 작용과 이소트레티노인 유사 증후군 사이에 기전적 연결도 확인되지 않습니다. 높은 모델 점수만으로는 진행을 정당화하기 어렵습니다.

**진행하려면 필요한 것:**
- 허가사항 원문(경고·금기 포함)을 확보하여 안전성 검토 수행
- 작용 기전(MOA) 데이터 보완 (예: DrugBank 조회)
- 옥시토신 신호와 레티노이드 관련 발달 이상 사이의 기전적 연관성에 대한 전임상 또는 문헌 근거 확인
- 투여 경로 적합성(현재 주사제만 시판) 및 대상 질환의 치료 표적 타당성 평가
