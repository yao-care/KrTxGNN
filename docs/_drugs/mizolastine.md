# Mizolastine: 알레르기 질환에서 급성 간헐성 포르피린증으로

## 한 문장 요약

Mizolastine은 제2세대 선택적 H1 수용체 길항제 계열의 항히스타민제입니다.
TxGNN 모델은 **급성 간헐성 포르피린증(Acute Intermittent Porphyria)**에 효과가 있을 수 있다고 예측했지만,
현재 이를 뒷받침하는 임상시험이나 문헌은 **전혀 없으며**, 오히려 알려진 약리학적 방향과 반대되는 신호로 판단됩니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 정보 없음 (제2세대 H1 수용체 길항제 계열 항히스타민제로 추정, 한국 허가 자료 없음) |
| 예측 신규 적응증 | 급성 간헐성 포르피린증 (Acute Intermittent Porphyria) |
| TxGNN 예측 점수 | 99.76% |
| 근거 수준 | L5 (모델 예측만 존재, 실제 임상/문헌 근거 없음) |
| 한국 시판 현황 | 미상장 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 mizolastine의 상세 작용 기전 데이터는 확보되지 않았습니다. 다만 근거 자료에 따르면 이 약물은 제2세대 선택적 H1 수용체 길항제로, 중추신경계 침투가 낮고 항콜린 작용이 극히 약한 것이 특징입니다.

급성 간헐성 포르피린증은 heme 생합성 경로(ALA synthase 등)의 효소 이상으로 발생하는 대사 질환으로, H1 수용체 길항 작용과 직접적인 기전 연관성이 없습니다. 오히려 일부 구세대 항히스타민제는 포르피린증 환자에게 잠재적으로 안전하지 않은 약물로 분류되어 있어, 이번 예측은 알려진 약리학적 방향과 **반대**되는 신호입니다.

즉, 이 예측은 지식그래프 임베딩 상의 구조적 유사성에서 비롯된 **거짓 양성(false positive) 가능성이 높은 신호**로 우선 해석해야 하며, 실제 치료적 근거로 채택하기에는 근거가 부족합니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 한국 시판 정보

Mizolastine은 한국에 허가된 제품이 없어 시판 정보가 없습니다 (미상장, 허가증 0건).

## 안전성 고려사항

안전성 정보는 허가사항을 참조하세요.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
근거 수준이 L5(모델 예측 단독)에 불과하고, 관련 임상시험 및 문헌이 전무합니다. 또한 예측 기전이 알려진 약리학적 방향과 상충되어 임베딩 유사성에 의한 거짓 양성 가능성이 높으므로, 현 단계에서 재창출 후보로 진행할 근거가 없습니다.

**진행하려면 필요한 것:**
- Mizolastine의 상세 작용 기전(MOA) 데이터 확보
- 급성 간헐성 포르피린증과의 기전적 연관성을 뒷받침할 전임상/문헌 근거
- 한국 허가사항(경고, 금기, 상호작용) 확인 — 특히 포르피린증 환자에서의 항히스타민제 안전성 관련 자료
- 상기 데이터 미확보 시 이 후보는 추가 검토 없이 보류 상태 유지 권장
