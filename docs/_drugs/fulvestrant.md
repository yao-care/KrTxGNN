# Fulvestrant: 전이성 유방암에서 HIV 감염증으로

## 한 문장 요약

Fulvestrant는 선택적 에스트로겐 수용체 분해제(SERD)로, 국제적으로 HR+/HER2- 전이성 유방암 치료에 사용되어 온 약물입니다. TxGNN 모델은 **HIV 감염증(HIV infectious disease)**에 효과가 있을 수 있다고 예측했으나, 이를 뒷받침하는 임상시험은 없고 유일한 관련 문헌 1편도 실제로는 HIV가 아닌 HTLV-1 관련 연구여서 근거가 매우 미흡합니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | HR+/HER2- 전이성 유방암 (한국 허가 데이터 없음 — 별도 확인 필요) |
| 예측 신규 적응증 | HIV 감염증 (HIV infectious disease) |
| TxGNN 예측 점수 | 99.91% |
| 근거 수준 | L5 |
| 한국 시판 현황 | 미상시판 (허가 0건) |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터가 확보되어 있지 않습니다(Blocking 데이터 갭). 근거 자료 내 다른 예측 적응증(다발성 내분비 종양)에 대한 분석 메모에 따르면 Fulvestrant는 선택적 에스트로겐 수용체 분해제(SERD)로, HR+/HER2- 전이성 유방암에 대한 효능이 입증된 약물로 언급되어 있습니다.

다만 이 정보를 감안하더라도 에스트로겐 수용체 분해 기전과 HIV 감염증 사이에는 알려진 직접적·간접적 연관성이 없습니다. 유일하게 확보된 관련 문헌도 HIV가 아닌 HTLV-1(사람 T세포 백혈병 바이러스 1형) 관련 코호트 분석으로, fulvestrant나 에스트로겐 신호 경로를 다루지 않습니다. 즉, 이번 예측은 지식그래프 상의 질병 온톨로지 혼동(레트로바이러스 감염 카테고리 내 근접 노드) 가능성이 높으며, 기전상 타당성을 뒷받침할 근거가 사실상 없습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
1위 예측 적응증인 HIV 감염증은 TxGNN 점수는 높지만 근거 수준 L5(모델 예측만 존재)이며, 유일한 관련 문헌도 실제로는 무관한 질환(HTLV-1)을 다루고 있어 기전적·임상적 뒷받침이 전혀 없습니다. 참고로 다른 예측 후보 중에서는 6위 류마티스 관절염이 그나마 문헌 5편(에스트로겐-활막염증 기전 연구 위주)으로 상대적으로 나은 편이나, 이 역시 fulvestrant 자체를 다룬 임상 근거는 미흡(L4, S1, Research Question 단계)하여 전체적으로 진행 근거가 부족합니다.
