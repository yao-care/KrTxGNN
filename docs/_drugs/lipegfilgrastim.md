# Lipegfilgrastim: 호중구감소증 치료제에서 혈소판 분비 장애로

## 한 문장 요약

Lipegfilgrastim은 페그화(pegylated) G-CSF 유사체로, 호중구 생성을 촉진하는 약물입니다. TxGNN 모델은 **혈소판 일차 분비 장애(primary release disorder of platelets)**에 효과가 있을 수 있다고 예측하지만, 이를 뒷받침하는 **임상시험과 문헌은 현재 0건**이며 모델 예측만 존재합니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가 적응증 본문은 이번에 정리된 데이터에 포함되지 않았습니다 (허가증 원문 링크만 확인됨) |
| 예측 신규 적응증 | 혈소판 일차 분비 장애 (primary release disorder of platelets) |
| TxGNN 예측 점수 | 99.93% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 2건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면 Lipegfilgrastim은 G-CSF 수용체를 통해 호중구 계열의 증식과 분화를 촉진하는 페그화 G-CSF 유사체입니다.

그러나 이 기전과 혈소판 과립 방출 또는 분비 결함 사이에는 확립된 연관성이 없습니다. 높은 TxGNN 점수는 생물학적 근거라기보다 지식 그래프상 유사한 출혈성 질환들과 이웃 노드를 공유하는 데서 비롯된 네트워크 기반 예측으로 보입니다. 따라서 이 예측은 가설 수준으로만 해석해야 합니다.
