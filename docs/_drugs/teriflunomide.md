# Teriflunomide: 국내 미허가 약물에서 재발-완화형 다발경화증(RRMS)으로

## 한 문장 요약

Teriflunomide는 한국에는 아직 허가되지 않은 약물로, 국내 기준 기존 적응증 정보가 확인되지 않습니다.
TxGNN 모델은 **재발-완화형 다발경화증(Relapsing-Remitting Multiple Sclerosis, RRMS)**에 효과가 있을 것으로 예측하며,
현재 **29건의 관련 임상시험**(다수의 완료된 Phase 3 RCT 포함)과 **20편의 문헌**이 이를 뒷받침합니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 정보 없음 (국내 미허가, 허가증 데이터 없음) |
| 예측 신규 적응증 | 재발-완화형 다발경화증 (Relapsing-Remitting Multiple Sclerosis) |

| 근거 수준 | L1 |
| 한국 시판 현황 | 미상판 (시판되지 않음) |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 다만 Teriflunomide는 류마티스 관절염 치료제 Leflunomide의 활성 대사체로,
디하이드로오로테이트 탈수소효소(DHODH)를 억제하여 활성화된 림프구의 de novo 피리미딘 합성을 차단하고
T세포·B세포 증식을 억제하는 면역조절제로 널리 알려져 있습니다.

이 예측은 완전히 새로운 적응증이라기보다, 전 세계적으로 이미 1차 경구 질병조절치료제(DMT)로 광범위하게 사용되고
있는 용도를 TxGNN이 정확히 재확인한 사례에 가깝습니다. 실제로 29건의 임상시험 중 다수가 RRMS 환자를 대상으로 한
Phase 3 완료 시험이며, 최근까지도 여러 신약(오파투무맙, 우블리툭시맙, 톨레브루티닙, 포네시모드, 에보브루티닙 등)의
비교대조군으로 지속적으로 사용되고 있어 임상적 위치가 확고합니다. 다만 본 Evidence Pack에는 국내 허가 및
원 적응증 데이터가 없어, 이번 예측은 국내 시장 도입 가능성 검토의 관점에서 해석하는 것이 적절합니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
효능 근거 수준은 L1(다수의 완료된 Phase 3 RCT)로 매우 강력하지만, 국내 허가·안전성 정보(주요 경고, 금기, 약물상호작용)가
전혀 확보되지 않아 안전성 초기평가(S1) 단계를 진행할 수 없습니다. 또한 국내 시판 이력이 없어 도입 경로(신약 허가 vs 재창출) 자체가
명확하지 않습니다.

**진행하려면 필요한 것:**
- MFDS/TFDA 공식 허가사항(경고, 금기, DDI) 확보 — 현재 Blocking 등급 데이터 갭
- 상세 작용 기전(MOA) 자료 확보 — DrugBank API 조회 필요
- 국내 허가 여부 및 도입 전략(신약 허가 신청 vs 별도 재창출 경로) 검토
- 위 데이터 확보 후 S1 안전성 초기평가 재개
