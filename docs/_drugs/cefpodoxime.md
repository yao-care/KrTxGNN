# Cefpodoxime: 세균 감염증에서 골관절염 감수성으로

## 한 문장 요약

Cefpodoxime(세프포독심 프록세틸)은 3세대 경구용 세팔로스포린계 항생제로, 한국에서 단일제로 허가되어 시판되고 있습니다.
TxGNN 모델은 **골관절염 감수성(osteoarthritis susceptibility)**에 효과가 있을 수 있다고 예측하지만, 현재 이를 뒷받침하는 **임상시험은 0건**, **문헌도 0편**입니다. 모델 예측만 있는 단계입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가 적응증 본문은 이번 데이터에 포함되지 않았습니다(허가사항 원문 참조 필요). 세팔로스포린계 항생제로 세균 감염증 치료에 사용됩니다. |
| 예측 신규 적응증 | 골관절염 감수성 (Osteoarthritis susceptibility) |
| TxGNN 예측 점수 | 99.35% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 20건 |
| 권장 결정 | Hold |

참고로 TxGNN은 같은 약물에 대해 골관절염(99.25%), 류마티스 관절염(99.24%)도 예측했습니다. 이들 역시 임상시험과 문헌 근거는 없으며 근거 수준은 L5, 권장 결정은 Hold입니다.

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면 cefpodoxime은 세균의 페니실린 결합 단백질(PBP)에 결합해 세포벽 합성을 억제하는 경구 세팔로스포린입니다. 이는 항균 작용이며, 골관절염에 연결되는 경로는 확인되지 않습니다.

예측된 "골관절염 감수성"은 유전적 위험 개념에 가깝고 치료 가능한 질환 상태가 아닙니다. 항균 기전과 연골 보호, 항염증, 질환 조절 작용 사이에 알려진 연결고리도 없습니다. 점수가 매우 높은 것은 지식 그래프상의 근접성을 반영한 결과일 가능성이 크며, 생물학적 타당성을 입증하는 것은 아닙니다. 감염이나 미생물군 조절을 통한 간접 효과 같은 가설은 현재 데이터로는 추측에 불과합니다.

## 안전성 고려사항

- **약물 상호작용**: 총 78건이 확인되었으며, 조회된 주요 항목은 모두 중등도(Moderate)입니다.
  - 위산 억제제: 파모티딘, 라니티딘, 시메티딘, 니자티딘, 오메프라졸, 에소메프라졸, 란소프라졸, 덱스란소프라졸, 판토프라졸, 라베프라졸
  - 제산제: 수산화알루미늄, 탄산칼슘, 마갈드레이트, 탄산마그네슘, 수산화마그네슘, 산화마그네슘
  - 기타: 카나마이신, 네오마이신, 발살라자이드

위산 억제제와 제산제는 경구 흡수를 떨어뜨릴 수 있으므로 병용 시 주의가 필요합니다. 그 밖의 경고, 금기 등 안전성 정보는 허가사항을 참조하세요.

만성 질환(특히 류마티스 관절염처럼 면역 조절 치료를 받는 집단)에서 항생제를 장기간 쓰면 내성, C. difficile 감염 위험, 다수의 약물 상호작용 같은 안전성 문제가 생길 수 있어 사전 검토가 필요합니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
예측 점수는 높지만 임상시험과 문헌이 전혀 없고 기전적 연결도 확인되지 않아 근거 수준이 L5(모델 예측만 존재)입니다. 예측된 적응증이 유전적 감수성 개념이라는 점도 재창출 근거를 약하게 합니다.

**진행하려면 필요한 것:**
- 상세한 약물 작용 기전(MOA) 데이터 확보 (DrugBank 조회)
- 허가사항 원문에서 경고·금기 및 허가 적응증 확인
- 골관절염 또는 관련 질환과의 생물학적 연결을 지지하는 전임상·기전 연구
- 관련 임상시험 및 문헌의 존재 여부 재확인
- 만성 항생제 사용에 따른 안전성 평가(내성, 상호작용 포함)
