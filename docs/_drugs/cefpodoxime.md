## Cefpodoxime: 세균 감염에서 골관절염으로
{: .text-alpha }

## 한 문장 요약

Cefpodoxime(세프포독심 프록세틸)은 경구용 3세대 세페임계 항생제로, 한국에서 단일 성분 제제로 허가되어 있습니다. TxGNN 모델은 **골관절염(Osteoarthritis)**에 효과가 있을 수 있다고 예측하지만, 현재 이를 직접 뒷받침하는 **임상시험은 0건**, **문헌도 0편**입니다. 따라서 이 예측은 모델 계산 결과일 뿐이며, 근거 수준은 L5입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가 적응증 본문은 첨부 문서 링크로만 제공되어 구체적인 질환명을 확인할 수 없음 (허가사항 참조) |
| 예측 신규 적응증 | 골관절염 |
| TxGNN 예측 점수 | 0.9925 |
| 근거 수준 | L5 |
| 한국 시판 현황 | Unknown (source lacks cancellation status) |
| 허가 건수 | 최소 20건 (목록이 일부일 수 있음) |
| 권장 결정 | Hold |

참고: 두 번째 예측인 **류마티스 관절염**(점수 0.9924)도 같은 L5, Hold 판정이며 임상시험과 문헌이 모두 없습니다.

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 일반적으로 cefpodoxime은 세균 세포벽 합성을 억제하는 경구 세팔로스포린계 항생제로 알려져 있습니다. 그러나 이 보고서를 위해 수집된 데이터에는 기전 정보가 확인되지 않았습니다.

골관절염은 연골 퇴행, 기계적 스트레스, 저강도 염증이 원인인 비감염성 퇴행성 관절 질환입니다. 항균 작용과 이 질환의 병태생리 사이에서 신뢰할 만한 기전적 연결고리는 확인되지 않았습니다. 예측 점수는 TxGNN 모델(딥러닝)에서 나온 값이며, 모델이 학습한 관련 질환 간의 유사성을 반영할 수 있지만 생물학적 근거는 아닙니다. 항염 효과 같은 가설은 입증되지 않은 추측입니다.

류마티스 관절염 역시 면역 이상에 의한 자가면역 질환으로, 면역조절 작용이 알려지지 않은 항생제와의 연결점이 없습니다. 면역억제 환자의 감염 치료는 기존 항균 용도에 해당하며 재창출 적응증이 아닙니다.

## 안전성 고려사항

- **약물 상호작용**: 총 78건이 확인되었으며, 그중 일부 목록은 모두 중등도(Moderate) 수준입니다.
  - 위산 억제제: famotidine, ranitidine, cimetidine, nizatidine, omeprazole, esomeprazole, lansoprazole, dexlansoprazole, pantoprazole, rabeprazole
  - 제산제: 수산화알루미늄, 탄산칼슘, magaldrate, 탄산마그네슘, 수산화마그네슘, 산화마그네슘
  - 기타: balsalazide, kanamycin, neomycin

그 외 경고 및 금기 정보는 허가사항을 참조하세요.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
골관절염에 대한 임상시험과 문헌이 없고, 신뢰할 만한 기전적 연결고리도 확인되지 않았습니다. 예측 점수가 높아도 모델 예측만으로는 재창출을 진행할 근거가 부족합니다.

**진행하려면 필요한 것:**
- 허가사항(첨부 문서)에서 기존 적응증과 경고·금기 정보 확인
- 작용 기전 데이터 보완 및 골관절염과의 기전적 연관성 검토
- 골관절염에 대한 전임상 또는 임상 근거 확보
- 한국 시판 현황(취소 여부) 확인
