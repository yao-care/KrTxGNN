# Azosemide: 기존 적응증에서 간폐증후군으로

## 한 문장 요약

Azosemide는 루프이뇨제로, 한국에서 단일제(유레틴정)로 허가·시판 중입니다. TxGNN 모델은 **간폐증후군(hepatopulmonary syndrome)**에 효과가 있을 수 있다고 예측하지만, 현재 이를 뒷받침하는 **임상시험과 문헌은 없습니다**. 따라서 모델 예측만 있는 초기 단계의 가설입니다.

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면 Azosemide는 Na-K-2Cl 공동수송체를 억제하는 루프이뇨제입니다. 따라서 체액 과다나 부종을 조절하는 데 쓰입니다.

간폐증후군은 폐혈관 확장과 산소화 장애로 발생하며, 체액 과다가 원인이 아닙니다. 따라서 이뇨 기전과 질환 자체를 직접 연결하는 고리는 뚜렷하지 않습니다. 기대할 수 있는 효과는 기저 간질환에 동반된 복수나 부종의 증상 완화 정도입니다.

같은 점수(99.41%)로 예측된 다른 후보는 원발성 문맥혈전증, 간문맥경화증, 조기발병 가족성 비경변성 문맥압항진증, 특발성 구리연관 간경변입니다. 이들 역시 임상시험이나 문헌 근거가 없으며, 복수 조절 외의 질환 특이적 기전은 확인되지 않습니다. 간포르피린증(99.21%)은 이뇨제로 인한 전해질 이상과 급성 발작 유발 가능성까지 검토가 필요합니다.
