# Iohexol: 방사선 조영제에서 불면증으로

## 한 문장 요약

Iohexol은 비이온성 요오드화 방사선 조영제로, 원래 치료 목적이 아닌 영상 진단(조영촬영)에 사용됩니다.
TxGNN 모델은 **불면증(Insomnia)**에 효과가 있을 수 있다고 예측하며 점수는 99.87%로 매우 높지만,
이를 뒷받침하는 임상시험이나 문헌은 **전무**합니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 자료 없음 (한국 미상장, 승인 적응증 없음). Iohexol은 치료제가 아닌 방사선 조영제(영상진단용)로 알려져 있음 |
| 예측 신규 적응증 | 불면증 (Insomnia) |
| TxGNN 예측 점수 | 99.87% |
| 근거 수준 | L5 (모델 예측만 존재, 실제 연구 없음) |
| 한국 시판 현황 | 미상장 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

작용기전(MOA) 상세 자료는 현재 확보되어 있지 않습니다(자료 공백, High 등급).

다만 Evidence Pack 내 다른 예측 적응증들의 기전 분석에서 일관되게 언급된 내용에 따르면,
Iohexol은 **비이온성 요오드화 방사선 조영제**로 중추신경계 약리 활성이 없는 물질입니다.
불면증 치료에 필요한 GABA성/세로토닌성 등 수면 조절 기전과의 연관성이 확인되지 않으며,
Evidence Pack 자체도 "TxGNN 고득점 추정은 임상·문헌 근거 없이 도출되었다"고 명시하고 있습니다.

참고로 함께 검토된 나머지 9개 예측 적응증(불안, 류마티스 관절염, 건염 등)도 대부분
Iohexol이 **GFR 측정이나 관절조영술(arthrography) 시 조영제로 공동 출현**한 잡음(noise)으로 확인되었으며,
실질적인 치료적 근거로 이어지는 경우는 없었습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 한국 시판 정보

한국에 시판 중인 허가 제품이 없습니다 (허가증 0건, 미상장).

## 안전성 고려사항

안전성 정보는 허가사항을 참조하세요.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
최상위 예측 적응증(불면증)은 근거 수준 L5로, 이를 뒷받침하는 임상시험이나 문헌이 전혀 없고
약물의 알려진 기전상 중추신경계 작용이 없어 생물학적 타당성도 낮습니다.
함께 검토된 나머지 예측 적응증들 역시 대부분 조영제 사용 시의 공동출현 잡음으로 확인되어
치료적 근거로 볼 수 없습니다.

**진행하려면 필요한 것:**
- TFDA(현지 허가당국) 경고문/금기사항 자료 확보 (현재 Blocking 등급 자료 공백으로 안전성 초기평가 진입 불가)
- DrugBank 작용기전(MOA) 상세 자료 확보
- 불면증에 대한 실제 전임상 또는 임상 근거 확보, 혹은 다른 후순위 예측 적응증 재평가 필요
