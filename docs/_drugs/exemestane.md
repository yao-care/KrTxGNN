# Exemestane: 유방암에서 항트롬빈 결핍증(Type 2)으로

## 한 문장 요약

Exemestane은 스테로이드형 방향화효소(aromatase) 억제제로, 문헌상 폐경 후 호르몬 수용체 양성 유방암 치료제로 확립되어 있습니다. TxGNN 모델은 **항트롬빈 결핍증 2형(Antithrombin deficiency type 2)**에 효과가 있을 수 있다고 예측했지만, 이를 지지하는 임상시험이나 문헌은 **0건**이며, 기전상 연관성도 확인되지 않아 모델 예측 단독 근거(L5)에 그칩니다.

---

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 유방암 (문헌 근거 기반 추정 — 한국 허가자료 없음) |
| 예측 신규 적응증 | 항트롬빈 결핍증 2형 (Antithrombin deficiency type 2) |
| TxGNN 예측 점수 | 99.83% |
| 근거 수준 | L5 (모델 예측만 있음, 실제 연구 없음) |
| 한국 시판 현황 | 미상시 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

---

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터가 없습니다 [Data Gap]. 다만 알려진 정보에 따르면 Exemestane은 스테로이드형 방향화효소 억제제로, 안드로겐의 에스트로겐 전환을 비가역적으로 차단하여 에스트로겐 의존성 유방암 치료에 사용됩니다.

항트롬빈 결핍증 2형은 SERPINC1 유전자 돌연변이로 인한 유전성 항응고 기능 이상 질환으로, 방향화효소/에스트로겐 경로와 생물학적으로 직접 연결되는 기전이 없습니다. TxGNN 예측 점수는 매우 높지만(99.83%), 임상시험·문헌 근거가 전무하다는 점을 고려하면 이는 지식그래프 내 공존질환/약물 노드 간 연결로 인한 **예측 아티팩트(false positive)일 가능성**이 높습니다. 실제로 같은 예측 목록의 상위권에 항트롬빈 결핍, Factor V 과다, 헤파린 보조인자 II 결핍, 혈전성향증 등 응고 관련 희귀질환이 다수 군집해 나타나는 패턴도 이러한 우려를 뒷받침합니다.

## 세포독성 (항종양약 참고)

Exemestane은 유방암 치료에 사용되는 호르몬 요법제(스테로이드형 방향화효소 억제제)로, 세포독성 화학요법제(fluoropyrimidine·platinum·taxane 계열)와는 작용 범주가 다릅니다.

| 항목 | 내용 |
|------|------|
| 세포독성 분류 | 호르몬 요법 (표적치료제에 가까움, 전통적 세포독성 약물 아님) |
| 골수억제 위험 | 허가사항의 경고 및 주의사항을 참조하세요 |
| 구토 유발성 등급 | 저(low) — 경구 호르몬제로 일반적으로 낮음 |
| 모니터링 항목 | 골밀도(BMD), 지질 프로파일, 간기능 |
| 취급 방호 | 경구제로 별도의 세포독성 방호 조치는 일반적으로 불필요 (허가사항 확인 필요) |

## 결론 및 다음 단계

**결정: Hold**

**사유:**
예측 점수는 높지만 임상시험·문헌 근거가 전무하고, 기전상 연관성도 확인되지 않습니다. 응고 관련 희귀질환들이 예측 상위권에 군집하는 패턴은 지식그래프 아티팩트 가능성을 시사하므로, 현 단계에서 진행 근거가 부족합니다.

**진행하려면 필요한 것:**
- TFDA 허가 정보(경고/금기) 확보 — S1 안전성 초평가 진입을 위한 필수 선행 조건 (DG001, Blocking)
- DrugBank MOA 상세 데이터 확보 — 기전 연관성 분석 (DG002, High)
- 항트롬빈 결핍증 2형에 대한 전임상/기전 연구 확인 — 예측 아티팩트 여부 검증
- (참고) 예측 순위 2위 무월경(amenorrhea)은 문헌 5편(L3) 확보되었으나, 인과관계가 반대 방향(치료 목적이 아닌 치료 유발 부작용)이므로 별도 재평가 필요
