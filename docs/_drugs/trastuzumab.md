# Trastuzumab: HER2 양성 유방암에서 프로게스테론 수용체 양성 유방암으로

## 한 문장 요약

Trastuzumab(DrugBank ID: DB00072)은 HER2(erbB-2)를 과발현하는 유방암 치료에 사용되는 항HER2 단클론항체입니다.
TxGNN 모델은 **프로게스테론 수용체(PR) 양성 유방암**에도 효과가 있을 수 있다고 예측하며, 현재 **36건의 임상시험**과 **20편의 문헌**이 관련 근거로 확인되었습니다.
다만 근거 검토 결과 이 "신규 적응증"은 실질적으로 **trastuzumab의 기존 승인 영역(HER2 양성 유방암)과 상당 부분 중첩**되는 바이오마커 하위군이라는 점에 유의가 필요합니다.

## 이 예측이 타당한 이유는?

공식 작용기전(MOA) 데이터는 확보되지 않았습니다(Data Gap, DG002). 다만 평가 근거에 포함된 기전 분석 텍스트에 따르면, Trastuzumab은 **항HER2 인간화 단클론항체**로, HER2/erbB-2 수용체에 결합하여 HER2를 과발현하는 종양세포의 증식을 억제하고 항체의존 세포독성(ADCC)을 매개하는 것으로 기술되어 있습니다.

문제는 이 예측이 **PR 상태 자체를 표적으로 한 새로운 약리 가설이 아니라는 점**입니다. 평가 근거는 다음과 같이 명시합니다:

> "Trastuzumab의 療效 기전은 HER2 과발현/증폭에 의존하며, PR 상태를 직접 표적으로 하지 않는다. 이 적응증 라벨은 실제로는 HER2 양성 유방암 임상시험에서 PR 상태에 따라 층화된 하위집단을 반영한 것으로, 독립적인 약리 가설이 아니다. 이미 trastuzumab의 기존 승인 적응증 범위(HER2+/PR+ 유방암)에 속하며, 외삽을 위해서는 HER2 양성 상태를 반드시 함께 확인해야 한다."

즉, "PR 양성 유방암"은 HER2 양성 유방암이라는 기존 적응증 내에서 호르몬 수용체 상태로 세분화된 하위군에 가까우며, 순수한 의미의 "약물 재창출(새로운 질환군으로의 확장)"이라기보다는 **기존 적응증의 바이오마커 기반 정밀화**로 해석하는 것이 타당합니다.

## 결론 및 다음 단계

**결정: Proceed with Guardrails**

**사유:**
- 근거 수준 L1(대형 Phase 3 RCT 다수 포함, 36건 임상시험·20편 문헌)로 근거 자체는 충분하나, "PR 양성 유방암"은 사실상 trastuzumab의 **기존 승인 적응증(HER2 양성 유방암) 내 바이오마커 하위군**에 해당하여 독립적 신규 적응증으로서의 임상적 신규성은 제한적입니다.
- HER2 양성 상태 확인 없이 PR 양성 단독 기준으로 외삽할 경우 기전적 근거가 성립하지 않으므로, 반드시 HER2/PR **이중 층화** 조건 하에서만 진행이 타당합니다.

**진행하려면 필요한 것:**
- **[Blocking, DG001]** 허가 라벨(경고·금기) 확보 — 출처: 식약처 공식 사이트, 방법: 허가사항 PDF 다운로드 및 파싱. 이 자료 없이는 안전성 초기평가(S1) 진입이 불가합니다.
- **[High, DG002]** 공식 작용기전(MOA) 데이터 확보 — 출처: DrugBank API 조회. 현재 기전 연관성 분석은 평가 근거 텍스트에 의존하고 있어 검증이 필요합니다.
- 한국 내 허가 및 시판 현황(현재 0건, 미시판) 재확인 — 실제 개발·허가 전략 수립 전 시장 진입 경로 검토 필요.
- HER2 양성 여부를 필수 동반진단 조건으로 명시한 프로토콜 설계.

*참고: 동일 예측 배치에서 함께 산출된 하위 순위 후보(정상유방형 아형, PR 음성, Luminal A/B 등)는 근거 수준 L3 이하로 확증적 근거가 부족하거나(연구질문 단계), HER2 발현과의 기전적 연관성이 반박되는 신호(Luminal 아형)를 보이고 있어 별도 검토가 필요합니다. 그 외 극희귀 종양(악성 과립세포종, 외배엽간엽종, HHV8 관련 종양 등)에 대한 예측은 모델 예측 점수만 존재하며(L5, Hold), 현 단계에서 실질적 근거가 전무합니다.*
