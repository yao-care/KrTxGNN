## Sirolimus: 기존 허가 적응증에서 지방육종(Liposarcoma)으로
{: .text-alpha }

## 한 문장 요약

Sirolimus는 국내에서 단일 성분 정제 3건이 허가된 mTOR 억제제입니다. 다만 이 보고서용으로 수집한 데이터에는 허가 적응증의 본문이 없고 허가 문서 링크만 있습니다.
TxGNN 모델은 **지방육종(Liposarcoma)**에 효과가 있을 수 있다고 예측하며(점수 0.9989), 관련 근거는 **임상시험 1건**(Phase 2 단일군, 병용요법)과 **문헌 7편**입니다. 문헌은 대부분 간접 근거입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가 적응증 본문이 확인되지 않음(허가 문서 링크만 제공) |
| 예측 신규 적응증 | 지방육종 (Liposarcoma) |

| 허가증 수 | 3건 (유효 3건) |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터는 수집되지 않았습니다. 다만 Sirolimus는 mTORC1을 억제하는 약물로 알려져 있습니다. 지방육종을 비롯한 연부조직 육종에서는 mTOR/PI3K 경로 활성화와 MDM2/CDK4 공동 신호전달이 관여하는 것으로 알려져 있어, mTOR 억제는 생물학적으로 그럴듯한 접근입니다. 특히 병용요법에서 가능성이 거론됩니다.

다만 직접 근거는 제한적입니다. 점액양 지방육종과 연골육종을 대상으로 Sirolimus와 cyclophosphamide를 병용한 Phase 2 단일군 시험이 1건 있으나, 효능 결과는 제공되지 않았습니다. 나머지 문헌은 육종 치료 리뷰와 이식 환자의 암 발생 위험 연구여서 지방육종에 대한 Sirolimus의 효능을 직접 보여주지 않습니다.

## 안전성 고려사항

- **약물 상호작용**: 상호작용 조회 결과 총 100건이 확인되었고, 이 중 20건이 수집되었습니다.
  - **중대(Major)**: Amphotericin B, Amphotericin B(지질 복합체), Mesalazine, Balsalazide, Clarithromycin
  - **중등도(Moderate)**: 혈당강하제(Acarbose, Metformin, Pioglitazone, Alogliptin, Albiglutide, Canagliflozin, Dapagliflozin, Chlorpropamide), 코르티코스테로이드(Hydrocortisone, Triamcinolone, Dexamethasone, Betamethasone, Budesonide), Aprepitant, Cimetidine

경고·금기 항목은 이번 데이터에 포함되지 않았으므로 허가사항을 직접 확인해야 합니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
지방육종을 직접 다룬 근거는 효능 결과가 공개되지 않은 병용요법 Phase 2 단일군 시험 1건뿐이고, 나머지 문헌은 간접 근거입니다. 또한 허가 적응증 본문과 경고·금기 정보가 확보되지 않아 안전성 1차 검토를 진행할 수 없습니다.

**진행하려면 필요한 것:**
- 허가 문서(식약처)에서 적응증, 경고, 금기 본문 확보
- 작용 기전(MOA) 데이터 보완
- NCT02821507의 결과 확인과 Sirolimus 단독 기여도 평가, 지방육종 아형별 추가 근거 탐색
- 위 상호작용 목록의 중대 항목을 포함한 병용약 관리 계획 수립

참고로 같은 데이터에서 림프관평활근종증(LAM)은 Phase 3 MILES 시험(NCT00414648)이 있어 근거가 훨씬 강합니다. 이 보고서의 대상인 지방육종과는 별도의 평가 대상입니다.
