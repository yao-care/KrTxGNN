# Emedastine: 알레르기성 두드러기로의 재창출 평가

## 한 문장 요약

Emedastine(에메다스틴)은 히스타민 H1 수용체 길항제로, 한국에서는 서방성 캡슐(레미코트서방성캡슐)로 허가·시판되고 있습니다.
TxGNN 모델은 **알레르기성 두드러기(allergic urticaria)**에 효과가 있을 수 있다고 예측하며, 이를 뒷받침하는 **문헌 4편**(무작위 대조시험 1편 포함)이 확인되었습니다. 등록된 임상시험은 없습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가 적응증 텍스트가 링크로만 제공되어 구체적 내용을 확인할 수 없음 (허가사항 참조 필요) |
| 예측 신규 적응증 | 알레르기성 두드러기 (allergic urticaria) |
| TxGNN 예측 점수 | 99.96% |
| 근거 수준 | L2 (만성 특발성 두드러기 대상 RCT 1건. 단, 이 시험은 Phase 2/3 분류 정보가 없고 완료된 시험으로 확인된 자료도 없으므로 잠정적인 판정임) |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 2건 |
| 권장 결정 | Hold (추가 연구 과제로 검토) |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터는 확보되지 않았습니다. 다만 emedastine은 강력하고 선택적인 히스타민 H1 수용체 길항제로 알려져 있으며, 이 항히스타민제 계열의 특성은 잘 확립되어 있습니다.

두드러기에서는 비만세포에서 방출된 히스타민이 팽진과 홍반 반응의 주요 매개체입니다. 따라서 H1 수용체를 차단하면 증상 조절이 가능하다는 점에서 기전상 일관됩니다. 문헌(PMID 19558341)에서는 알레르기성 조직 리모델링에 대한 개선 가능성도 언급되지만, 이는 H1 차단 기전에 부차적인 효과입니다.

두 번째 예측 질환인 **한랭 두드러기(cold urticaria)**도 비만세포 탈과립과 히스타민 방출이 핵심이므로 H1 길항이 원칙적으로 타당합니다. 그러나 이는 약물 계열 수준의 추론일 뿐이며, emedastine 고유의 근거 자료는 없습니다(TxGNN 점수 99.82%, 근거 수준 L5).

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
만성 특발성 두드러기에서 loratadine과 비교한 RCT 1건이 있고 H1 길항제로서 기전상 타당하지만, 임상시험 등록이 없고 허가 적응증과 안전성 정보를 확인하지 못했습니다. 한랭 두드러기는 약물 고유의 근거가 전혀 없습니다.

**진행하려면 필요한 것:**
- MFDS 허가사항(적응증, 경고, 금기) 확인: 현재 안전성 검토를 진행할 수 없는 차단 수준의 자료 공백입니다.
- 기존 허가 적응증에 이미 두드러기가 포함되어 있는지 확인 (포함 시 재창출이 아닌 기존 적응증일 수 있음)
- 상세한 작용 기전(MOA) 데이터 (DrugBank 조회)
- RCT(PMID 17229605)의 시험 단계와 완료 여부, 한국인 대상 적용 가능성 검토
- 한랭 두드러기에 대한 emedastine 고유의 임상 근거 확보
