# Magnesium Lactate: 적응증 정보 없음에서 무증상 전신 비만세포증(Smouldering Systemic Mastocytosis)으로

## 한 문장 요약

Magnesium Lactate(마그네슘 락테이트)는 한국에서 허가된 제품이 없어 기존 적응증 정보를 확인할 수 없습니다. TxGNN 모델은 **무증상 전신 비만세포증(Smouldering Systemic Mastocytosis)**에 효과가 있을 수 있다고 예측(점수 99.78%)하지만, 현재 이를 뒷받침하는 **임상시험이나 문헌은 전혀 없어** 모델 예측에만 의존하는 최하위 근거 수준(L5)입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 정보 없음 (한국 내 허가 이력 없음) |
| 예측 신규 적응증 | 무증상 전신 비만세포증 (Smouldering Systemic Mastocytosis) |
| TxGNN 예측 점수 | 99.78% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✗ 미판매 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터가 없습니다. Magnesium Lactate는 한국 내 허가 이력이 없어 기존 적응증 자체도 확인되지 않는 상태입니다.

이론적으로는 마그네슘 이온이 세포막을 안정화하고 칼슘 의존성 활성화를 길항함으로써 비만세포 탈과립을 조절할 가능성이 제시되지만, 이는 마그네슘 계열 약물 일반의 약리학적 추론일 뿐 본 적응증에 특이적인 근거는 아닙니다.

TxGNN의 높은 예측 점수는 지식그래프 상에서 "마그네슘-비만세포 관련 질환" 노드 간 근접성을 반영한 것으로 보이며, 기전 특이적 연결을 의미하지는 않습니다. 즉 이 예측은 가설 생성(hypothesis-generating) 단계로 해석해야 하며, 실제 검증된 근거로 보기는 어렵습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 한국 시판 정보

한국 내 허가 제품이 없습니다 (허가증 0건, 미판매).

## 안전성 고려사항

안전성 정보는 허가사항을 참조하세요.

> 참고: 본 약물의 경고/금기 정보(TFDA/MFDS 라벨) 확보가 안전성 초기 평가(S1)를 위한 필수 선행 요건이나, 현재 미확보 상태입니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
현재 무증상 전신 비만세포증에 대한 예측은 TxGNN 모델 점수(L5)에만 근거하며, 지지하는 임상시험이나 문헌이 전혀 없습니다. 또한 이 약물은 한국 내 허가 이력이 없고 작용기전 데이터도 확보되지 않아, 안전성 초기 평가 단계(S1)에도 진입할 수 없는 상태입니다.

**진행하려면 필요한 것:**
- 라벨 경고사항/금기 정보 확보 (안전성 초기 평가의 필수 선행 요건)
- 작용기전(MOA) 데이터 확보 (기전 연관성 분석에 필수)
- 무증상 전신 비만세포증에 대한 전임상 또는 기전 연구
- 실제 임상시험 또는 문헌 근거 축적 (현재 0건)
