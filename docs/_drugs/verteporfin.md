# Verteporfin: 습성 황반변성(맥락막 신생혈관)에서 미토콘드리아 산화적 인산화 장애로

## 한 문장 요약

Verteporfin은 원래 광동력요법(PDT)을 통해 습성 노인성 황반변성의 맥락막 신생혈관을 치료하는 데 사용되는 광과민제입니다.
TxGNN 모델은 **미토콘드리아 산화적 인산화 장애(핵 DNA 이상으로 인한, mitochondrial OXPHOS disorder)**에 효과가 있을 수 있다고 예측했으나(점수 99.49%),
이를 뒷받침하는 임상시험이나 문헌은 **0건**이며, 오히려 알려진 약리 기전은 이 예측과 상충되는 안전성 우려를 시사합니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 습성 노인성 황반변성의 맥락막 신생혈관 (광동력요법, PDT) |
| 예측 신규 적응증 | 미토콘드리아 산화적 인산화 장애 (핵 DNA 이상으로 인한) |
| TxGNN 예측 점수 | 99.49% |
| 근거 수준 | L5 (모델 예측만 있음, 실제 연구 없음) |
| 한국 시판 현황 | 미상판 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터는 확인되지 않았습니다(Data Gap). 다만 공개된 약리학적 배경을 참고하면, Verteporfin은 벤조포르피린 유도체 광과민제로, 특정 파장의 빛으로 활성화되면 활성산소종(ROS)을 생성해 표적 혈관 내피를 손상시키는 방식으로 작용합니다. 이 외에 빛 활성화 없이도 YAP-TEAD 상호작용(Hippo 경로)을 억제한다는 체외 연구 결과도 존재합니다.

그러나 이 두 가지 알려진 기전 모두 "핵 DNA 이상에 의한 미토콘드리아 산화적 인산화 장애"와 직접적인 치료적 연관성을 갖지 않습니다. 오히려 이러한 질환의 병리학적 기반이 미토콘드리아의 ROS 제거 능력 저하와 OXPHOS 기능 부전이라는 점을 고려하면, Verteporfin의 광과민화에 의한 ROS 생성 특성은 해당 환자군에서 산화 스트레스를 악화시킬 위험이 있어 **치료 효과보다는 안전성 문제를 유발할 가능성**이 더 큽니다.

따라서 TxGNN의 높은 점수(99.5%)는 지식그래프 상의 통계적 연관성으로 해석해야 하며, 기전적으로 검증된 관계로 보기는 어렵습니다. 이 사례는 모델 예측이 실제 약리학적 타당성과 배치될 수 있음을 보여주는 예시입니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
근거 수준이 L5(모델 예측만 존재, 실제 임상/문헌 근거 없음)이며, 공개된 약리학적 정보에 따르면 Verteporfin의 ROS 생성 기전이 오히려 미토콘드리아 산화적 인산화 장애 환자군에서 산화 스트레스를 악화시킬 잠재적 위험을 시사합니다. 이는 치료적 타당성을 뒷받침하기보다 안전성 우려를 제기하는 근거에 가깝습니다.
