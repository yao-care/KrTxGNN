# POTASSIUM NITRATE: 미상 적응증에서 뇌수막염구균 감염으로

## 한 문장 요약

Potassium Nitrate(질산칼륨)는 한국에 시판 허가가 없는 미상품 상태의 물질로, 원래 적응증 데이터도 확보되지 않았습니다. TxGNN 모델은 **뇌수막염구균 감염(Meningococcal Infection)**에 효과가 있을 수 있다고 예측하지만(예측 순위 7104위), 이를 지지하는 임상시험이나 문헌은 **현재 전혀 없습니다**.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 자료 없음 |
| 예측 신규 적응증 | 뇌수막염구균 감염 (Meningococcal Infection) |
| TxGNN 예측 점수 | 99.61% |
| 근거 수준 | L5 |
| 한국 시판 현황 | 미상품 (허가 없음) |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전(MOA) 데이터가 없습니다. 알려진 정보에 따르면 질산칼륨은 전통적으로 국소 지혈제나 치과용 지각과민 완화제로 사용되어 왔으며, 항균 또는 면역조절 경로와 연결되는 알려진 기전은 없습니다.

TxGNN의 예측 점수(99.61%)는 지식그래프 상의 위상적 유사성을 반영할 뿐, 실제 약리학적 기전 추론에 근거한 것이 아닙니다. 원본 적응증 데이터 자체가 확보되지 않은 상태에서 뇌수막염구균 감염과의 생물학적 타당성을 뒷받침할 근거가 없습니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 문헌 근거

현재 관련 문헌이 없습니다.

## 한국 시판 정보

한국 내 허가된 제품이 없습니다(미상품, 허가증 0건).

## 안전성 고려사항

안전성 정보는 허가사항을 참조하세요.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
원본 적응증·작용기전·안전성 정보가 모두 확보되지 않았고, 예측 적응증을 지지하는 임상시험이나 문헌 근거가 전무하여(L5) 진행 근거가 부족합니다. 한국 내 시판 이력도 없어 안전성 프로파일을 참조할 방법이 없습니다.

**진행하려면 필요한 것:**
- DrugBank/TFDA를 통한 작용 기전(MOA) 확보
- 원본 적응증 데이터 확인
- TFDA 등 규제기관의 안전성 경고 및 금기 정보 확보
- 뇌수막염구균 감염과의 기전적 연관성을 뒷받침할 전임상 또는 문헌 근거 확보
