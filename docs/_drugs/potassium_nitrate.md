## Potassium Nitrate: 기존 적응증 정보 미확인에서 수막구균 감염으로
{: .text-alpha }

## 한 문장 요약

Potassium nitrate(질산칼륨)는 한국에서 겔 제형(수출용) 1건으로 허가되어 있으나, 허가 적응증의 구체적인 내용은 이번 데이터에서 확인되지 않았습니다.
TxGNN 모델은 **수막구균 감염(Meningococcal infection)**에 효과가 있을 수 있다고 예측하지만, 이를 뒷받침하는 **임상시험은 0건**, **문헌도 0편**입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 확인 불가 (허가 적응증이 문서 링크로만 제공됨) |
| 예측 신규 적응증 | 수막구균 감염 (Meningococcal infection) |
| TxGNN 예측 점수 | 99.61% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 1건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 질산칼륨은 질산염 염(nitrate salt)이며, 질산염은 아질산염과 일산화질소(NO)로 환원될 수 있습니다. 일산화질소는 일부 환경에서 일반적인 항균 특성을 보이는 것으로 알려져 있습니다.

그러나 이러한 활성이 수막구균(*Neisseria meningitidis*) 감염과 관련된다는 근거는 없습니다. 전신성 수막구균 질환은 이미 확립된 항생제로 치료합니다. 따라서 기전상의 연결고리는 현재 데이터로 뒷받침되지 않으며, 높은 TxGNN 점수(0.996)는 어디까지나 컴퓨터 모델의 예측일 뿐입니다.

참고로 두 번째 예측 후보인 **경화성 담관염(Sclerosing cholangitis, 점수 99.21%)**도 임상시험과 문헌이 없는 L5 수준이며, 질산염-아질산염-일산화질소 신호전달이 염증·혈관 생물학에서 연구된 바 있다는 점에서 이론적 추측만 가능한 상태입니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
수막구균 감염에 대한 임상시험과 문헌이 전혀 없고, 기전상 연결고리도 확인되지 않아 근거는 모델 예측(L5)에 그칩니다. 또한 해당 제품은 외용 겔 제형인 반면 수막구균 감염은 전신 치료가 필요한 질환이어서 투여 경로의 적합성도 확인되지 않았습니다.

**진행하려면 필요한 것:**
- 허가사항 원문(MFDS 문서)을 확인하여 기존 적응증, 경고, 금기 정보 확보
- DrugBank 등에서 작용 기전(MOA) 데이터 확보
- 수막구균 감염 또는 경화성 담관염과 관련한 전임상·임상 근거 탐색
- 투여 경로 적합성 검토 (외용 겔 제형 대 전신 치료 필요성)
