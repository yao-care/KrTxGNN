# Pentamidine: 허가 적응증 확인 불가에서 점상 상피성 각결막염으로

## 한 문장 요약

Pentamidine(화이자펜타미딘이세티온산염주 300mg)은 한국에서 주사용 분말 제제로 시판 중이며, 이번 데이터에는 허가 적응증의 본문이 포함되어 있지 않습니다(허가 문서 링크만 확인됨).
TxGNN 모델은 **점상 상피성 각결막염(Punctate Epithelial Keratoconjunctivitis)**에 효과가 있을 수 있다고 예측하지만, 현재 **임상시험 0건**, **문헌 0건**으로 모델 예측 외의 근거가 없습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 허가 적응증 본문 확인 불가 (허가 문서 링크만 제공됨) |
| 예측 신규 적응증 | 점상 상피성 각결막염 (Punctate Epithelial Keratoconjunctivitis) |
| TxGNN 예측 점수 | 99.73% |
| 근거 수준 | L5 |
| 한국 시판 현황 | ✓ 시판 중 |
| 허가증 수 | 1건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. Pentamidine은 일반적으로 항원충·항진균 작용을 가진 약물로 알려져 있으며, 이 보고서에 사용된 데이터에서는 기전과 예측 질환 간의 연관성이 확인되지 않았습니다.

점상 상피성 각결막염은 흔히 바이러스성 또는 염증성 원인으로 발생합니다. 아칸트아메바 같은 감염성 각막염에서 항미생물 활성이 이론적으로 관련될 수는 있으나, 이는 추측일 뿐 뒷받침하는 자료가 없습니다. 높은 TxGNN 점수(0.997)는 계산상 예측일 뿐입니다.

참고로 상위 예측 질환은 다음과 같으며, 모두 L5(모델 예측만 존재), Hold입니다.

| 순위 | 예측 질환 | 점수 | 비고 |
|------|----------|------|------|
| 2 | 신경영양성 각막병증 | 99.67% | 각막 신경 지배 손상이 원인이며, pentamidine의 신경영양 작용은 알려져 있지 않음 |
| 3 | 노출성 각막염 | 99.36% | 주로 눈꺼풀 폐쇄 불완전에 따른 건조·기계적 문제로, 항미생물 작용으로 해결되기 어려움 |
| 4 | 비인간 동물 질환 | 99.13% | 인간 임상 적응증이 아닌 온톨로지 분류로, 지식 그래프 인공물일 가능성이 높아 우선순위에서 제외 권장 |
| 5 | 선천성 무알부민혈증 | 99.09% | 알부민 합성 유전 질환으로, pentamidine이 작용하는 경로가 알려져 있지 않음 |

## 안전성 고려사항

- **약물 상호작용**: 총 337건이 조회되었으며, 이 중 목록에 포함된 20건은 모두 '중등도(Moderate)' 등급입니다.
  - 혈당강하제: acarbose, albiglutide, alogliptin, metformin, pioglitazone, canagliflozin, chlorpropamide, dapagliflozin
  - 위산억제제: famotidine, rabeprazole, omeprazole
  - 항진균제: amphotericin B, amphotericin B (lipid complex)
  - 위장관계 약물: loperamide, mesalazine, balsalazide, bisacodyl, picosulfuric acid, polyethylene glycol (전해질 포함)
  - 항생제: clarithromycin
- **지식 그래프 기반 금기 관련 질환** (허가사항이 아닌 TxGNN 지식 그래프 기준): 고혈압, 저혈압, 심실빈맥(torsades de pointes), 심장 전도 질환, 심정지, 신장 질환, 췌장염, 간 질환, 담낭 질환, 혈소판감소증, 백혈구감소증, 빈혈(대구성 빈혈 포함), 고혈당, 저혈당, 당뇨병, 당뇨병성 케톤산증, 천식, 고칼슘혈증, 신석회화증, 인 대사 질환, 요관농축증

위 지식 그래프 정보는 공식 허가사항의 금기와 다를 수 있으므로, 반드시 허가사항으로 확인해야 합니다. 또한 허가사항의 경고·금기 정보는 이번 데이터에 포함되지 않아 별도 확인이 필요합니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
임상시험과 문헌 근거가 전혀 없고, 작용 기전 데이터도 없어 TxGNN 예측(점수 99.73%)만으로는 임상적 판단을 내릴 수 없습니다. 안전성 면에서도 지식 그래프상 금기 질환이 다수이고, 허가사항 기반 경고·금기 정보가 확보되지 않았습니다.

**진행하려면 필요한 것:**
- 식약처(MFDS) 허가사항 PDF에서 기존 적응증, 경고 및 금기 정보 확보
- DrugBank 등에서 작용 기전(MOA) 데이터 확보 및 점상 상피성 각결막염과의 기전적 연관성 분석
- 안구 질환에 대한 임상시험 및 문헌 검색
- 주사용 제제의 안구 적용 가능성(투여 경로) 평가
- 비인간 동물 질환 등 모호한 예측 항목은 우선순위에서 제외
