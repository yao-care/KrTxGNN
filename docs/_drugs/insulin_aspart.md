# Insulin Aspart: 제1형 당뇨병에서 제1형 당뇨병으로 (기존 적응증과 일치하는 예측)

## 한 문장 요약

Insulin Aspart는 속효성 인슐린 유사체로, 당뇨병 치료에 사용되어 온 약물입니다.
TxGNN 모델은 **제1형 당뇨병(type 1 diabetes mellitus)**에 효과가 있을 것으로 예측하며(점수 99.95%), 현재 **30건의 임상시험**과 **20편의 문헌**이 이 방향을 지지합니다. 다만 이 예측은 이미 알려진 사용 방식과 일치하므로 엄밀한 의미의 재창출은 아닙니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 한국 허가증에는 허가 문서 링크만 제공되어 있어 적응증 문구를 확인할 수 없음 |
| 예측 신규 적응증 | 제1형 당뇨병 (type 1 diabetes mellitus) |

## 이 예측이 타당한 이유는?

현재 상세한 작용 기전 데이터가 없습니다. 알려진 정보에 따르면, Insulin Aspart는 속효성 인슐린 유사체로 피하 투여 후 인체 인슐린보다 빠르게 흡수됩니다. 제1형 당뇨병에서 결핍된 내인성 인슐린을 보충하는 역할을 하므로 기전상 적용 가능합니다.

따라서 이 예측은 새로운 적응증 발굴이라기보다 이미 확립된 사용을 재확인한 결과입니다. 매우 높은 TxGNN 점수도 이 기존 용도와 일치합니다. 완료된 Phase 3 임상시험이 여러 건 있어 효능과 안전성을 뒷받침합니다.

## 결론 및 다음 단계

**결정: Proceed with Guardrails**

**사유:**
제1형 당뇨병에서 aspart를 직접 또는 식사 인슐린으로 사용한 완료된 Phase 3 임상시험이 여러 건 있어 근거 수준은 L1입니다. 다만 이는 기존 적응증과 일치하는 예측이므로 신규 재창출 가치는 제한적입니다.

**진행하려면 필요한 것:**
- 허가사항(경고·금기·적응증 문구) 확인: 현재 허가 문서의 본문이 확보되지 않아 안전성 검토를 진행할 수 없음
- 상세한 약물 작용 기전(MOA) 데이터 확보
- 상위 예측 중 제1형 당뇨병 외 항목(자가면역성 난소염, 오프시스모이형성증, 국소 지방이영양증 등)은 근거가 없거나 부작용 연관성에 가까워 보류(Hold)가 적절하며, 영아기 신생아 당뇨병과 췌장 무형성증은 기존 당뇨병 적응증의 연장선으로 간접 근거만 있어 추가 연구 질문 수준임
