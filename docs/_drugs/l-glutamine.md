# L-글루타민: 적응증 정보 없음(한국 미판매)에서 피부염(방사선·화학요법 유발성)으로

## 한 문장 요약

L-글루타민(DrugBank DB00130)은 한국에서 정식 허가·시판 이력이 없는 아미노산 성분으로, 국내에 등록된 기존 적응증 정보가 없습니다.
TxGNN 모델이 제시한 10개 후보 질환을 모두 근거 스크리닝한 결과, 대부분(9건)은 임상시험·문헌 근거가 전혀 없는 지식그래프 임베딩 유사성에 의한 예측(근거 수준 L5, Hold)이었으며,
유일하게 **피부염(Dermatitis)** 후보만 **2건의 완료된 RCT**와 **20편의 문헌**(그중 9편이 직접 관련)을 확보해 근거 수준 **L3**, 결정 단계 **S1(연구 질문)**까지 도달했습니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 확인되지 않음 (한국 미판매, 등록된 적응증 없음) |
| 예측 신규 적응증 | 피부염 (Dermatitis, 주로 방사선·화학요법 유발성) |
| TxGNN 예측 점수 | 99.85% |
| 근거 수준 | L3 |
| 한국 시판 현황 | 미판매 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold (연구 질문 단계) |

## 이 예측이 타당한 이유는?

현재 DrugBank 기반 상세 작용 기전(MOA) 데이터는 확보되지 않았습니다(Data Gap, 별도 조치 필요). 다만 수집된 문헌을 종합하면, L-글루타민은 빠르게 분열하는 상피세포·면역세포의 주요 에너지·질소 공급원이며 글루타치온(항산화 물질)의 전구체로서 점막 및 피부 장벽 회복에 관여하는 것으로 알려져 있습니다. 동물실험에서는 CARD11-mTORC1 경로를 통해 Th1/Th17 면역반응을 조절하고, 알레르기성 접촉피부염 모델에서 염증 반응을 억제하는 것이 확인되었습니다.

기존에 국내 허가된 적응증은 없지만, 국제적으로는 두경부암·유방암 환자의 방사선·화학요법 유발 구강점막염 및 피부 독성 완화 목적의 경구/장관 보충제로 다수 연구되어 왔습니다. 이 때문에 TxGNN이 예측한 "피부염" 적응증은 일차성 아토피 피부염이라기보다, 항암치료 관련 이차성 피부 독성 완화라는 좁은 맥락에서 기전적 개연성이 있습니다. 다만 예측 질환명("dermatitis")과 실제 근거의 임상 맥락(방사선/화학요법 유발성) 사이에는 다소 불일치가 존재합니다.

## 안전성 고려사항

안전성 정보는 허가사항을 참조하세요. (약물상호작용 조회 결과 없음, 한국 내 허가·시판 이력 없음)

## 결론 및 다음 단계

**결정: Hold (연구 질문 단계)**

**사유:**
- 완료된 RCT 2건이 존재하지만 모두 방사선·화학요법으로 유발된 이차성 피부염을 대상으로 하며, TxGNN이 예측한 "피부염" 자체(일차성/아토피성)에 대한 직접 근거는 아닙니다.
- 나머지 9개 예측 후보(골다공증, 신생아 출혈질환 등)는 근거 수준 L5로, 임상시험·문헌 근거가 전무하여 지식그래프 임베딩 유사성에 의한 예측으로 판단됩니다.

**진행하려면 필요한 것:**
- 일차성/아토피 피부염을 주요 평가지표로 하는 전향적 임상시험 설계
- L-글루타민의 DrugBank MOA 상세 데이터 보완 (DG002)
- TFDA/식약처 허가사항 기반 경고·금기사항 확인 (DG001, Blocking)
- 한국 내 시판·허가 현황 추가 조사 (현재 0건)
