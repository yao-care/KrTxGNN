# Triptorelin: 성조숙증에서 다모증(Hypertrichosis)으로

## 한 문장 요약

Triptorelin은 GnRH 유사체(agonist)로, 중추성 성조숙증과 같은 성선자극호르몬 의존성 질환에 사용되어 온 약물입니다.
TxGNN 모델은 **다모증(Hypertrichosis)**에 효과가 있을 수 있다고 예측하며(예측 점수 99.99%),
현재 이를 직접 뒷받침하는 임상시험은 없고 관련 문헌도 간접적인 사례 보고 1건에 그쳐 근거가 매우 제한적입니다.
한국에는 아직 허가·시판되지 않은 약물입니다.

## 빠른 개요

| 항목 | 내용 |
|------|------|
| 기존 적응증 | 중추성 성조숙증 등 GnRH 의존성 질환 (해외 승인 기준, 한국 허가 자료 없음) |
| 예측 신규 적응증 | 다모증 (Hypertrichosis) |
| TxGNN 예측 점수 | 99.99% (전체 순위 189위) |
| 근거 수준 | L4 |
| 한국 시판 현황 | 미상장 |
| 허가증 수 | 0건 |
| 권장 결정 | Hold |

## 이 예측이 타당한 이유는?

현재 Triptorelin의 상세한 작용 기전(MOA) 데이터는 확보되지 않았습니다. 다만 Triptorelin은 GnRH 유사체(agonist)로 분류되며, 지속 투여 시 뇌하수체 GnRH 수용체를 탈감작시켜 LH/FSH 분비를 억제하고 성선호르몬(테스토스테론, 에스트로겐) 생성을 감소시키는 기전으로 작용합니다.

안드로겐이 모발 성장을 자극하는 것으로 알려져 있어, 이론적으로는 성선 억제를 통해 안드로겐 의존성 다모증을 완화할 수 있다는 가설이 성립합니다. 그러나 다모증은 약물성·대사성·선천성 등 원인이 매우 다양한 이질적 질환군으로, 특정 단일 기전에 국한되지 않습니다.

실제로 확보된 유일한 문헌은 Ciclosporin에 의해 유발된 다모증 사례 보고이며, Triptorelin은 해당 환자의 배경 약물(테스토스테론 차단 요법의 일부)로 언급되었을 뿐, 다모증 치료 효과를 직접 검증한 연구가 아닙니다. 즉 이 예측은 기전상 가설 수준에 머물러 있으며, 직접적인 인과 근거는 부족합니다.

## 임상시험 근거

현재 관련 임상시험 등록이 없습니다.

## 결론 및 다음 단계

**결정: Hold**

**사유:**
관련 임상시험이 전무하고, 문헌 근거도 단 1건의 간접 사례보고(다모증의 원인이 다른 약물로 명시됨)에 그칩니다. 기전적 연관성 역시 가설 수준이며, 근거 수준 L4로 초기 개발 단계 진입에 필요한 최소 조건을 충족하지 못합니다.

**진행하려면 필요한 것:**
- Triptorelin과 다모증 간의 직접적 인과관계를 검증하는 전임상 또는 관찰 연구
- DrugBank 기반 상세 MOA 및 약물 분류 자료 확보
- 한국 내 허가 현황 및 안전성 자료(경고, 금기, DDI) 확보
- 다모증 하위 유형(안드로겐 의존성 vs 비의존성)별 반응 차이 규명
